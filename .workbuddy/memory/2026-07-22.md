## 销售退货全链路流程设计讨论

与用户深入讨论了销售退货的完整流程设计，核心内容：

### 四阶段流程
退货申请(ERP) → 司机回收(TMS/PDA) → 仓库验收(WMS) → 财务结算(ERP)

### 关键设计决策
1. **双模式退货**：ORDER_BASED（按单退，~20%）+ GOODS_BASED（按品退，~80%），不强制按单
2. **司机轧差上缴**：司机端只记流水不做凭证，日终 COD收款 - 退货退款 = 净上缴，财务端一次生成全部凭证
3. **库存更新锚点**：以仓库验收为准，不以司机回收为准
4. **退货成本**：按当前移动加权平均成本入库，不按原出库成本
5. **回收入库差异处理**：五条路径（数量缺失→司机/客户、品质差异→运输/原厂、品种错误），有容差自动处理机制

### 入账方式可配置
- 模式A（司机签收入账）：PDA提交即生成凭证，差异用正常单据补差，不调账
- 模式B（仓库入库入账，推荐默认）：验收确认才入账，差异在入账前解决
- 系统级配置 + 退货单级覆盖

### 差异处理核心原则（经用户确认优化）
- **差异不调账，用正常单据补差**——原始退货凭证不动
- 司机丢货 → 开销售出库单给司机买赔
- 客户少退 → 开销售出库单给客户增加应收
- 供应商问题 → 开采购退货单
- 品种错误 → 撤销退货明细 + 追回退款
- 差异记录仅做流程追踪，不生成凭证，零新增单据类型

### 残次品处理（经用户确认）
- **WMS质检分流与ERP财务完全解耦**
- WMS决定放正常库/残次库/报废区，不触发任何凭证
- 后续处置（退供应商/报废/折价销售）才通过正常单据走财务
- 品质差异不纳入差异处理流程
