# 通用业务规则

## 一、通用单据状态

```text
DRAFT 草稿
PENDING 待审核
APPROVED 已审核
COMPLETED 已完成
CLOSED 已关闭
CANCELLED 已作废
REJECTED 已驳回
```

## 二、审核原则

| 动作 | 是否产生业务影响 |
|---|---|
| 保存草稿 | 否 |
| 提交审核 | 否 |
| 审核 | 是 |
| 反审核 | 是，必须反向冲销或释放影响 |
| 作废 | 按单据状态判断，已审核单据必须检查下游 |

## 三、库存影响规则

| 场景 | 影响 |
|---|---|
| 采购入库审核 | 增加库存、生成入库流水、重算成本 |
| 销售订单审核 | 锁定库存 |
| 销售出库审核 | 扣减库存、释放锁定、生成出库流水 |
| 报损审核 | 扣减库存、生成出库流水 |
| 调拨审核 | 调出、在途、调入按模式处理 |

## 四、财务影响规则

| 场景 | 影响 |
|---|---|
| 采购收货单审核 | 生成应付 |
| 销售收货单审核 | 生成应收 |
| 收款单审核 | 增加资金账户余额，可核销应收 |
| 付款单审核 | 减少资金账户余额，可核销应付 |

## 五、价格匹配规则

销售开单价格匹配顺序：

```text
客户生效专属价 → 客户等级价/价格组价 → 商品标准售价 → 手工价
```

客户价格调整单审核后才生成生效价格。最新审核生效的同客户同商品价格自动覆盖前价，前价自动停用。

## 六、历史快照

业务单据必须保存以下快照：

- 客户/供应商名称
- 商品名称
- 商品规格
- 单位名称
- 税率
- 单价
- 成本价
- 价格来源
