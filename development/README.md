# ERP-WMS-TMS V1.0 系统开发目录

本目录用于管理 ERP-WMS-TMS V1.0 从 PRD/原型进入系统开发阶段的工程化文件。

## 目录结构

| 目录 | 说明 |
|---|---|
| `00-project-management/` | 开发阶段计划、里程碑、任务拆分、变更记录 |
| `01-architecture/` | 可扩展系统架构、技术架构、模块边界、通用规则、状态流 |
| `02-database/` | 数据库设计落地、初始化脚本、迁移脚本 |
| `03-api/` | API 规范、接口清单、请求响应约定 |
| `04-backend/` | 后端工程规划、模块划分、服务清单 |
| `05-frontend/` | 前端工程规划、页面/组件清单、UI规则 |
| `06-testing/` | 测试策略、验收用例、联调清单 |
| `07-deployment/` | 部署方案、环境配置、发布检查清单 |
| `08-sprints/` | Sprint 计划、每日任务、交付记录 |

## 当前开发基线

- PRD 基准：`docs/PRD-版本化产品需求/V1.0-ERP核心经营版/`
- 原型基准：`prototype/v1-erp-complete/`
- 当前阶段：开发准备 + Sprint 1 系统底座启动

## 开发原则

1. 以当前 PRD 和原型作为 V1.0 开发冻结基线。
2. 审核才产生库存、成本、应收、应付、资金等业务影响。
3. 所有余额类数据必须有来源流水。
4. 基础资料修改不得破坏历史单据快照。
5. 通用能力先抽象，业务模块复用通用列表、表单、单据、导入导出、权限、日志能力。
