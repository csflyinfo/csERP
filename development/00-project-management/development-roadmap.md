# V1.0 开发路线图

## 一、阶段划分

| 阶段 | 名称 | 目标 | 优先级 |
|---|---|---|---|
| Phase 0 | 开发准备 | 工程结构、规范、数据库/API骨架、Sprint计划 | P0 |
| Phase 1 | 系统底座 | 登录、菜单、权限、系统参数、单据编号、操作日志 | P0 |
| Phase 2 | 基础资料 | 商品、客户、供应商、仓库、单位、价格、资金、费用 | P0 |
| Phase 3 | 库存底层 | 库存余额、流水、锁定、批次、成本服务 | P0 |
| Phase 4 | 采购闭环 | 采购订单、入库、收货、费用、应付 | P0/P1 |
| Phase 5 | 销售闭环 | 快速开单、销售订单、出库、收货、客户价格、应收 | P0 |
| Phase 6 | 财务闭环 | 应收、应付、收款、付款、核销、资金流水 | P0/P1 |
| Phase 7 | 增强与报表 | 调拨、盘点、报损、成本调整、报表、导出中心 | P1/P2 |

## 二、里程碑

### M1 系统底座完成

交付：

- 登录可用
- 菜单按权限加载
- 用户/权限组可维护
- 系统参数可维护
- 单据编号规则可维护
- 操作日志可记录
- 通用列表、表单、弹窗、抽屉、单据页基础组件完成

### M2 基础资料完成

交付：

- 商品分类、品牌、单位、商品档案
- 客户、供应商、仓库、资金账户、费用类型
- 价格组、客户价格调整单、客户价格查询
- 基础资料导入/导出骨架

### M3 库存底层完成

交付：

- 库存余额
- 库存流水
- 库存锁定
- 批次库存
- 移动加权成本服务

### M4 采购链路完成

交付：

采购订单 → 采购入库 → 采购收货单 → 应付

### M5 销售链路完成

交付：

销售快速开单 / 销售订单 → 销售出库 → 销售收货单 → 应收

### M6 财务闭环完成

交付：

应收/应付 → 收款/付款 → 核销 → 资金流水

### M7 V1.0 验收版

交付：

- 核心流程测试通过
- 导入导出可用
- 权限/字段权限可用
- 部署检查通过

## 三、近期执行顺序

1. 初始化开发目录和规范。
2. 整理数据库初始化脚本。
3. 整理 API 统一规范。
4. 明确前后端工程结构。
5. 启动 Sprint 1：系统底座 + 基础资料骨架。
