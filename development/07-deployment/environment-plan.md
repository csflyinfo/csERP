# 环境与部署计划

## 一、环境划分

| 环境 | 用途 |
|---|---|
| local | 开发本地环境 |
| dev | 联调环境 |
| test | 测试验收环境 |
| prod | 生产环境 |

## 二、基础依赖

- MySQL 8.x
- Redis 7.x，可选但建议预留
- 后端运行环境按最终技术栈确定
- 前端 Node.js LTS
- 文件存储目录或对象存储

## 三、配置项

| 配置 | 说明 |
|---|---|
| 数据库连接 | host/port/database/user/password |
| Redis连接 | host/port/password/db |
| JWT密钥 | 登录认证 |
| 文件上传路径 | 导入导出、附件 |
| 日志路径 | 应用日志 |

## 四、发布检查清单

- 数据库迁移脚本已执行。
- 配置文件已按环境设置。
- 管理员账号已初始化。
- 菜单权限已初始化。
- 系统参数已初始化。
- 单据编号规则已初始化。
- 健康检查接口可访问。
