# ERP-WMS-TMS Frontend

Vue 3 + Vite 管理后台前端工程骨架。

## 环境要求

- Node.js LTS
- npm

## 安装依赖

```bash
npm install
```

## 启动

```bash
npm run dev
```

默认地址：

```text
http://localhost:5173
```

## 已包含

- 后台主布局
- 左侧菜单
- 菜单顶部快捷搜索
- 顶部模块标题
- 紧凑查询区
- 通用表格样式
- 商品分类、客户价格调整单、客户价格查询 UI 骨架
