# ERP+WMS+TMS 商贸经销商管理系统 — 系统架构设计

## 1. 系统概述

### 1.1 项目背景
面向商贸经销商行业（食品饮料、日化百货、五金建材、家电3C等），提供一套完整的进销存+仓储作业+配送运输的数字化管理系统。

### 1.2 系统定位
- **ERP后台管理系统**：采购、销售、库存、财务、报表、基础数据管理
- **WMS仓库作业APP**：PDA手持终端操作，收货、上架、拣货、复核、盘点、移库
- **TMS司机配送APP**：派单接收、路线导航、签收拍照、回款登记、异常上报

### 1.3 核心业务场景
```
供应商 → 采购订货(ERP) → 仓库收货(WMS→PDA) → 上架(WMS→PDA) → 生成采购收货单(ERP)
    → 应付核算 → 销售开单(ERP) → 波次下放(WMS) → 拣货(WMS→PDA) → 复核(WMS→PDA)
    → 销售出库(WMS) → 司机配送(TMS→司机APP) → 客户签收 → 生成销售收货单(ERP)
    → 应收核算 → 回款核销(财务) → 凭证生成(财务)

退货流程：
  客户退货 → 退货申请(ERP) → 司机回收/仓库入库(WMS→PDA) → 销售退货单(ERP) → 冲减应收
  拒收流程：司机APP拒收 → 拒收入库(WMS→PDA) → 成本冲回

特殊流程：
  商品组合/拆分 → 组合申请(ERP) → 组合出库(WMS→PDA) → 组合入库(WMS→PDA)
  库内作业：移库(WMS→PDA)、生产日期修改(WMS→PDA)、报损出库(WMS→PDA)
```

### 1.4 核心算法
- **成本计算**：移动加权平均法，按成本分组（仓库分组）独立核算
- **采购收货单审核后**触发成本重算，更新库存成本单价
- **其他出入库**取审核时的成本单价
- **采购费用分摊**：按金额/按件数(大单位)/按重量分摊到入库单，重算成本
- **采购改价**：修改历史采购收货单价格，重算成本及应付，更新已日结数据
- **每日定时生成**：客户/供应商/往来单位/商品的日结数据

## 2. 技术选型

### 2.1 后端技术栈

| 层面 | 技术 | 说明 |
|------|------|------|
| 微服务框架 | **Spring Cloud Alibaba 2023.x** | 微服务全家桶，企业级解决方案 |
| 注册中心 & 配置中心 | **Nacos 2.3.x** | 服务发现 + 动态配置管理 |

| 服务调用 | **Dubbo 3.3.x** (核心链路) + **OpenFeign** (一般场景) | RPC高性能双通道 |

| 消息队列 | **RocketMQ 5.x** | 异步解耦、事件驱动 |
| 定时任务 | **XXL-JOB 2.4.x** | 分布式定时调度 |
| 链路追踪 | **SkyWalking 9.x** | APM监控、调用链追踪 |
| 日志中心 | **ELK (Elasticsearch + Logstash + Kibana)** | 日志集中采集分析 |

| 时序数据库 | **TDengine** | 库存变动流水、设备轨迹 |

## 5. 数据架构设计

### 5.1 数据库隔离策略
- **租户隔离**：schema级别隔离（PostgreSQL），每个租户一个schema
- **服务隔离**：每个微服务独立database，跨服务通过API/消息通信
- **读写分离**：PostgreSQL主从复制，写走主库，读走从库

### 5.2 核心数据模型概要

```
基础数据域：
  商品档案(goods) ← 多规格SKU → 条码(barcode)
  客户档案(customer) ← 客户地址 → 配送区域(delivery_zone)
  供应商(supplier) ← 供货商品 → 采购价(purchase_price)
  仓库(warehouse) ← 库区(area) ← 库位(location)

进销存域：
  采购订单(purchase_order) → 采购入库(purchase_in) → 应付账款
  销售订单(sales_order) → 销售出库(sales_out) → 应收账款
  库存流水(inventory_ledger) → 库存余额(inventory_balance)

WMS域：
  入库单(inbound_order) → 上架任务(putaway_task)
  出库单(outbound_order) → 波次(wave) → 拣货任务(pick_task) → 复核(verify)
  盘点计划(stocktake_plan) → 盘点明细(stocktake_detail)

TMS域：
  派送单(delivery_order) → 装车(loading) → 配送路线(delivery_route)
  签收记录(sign_record) → 回款记录(payment_record)
  GPS轨迹(gps_track) → 电子围栏事件(geofence_event)

财务域：
  应收(ar) / 应付(ap) / 收付款(payment) / 核销(reconciliation)
  费用(expense) / 资金流水(cash_flow)
```

## 6. 关键技术方案

### 6.1 高性能方案
- **多级缓存**：浏览器缓存 → CDN → Nginx本地缓存 → Redis集群 → 本地Caffeine缓存
- **数据库优化**：合理索引 + 分区表(按月) + 慢SQL持续优化
- **异步处理**：库存记账、短信推送等非实时操作走MQ异步
- **读写分离**：报表查询走从库/ES，不冲击主库

### 6.2 高可用方案
- 所有服务至少2实例，Nacos/Redis/RocketMQ均为集群模式
- PostgreSQL主从 + 自动故障切换（Patroni + etcd）
- 服务熔断降级（Sentinel），关键链路兜底
- 异地灾备，RPO < 1分钟

### 6.3 安全方案
- JWT + OAuth2.0 认证
- RBAC权限模型，细粒度按钮级权限
- 所有API统一经过Gateway鉴权
- 敏感数据加密存储(密码、手机号)
- 操作日志全记录（审计追踪）
- SQL注入/ XSS / CSRF 防御

### 6.4 PDA适配方案
- 适配主流PDA品牌：斑马(Zebra)、霍尼韦尔(Honeywell)、东集(Seuic)、优博讯(Urovo)
- 支持一维码/二维码扫描（摄像头 + 硬件扫描头）
- 离线模式：本地SQLite缓存，有网时自动同步
- 蓝牙打印：对接便携蓝牙打印机
