## 三、版本说明

| 版本 | 文件夹 | 目标 |
|---|---|---|
| 总览与规范 | `00-总览与规范` | 产品路线、统一对象、状态机、验收标准 |
| V1.0 | `V1.0-ERP核心经营版` | 基础数据、采购、销售、库存、应收应付、收付款、报表 |
| V1.5 | `V1.5-仓储作业版` | WMS后台、PDA收货、上架、拣货、复核、盘点 |
| V2.0 | `V2.0-仓配一体版` | TMS调度、司机APP、装车、配送、签收、拒收 |
| V2.5 | `V2.5-B2B订货版` | B2B后台、客户商城小程序、线上订单、售后、对账 |
| V3.0 | `V3.0-平台多入驻商版` | 入驻商、统配、自配、订单拆单、结算分账 |

## 四、维护规则

1. 新增某个版本的文档，放到对应版本文件夹。
2. 跨版本统一规则，放到 `00-总览与规范`。
3. V1.0开发相关文档，统一放到 `V1.0-ERP核心经营版`。
4. 历史参考资料不放入本目录，仍保留在 `E:\我的工作项目\参考资料`。
5. 当前产品设计、UI、开发、测试以本目录和 `docs/子系统/` 为准。
