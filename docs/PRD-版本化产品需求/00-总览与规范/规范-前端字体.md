# 全局规范 — 前端字体

> 生效范围：V1.0 及以后所有前端页面
> 生成日期：2026-07-22

## 一、字体方案（三段组合，不使用微软雅黑）

|用途|字体|npm 包|
|---|---|---|
|中文正文|**思源黑体（Noto Sans SC）**，Variable Font|`@fontsource-variable/noto-sans-sc`|
|英文/数字正文|**Inter**（400 / 500 / 700）|`@fontsource/inter`|
|等宽（金额、代码、编码列）|**Fira Code**（400 / 500）|`@fontsource/fira-code`|

**加载方式**：走 npm 包 + Vite 打包，不使用 Google Fonts CDN。字体文件随 dist 一起发布，离线可用。

## 二、CSS 变量

`frontend/src/styles/app.css` 顶部声明，全站引用：

```css
:root {
  --font-sans: "Inter", "Noto Sans SC Variable", "Noto Sans SC",
               -apple-system, BlinkMacSystemFont, "Helvetica Neue", Arial, sans-serif;
  --font-mono: "Fira Code", ui-monospace, "SF Mono", Menlo, Consolas, monospace;
}

body {
  font: 13px/1.45 var(--font-sans);
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}
```

浏览器按 code point 匹配：**拉丁字母/数字 → Inter；CJK → 思源黑体；等宽场景 → Fira Code**。

## 三、使用规则

- **正文/表单/菜单**：不要写 `font-family`，让 body 全局继承 `--font-sans`
- **金额、数量、编码、单据号、时间戳**：用 `font-family: var(--font-mono); font-variant-numeric: tabular-nums;`（等宽 + 数字定宽对齐）
- **禁止**：`Microsoft YaHei`、`PingFang SC`、`Consolas` 硬编码；老代码遇到就替换成 `var(--font-mono)` 或删掉
- 新增权重时（如 `600` 半粗）在 `main.js` 追加 `import '@fontsource/inter/600.css'`

## 四、main.js 引入顺序

```js
// 字体先于业务 CSS 引入，避免首屏闪烁
import '@fontsource-variable/noto-sans-sc/index.css'
import '@fontsource/inter/400.css'
import '@fontsource/inter/500.css'
import '@fontsource/inter/700.css'
import '@fontsource/fira-code/400.css'
import '@fontsource/fira-code/500.css'
import './styles/app.css'
```
