## 一、设计目标

### 1.1 业务背景

商贸经销商行业的核心财务诉求：

- **业财一体**：采购入库、销售出库、费用单等业务单据自动生成会计凭证，减少人工录入
- **多维度核算**：按部门、片区、业务员、项目等多维度归集收入与成本
- **税务合规**：商贸企业增值税进项/销项管理、发票与凭证关联
- **固定资产管理**：商贸企业的车辆、仓库设备、冷链设备、货架等资产的管理与折旧
- **快速结账**：月末结账自动计提折旧、摊销、结转成本

### 1.2 与 V1.0 的关系

| 模块 | V1.0 形态 | V2.0 深化 |
|---|---|---|
| 应收/应付 | 单据级应收应付 | 凭证级总账核算 |
| 费用单 | 费用录入与分摊 | 费用自动归集科目 + 凭证生成 |
| 资金流水 | 收付款流水 | 银行对账 + 凭证生成 |
| 库存 | 进销存 | 成本自动结转凭证 |

## 二、科目管理（Chart of Accounts）

### 2.1 页面入口

`财务管理 → 科目管理`

### 2.2 功能定位

### 2.6 业务规则

- **系统预置科目**不可删除、不可修改编码，但可停用
- 科目编码全局唯一，符合国家会计制度
- 新增科目自动作为末级科目；若已有凭证引用则不可删除
- 科目启用后不可禁用，但可停用（停用后不可再用于新凭证）
- 辅助核算维度启用后，对应凭证分录必须填写辅助核算项

## 三、核算项目管理（Cost/Profit Center）

### 3.1 页面入口

`财务管理 → 核算项目管理`

### 3.2 功能定位

定义辅助核算的具体维度值，为科目挂接辅助核算时提供数据源。V2.0 支持以下核算维度：

| 维度 | 数据来源 | 用途 |
|---|---|---|
| 客户 | 基础资料 → 客户资料 | 应收/收入按客户归集 |
| 供应商 | 基础资料 → 供应商资料 | 应付/成本按供应商归集 |
| 商品 | 基础资料 → 商品档案 | 收入/成本按商品归集 |
| 部门 | 基础资料 → 部门管理 | 费用按部门归集 |
| 片区 | 基础资料 → 片区管理 | 收入/费用按区域归集 |
| 业务员 | 基础资料 → 人员信息 | 收入/提成按人归集 |
| 项目 | 本模块维护 | 按项目/合同独立核算 |

### 3.3 页面结构

**以 Tab 切换维度**：

- Tab 1：按客户（引用客户资料，只读选择）
- Tab 2：按供应商（引用供应商资料，只读选择）
- Tab 3：按商品（引用商品档案，只读选择）
- Tab 4：按部门（引用部门管理，只读选择）
- Tab 5：按片区（引用片区管理，只读选择）
- Tab 6：按业务员（引用人员信息，只读选择）
- Tab 7：按项目（本模块维护）

### 3.4 项目维护（Tab 7）

| 字段 | 类型 | 说明 |
|---|---|---|
| 项目编码 | 输入框 | 唯一 |
| 项目名称 | 输入框（必填） | 如「2026年夏季促销活动」、「仓储改造工程」 |
| 项目类型 | 下拉 | 经营项目/工程项目/其他 |
| 开始日期 | 日期 | |
| 结束日期 | 日期 | |
| 预算金额 | 数字 | 可选，用于预算控制 |
| 负责人 | 下拉（人员信息） | |
| 状态 | 下拉 | 未开始/进行中/已结束/已暂停 |

### 3.5 业务规则

- 前 6 个维度引用现有基础资料，不可在本模块新增/编辑（跳转到对应模块）
- 项目维度在本模块维护
- 科目挂接了辅助核算维度后，凭证分录必须选择对应维度值
- 同一个辅助核算维度值停用后，已有凭证不受影响，但不可用于新凭证

## 四、凭证管理（Voucher Management）

### 4.1 页面入口

`财务管理 → 凭证管理`

### 4.2 功能定位

凭证的录入、审核、查询、打印，支持手工录入和业务单据自动生成。是总账核算的核心载体。

### 4.3 页面结构

**列表页**：

| 筛选 | 说明 |
|---|---|
| 凭证日期范围 | 日期段，默认当月 |
| 凭证字号 | 如「记-202607-0001」 |
| 科目 | 按科目筛选 |
| 制单人/审核人 | |
| 状态 | 全部/草稿/已审核/已作废 |

列表列：`凭证字号 / 日期 / 附件数 / 摘要 / 借方金额合计 / 贷方金额合计 / 制单人 / 审核人 / 状态 / 操作`

**编辑页（抽屉/独立页）**：

参照 V1.0 商品编辑抽屉风格，分三个区域：

#### 4.3.1 凭证头

| 字段 | 说明 |
|---|---|
| 凭证字号 | 自动生成：`记 + yyyyMM + 4位流水` |
| 凭证日期 | 默认当前日期，不可跨月（只允许当月） |
| 附件数 | 数字，默认 0 |
| 摘要 | 凭证级摘要，自动取第一行分录摘要 |

#### 4.3.2 分录明细（网格，至少 2 行，借贷平衡）

| 行号 | 摘要 | 科目 | 辅助核算 | 借方金额 | 贷方金额 |
|---|---|---|---|---|---|
| 1 | 输入 | 下拉选择末级科目 | 按科目辅助核算配置动态展示 | 数字 | 数字 |
| 2 | … | … | … | … | … |

- 分录至少 2 行，借贷方金额合计必须相等
- 选择科目后自动带出该科目的辅助核算维度（如科目挂接了「客户」辅助核算，则出现客户下拉框）
- 支持快捷复制上行摘要
- 支持「插入行」「删除行」
- 底部显示借方合计、贷方合计、差额（差额为 0 时绿色显示）

#### 4.3.3 快捷操作

- **保存草稿**：不校验借贷平衡，状态为「草稿」
- **保存并审核**：校验借贷平衡，状态为「已审核」
- **作废**：仅「草稿」状态可作废；已审核凭证需「反审核」后再作废
- **打印**：调用打印模板，输出标准记账凭证格式

### 4.4 业务单据自动生成凭证（业财一体）

V2.0 核心能力：以下业务单据在审核后自动生成对应凭证（可配置开/关）：

| 业务单据 | 借方科目 | 贷方科目 | 说明 |
|---|---|---|---|
| 采购入库 | 库存商品 | 应付账款-暂估 | 按供应商辅助核算 |
| 采购收货单审核 | 应付账款-暂估 | 应付账款 | 过渡科目冲销 |
| 销售出库 | 主营业务成本 | 库存商品 | 按商品辅助核算 |
| 销售收货单审核 | 应收账款 | 主营业务收入 | 按客户+商品辅助核算，同时带出增值税 |
| 收款单 | 银行存款 | 应收账款 | 按客户辅助核算 |
| 付款单 | 应付账款 | 银行存款 | 按供应商辅助核算 |
| 费用单 | 销售费用/管理费用 | 应付账款/银行存款 | 按费用类型映射科目 |
| 固定资产折旧 | 销售费用/管理费用 | 累计折旧 | 按月自动生成 |

### 4.5 业务规则

- 凭证日期不可跨月，必须与业务单据日期同月
- 凭证号每月从 0001 起，按创建时间连续
- 已审核凭证不可修改；反审核后恢复为草稿，可修改
- 反审核条件：凭证未被财务报表引用、不在已结账期间
- 凭证作废后保留原编号，不可复用
- 自动生成凭证的摘要规则：`单据类型 + 单号 + 往来单位`（如「采购入库单 PO202607150001 农夫山泉」）

## 五、凭证模板管理（Voucher Template）

### 5.1 页面入口

`财务管理 → 凭证模板管理`

### 5.2 功能定位

为高频业务场景预制凭证模板，用户选择模板后快速生成凭证分录，减少重复录入。适用于商贸企业的固定计提、摊销、结转等业务。

### 5.3 页面结构

列表列：`模板编码 / 模板名称 / 凭证类型 / 分录行数 / 使用次数 / 状态 / 操作`

### 5.4 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 模板编码 | 输入框 | 唯一 |
| 模板名称 | 输入框（必填） | 如「工资计提」、「房租摊销」 |
| 凭证类型 | 下拉 | 记账凭证/转账凭证/收款凭证/付款凭证 |
| 说明 | 多行文本 | 适用场景说明 |

**分录模板（网格，与凭证分录类似）**：

| 行号 | 摘要模板 | 科目 | 辅助核算 | 金额方向 | 金额公式/固定值 |
|---|---|---|---|---|---|
| 1 | `计提{月份}工资` | 销售费用-工资 | 按部门 | 借 | 固定值 / 公式引用 |
| 2 | `计提{月份}工资` | 应付职工薪酬 |  | 贷 | 同借方合计 |

- 金额支持：固定值、取上月值、取业务单据汇总值、自定义公式
- 摘要支持变量占位：`{月份}`、`{日期}`、`{当前用户}`

### 5.5 使用场景

**场景一：月末计提工资**
```
借：销售费用-工资　→　按部门辅助核算　→　金额：上月工资总额
贷：应付职工薪酬　→　金额：同借方合计
```

**场景二：房租摊销（按月）**
```
借：管理费用-房租　→　金额：每月固定 5000
贷：预付账款-房租　→　金额：5000
```

**场景三：结转本期损益**
```
借：主营业务收入（各明细科目）
借：其他业务收入
贷：本年利润
贷：主营业务成本（各明细科目）
贷：销售费用（各明细科目）
贷：管理费用（各明细科目）
贷：财务费用
```

### 5.6 业务规则

- 模板列表只显示状态为「正常」的模板
- 点击「应用模板」→ 打开新凭证页，自动填入分录
- 用户可修改模板带入的分录后再保存
- 模板修改不影响已生成的凭证

## 六、固定资产管理（Fixed Assets）

| 资产名称 | 输入框（必填） | |
| 资产类别 | 下拉 | 房屋建筑/运输工具/仓储设备/办公设备/冷链设备/电子设备/其他 |

| 使用部门 | 下拉（部门管理） | |
| 使用人 | 下拉（人员信息） | |
| 存放地点 | 输入框 | |
| 原值 | 数字（必填） | 含税购置价格 |
| 启用日期 | 日期 | 次月起计提折旧 |
| 折旧方法 | 下拉 | 平均年限法 / 双倍余额递减法（V2.0 仅实现平均年限法） |
| 折旧年限 | 数字 | 年 |
| 残值率 | 百分比 | 默认 5% |
| 月折旧额 | 自动计算 | `原值 × (1 - 残值率) / (折旧年限 × 12)` |
| 累计折旧 | 自动计算（只读） | 由每月折旧计提更新 |
| 净值 | 自动计算（只读） | `原值 - 累计折旧` |
| 资产状态 | 下拉 | 使用中/已停用/已报废 |

### 6.5 折旧计提（月度任务）

**执行入口**：`财务管理 → 固定资产管理 → 计提折旧`

- 每月每个资产生成一条折旧凭证分录
- 借：`销售费用-折旧` / `管理费用-折旧`（按使用部门入对应科目）
- 贷：`累计折旧`
- 支持「预览」：查看当月应计提折旧清单，确认后一键生成凭证
- 已计提月份不可重复计提
- 已报废/已停用资产不计提

### 6.6 资产处置

- 报废：净值归零，凭证分录 `借：固定资产清理 / 累计折旧 / 贷：固定资产`
- 出售：按实际售价入账，差额入「资产处置损益」
- 调拨：变更使用部门，不改变资产价值

### 6.7 业务规则

- 折旧不允许跨月补提，只能从资产启用次月起逐月计提
- 已计提折旧月份不可反操作（需先删除对应折旧凭证，再反计提）
- 资产处置后保留原卡片，状态变更为「已报废」，不可再修改原值
- 当月新增的资产，次月开始计提折旧；当月减少的资产，当月照提

## 十一、与 V1.0 的集成边界

| 边界 | 说明 |
|---|---|
| 客户/供应商/商品/部门/片区/人员 | 引用 V1.0 基础资料，不可在财务模块内修改 |
| 应收/应付 | V1.0 应收应付作为明细账，V2.0 凭证作为总账。两者并行，期末对账 |
| 收付款单 | V1.0 收付款单审核后自动生成凭证分录 |
| 费用单 | V1.0 费用单审核后按费用类型映射科目自动生成凭证 |
| 单据编号规则 | 凭证字号格式放到 V1.0 单据编号规则统一维护 |
| 用户权限 | 凭证审核人需要独立的「凭证审核」权限，区别于制单人 |
| 操作日志 | 凭证的审核、反审核、作废写入 V1.0 操作日志 |
