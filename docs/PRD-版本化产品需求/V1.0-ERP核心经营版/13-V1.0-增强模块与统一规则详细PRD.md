## 一、本次增强范围

### 1.0 通用基础功能补充

V1.0所有数据网格和业务单据必须统一支持以下基础能力，详细页面级规范见 `17-V1.0-通用网格与单据交互规范.md`：

- 数据网格字段展示顺序可拖拽调整。
- 用户退出后自动保存字段顺序，下次进入按该顺序展示。

- 数量、金额、成本金额字段在网格底部显示汇总。

- 所有业务单据录入支持键盘快捷操作。

## 二、统一单据编号规则

### 2.1 功能定位

统一管理所有业务单据编号生成规则，保证单据号可读、唯一、连续可追踪，避免不同模块各自定义导致混乱。

### 2.2 页面入口

`系统管理 → 单据编号规则`

### 2.3 编号组成

标准规则：

```text
单据前缀 + 日期段 + 流水号
```

示例：

```text
SO202606130001
PO202606130001
PI202606130001
```

### 2.4 编号规则字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 规则ID | 是 | 系统生成 |
| 单据类型编码 | 是 | 如 SALES_ORDER、PURCHASE_ORDER |
| 单据类型名称 | 是 | 如销售订单、采购订单 |
| 单据前缀 | 是 | 如 SO、PO、PI |
| 日期格式 | 是 | YYYYMMDD / YYYYMM / YYMMDD |
| 流水号位数 | 是 | 默认4位，可设4-8位 |
| 流水重置周期 | 是 | 按日/按月/按年/永不重置 |
| 是否允许手工改号 | 是 | 默认否 |
| 是否启用 | 是 | 启用/停用 |
| 示例 | 自动 | 根据规则生成示例 |

### 2.6 业务规则

- 单据号全局唯一，同一单据类型内不可重复。
- 已使用过的单据号不可回收。
- 删除草稿单据后，已占用流水号不回退。
- 审核后的单据号不可修改。
- 若允许手工改号，保存时仍需校验唯一性。
- 编号规则修改后仅影响新单据，不影响历史单据。
- 修改编号规则必须记录操作日志。

## 三、显示精度设置

### 3.1 功能定位

系统允许用户自定义单价、数量、金额的页面显示位数，以适配不同行业称重、散货、批发报价场景。

### 3.2 页面入口

`系统管理 → 系统参数 → 显示精度设置`

### 3.3 精度参数

| 参数 | 默认 | 最小 | 最大 | 说明 |
|---|---:|---:|---:|---|
| 数量显示位数 | 2 | 当前已用最小值 | 6 | 页面、导出、打印数量小数位 |
| 单价显示位数 | 2 | 当前已用最小值 | 6 | 销售价、采购价、成本价展示位数 |
| 金额显示位数 | 2 | 当前已用最小值 | 4 | 金额展示位数 |
| 成本单价显示位数 | 4 | 当前已用最小值 | 8 | 成本单价展示位数 |
| 税率显示位数 | 2 | 当前已用最小值 | 4 | 税率展示位数 |

### 3.4 “只可往大改，不能改小”规则

#### 规则说明

用户可以把显示位数调大，例如金额从2位改为4位；但不能调小，例如金额从4位改回2位。

#### 原因

- 防止历史数据展示精度降低导致金额、数量看似不一致。
- 防止导出、打印、报表四舍五入后引发对账争议。
- 防止成本单价精度降低影响毛利和库存金额理解。

### 3.5 保存校验

| 场景 | 处理 |
|---|---|
| 新值 > 当前值 | 允许保存 |
| 新值 = 当前值 | 允许保存 |
| 新值 < 当前值 | 阻止保存，提示“显示位数只可增加，不可减少” |
| 超过最大值 | 阻止保存 |
| 非整数 | 阻止保存 |

### 3.6 展示规则

- 数据库存储精度不因显示位数变化而降低。
- 页面展示按配置位数补零或四舍五入。
- 计算仍使用数据库原始精度。
- 打印、导出、报表使用同一显示精度。
- 明细金额合计时，以原始金额计算，展示时按精度显示。

## 四、采购费用管理

### 4.1 功能定位

采购费用管理用于记录采购过程中发生的运费、装卸费、保险费、港杂费等费用，并支持按金额、数量、重量等方式分摊到采购入库单，从而重算入库商品成本。

### 4.2 页面入口

`采购管理 → 采购费用单`

### 4.3 业务流程

```text
新建采购费用单
    │
    ├─ 选择费用类型、供应商/往来单位、费用金额
    │
    ├─ 选择分摊对象：一张或多张采购入库单
    │
    ├─ 选择分摊方式：按金额/按数量/按重量/手工分摊
    │
    ├─ 预览分摊结果
    │
    └─ 审核
        ├─ 生成费用应付或直接费用记录
        ├─ 将费用分摊到采购入库明细
        ├─ 重算入库成本
        └─ 更新库存成本和后续成本链
```

### 4.4 查询条件

| 条件 | 控件 | 说明 |
|---|---|---|
| 费用日期 | 日期范围 | 默认本月 |
| 费用单号 | 输入框 | 精确/模糊 |
| 费用类型 | 下拉树 | 运费、装卸费等 |
| 供应商 | 搜索选择 | 收款方为供应商时 |
| 往来单位 | 搜索选择 | 收款方为其他单位时 |
| 分摊状态 | 下拉 | 未分摊/已分摊/部分分摊 |
| 审核状态 | 下拉 | 草稿/待审核/已审核/已关闭 |
| 采购入库单号 | 输入框 | 反查费用 |

### 4.5 列表字段

| 字段 | 说明 |
|---|---|
| 费用单号 | 点击进入详情 |
| 费用日期 | 业务日期 |
| 费用类型 | 运费/装卸费等 |
| 收款对象类型 | 供应商/往来单位/员工/其他 |
| 收款对象 | 供应商或往来单位名称 |
| 费用金额 | 费用总额 |
| 已分摊金额 | 已分摊到入库单金额 |
| 未分摊金额 | 剩余未分摊金额 |
| 分摊方式 | 按金额/数量/重量/手工 |
| 状态 | 草稿/待审核/已审核/已关闭 |
| 应付生成 | 是/否 |
| 操作 | 查看、编辑、审核、反审核、分摊明细、日志 |

### 4.6 主表字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 费用单号 | 是 | 系统编号PE |
| 费用日期 | 是 | 默认当天 |
| 费用类型 | 是 | 引用费用类型 |
| 收款对象类型 | 是 | SUPPLIER/COUNTERPARTY/EMPLOYEE/OTHER |
| 供应商 | 条件必填 | 对象类型为供应商时必填 |
| 往来单位 | 条件必填 | 对象类型为往来单位时必填 |
| 费用金额 | 是 | 大于0 |
| 税率 | 否 | 有发票时使用 |
| 税额 | 否 | 自动计算 |
| 不含税金额 | 否 | 自动计算 |
| 分摊方式 | 是 | BY_AMOUNT/BY_QTY/BY_WEIGHT/MANUAL |
| 是否生成应付 | 是 | 默认是 |
| 付款方式 | 否 | 已支付时可记录 |
| 资金账户 | 条件必填 | 直接支付时必填 |
| 状态 | 是 | 草稿/待审核/已审核 |
| 备注 | 否 | 500字以内 |

### 4.7 分摊对象字段

| 字段 | 说明 |
|---|---|
| 采购入库单 | 被分摊的入库单 |
| 入库日期 | 入库日期 |
| 供应商 | 来源供应商 |
| 入库金额 | 商品入库金额 |
| 入库数量 | 基本单位数量或大单位数量 |
| 入库重量 | 商品重量汇总 |
| 分摊比例 | 系统计算 |
| 分摊金额 | 本次分摊金额 |

### 4.8 分摊方式

#### 按金额分摊

```text
某入库单分摊金额 = 该入库单商品金额 / 选中入库单商品总金额 × 费用金额
```

#### 按数量分摊

```text
某入库单分摊金额 = 该入库单入库数量 / 选中入库单总数量 × 费用金额
```

#### 按重量分摊

```text
某入库单分摊金额 = 该入库单商品重量 / 选中入库单总重量 × 费用金额
```

#### 手工分摊

用户手工录入每张入库单或每行商品的分摊金额，系统校验合计等于费用金额。

### 4.9 审核影响

采购费用单审核后：

1. 生成采购费用记录。
2. 如果勾选生成应付，则生成供应商/往来单位应付。
3. 分摊金额写入采购入库单和入库明细。
4. 重算采购入库成本：

```text
入库最终成本金额 = 原入库商品金额 + 分摊费用金额
入库最终成本单价 = 入库最终成本金额 / 入库数量
```

5. 若该入库单后续已有出库，需触发成本重算链或生成成本调整差异。
6. 写入操作日志。

### 4.10 业务规则

- 已审核费用单不可直接修改，需反审核。
- 已参与付款核销的费用应付不可反审核。
- 已结账期间的费用单不可反审核。
- 分摊金额合计必须等于费用金额。
- 费用单可先保存不分摊，后续再分摊，但未分摊费用不影响成本。
- 同一采购入库单可被多张采购费用单分摊。

## 五、采购发票管理

### 5.1 功能定位

采购发票管理用于登记供应商开具的进项发票，支持与采购收货单、应付账款进行勾稽，跟踪未开票、部分开票、已开票状态。

### 5.2 页面入口

`采购管理 → 采购发票`  
或 `财务管理 → 发票管理 → 采购发票`

### 5.3 业务流程

```text
收到供应商发票
    │
    ├─ 新建采购发票
    │
    ├─ 选择供应商
    │
    ├─ 录入发票号码、发票代码、开票日期、金额、税额
    │
    ├─ 选择采购收货单/应付记录进行勾稽
    │
    └─ 审核
        ├─ 更新采购收货单开票状态
        ├─ 更新应付开票状态
        └─ 进入发票台账
```

### 5.4 查询条件

发票日期、发票号码、供应商、勾稽状态、认证状态、金额区间、采购收货单号、应付单号。

### 5.5 主表字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 采购发票单号 | 是 | 系统编号PINV |
| 发票代码 | 否 | 税票代码 |
| 发票号码 | 是 | 发票号码，同供应商内不可重复 |
| 发票类型 | 是 | 专票/普票/电子发票/其他 |
| 供应商 | 是 | 开票供应商 |
| 开票日期 | 是 | 发票日期 |
| 收票日期 | 否 | 实际收到日期 |
| 不含税金额 | 是 | 发票不含税金额 |
| 税额 | 是 | 发票税额 |
| 含税金额 | 是 | 不含税+税额 |
| 认证状态 | 是 | 未认证/已认证/无需认证 |
| 勾稽状态 | 是 | 未勾稽/部分勾稽/已勾稽 |
| 状态 | 是 | 草稿/已审核/已作废 |
| 附件 | 否 | 发票图片/PDF |

### 5.6 勾稽明细字段

| 字段 | 说明 |
|---|---|
| 采购收货单号 | 被勾稽单据 |
| 应付单号 | 对应应付 |
| 收货金额 | 可勾稽金额 |
| 已勾稽金额 | 历史已勾稽 |
| 本次勾稽金额 | 本次关联金额 |
| 本次勾稽税额 | 本次关联税额 |
| 差异金额 | 发票金额与单据金额差异 |

### 5.7 业务规则

- 发票号码在同一供应商下不可重复。
- 发票含税金额必须等于不含税金额+税额。
- 本次勾稽金额不可超过收货单未勾稽金额。
- 允许一张发票勾稽多张采购收货单。
- 允许一张采购收货单被多张发票部分勾稽。
- 已审核并勾稽的发票作废时，应回退收货单和应付的开票状态。
- 采购发票不直接影响库存成本，除非与采购费用单或改价流程关联。

## 六、成本调整单

### 6.1 功能定位

成本调整单用于在受控场景下调整库存成本金额或成本单价，例如历史成本错误、盘点成本差异、费用补录差异、财务调整等。

### 6.2 页面入口

`库存管理 → 成本调整单`  
或 `财务管理 → 成本调整单`

### 6.3 适用场景

| 场景 | 说明 |
|---|---|
| 历史成本错误 | 由于入库价格错误导致成本异常 |
| 采购费用补录 | 费用无法准确追溯分摊时做成本调整 |
| 盘点成本修正 | 盘盈商品成本需修正 |
| 财务调整 | 财务要求调整库存金额 |
| 系统初始化 | 初始库存成本修正 |

### 6.4 主表字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 成本调整单号 | 是 | 系统编号CA |
| 调整日期 | 是 | 默认当天 |
| 仓库 | 是 | 调整库存所在仓库 |

- 成本字段受权限控制。

## 十二、业务单据明细成本字段统一规则

### 12.1 适用范围

所有影响库存或与商品明细相关的业务单据明细，都必须包含成本单价和成本金额字段，至少用于审计、报表、毛利和库存核算。

### 12.2 必须包含成本字段的单据

| 单据 | 成本单价来源 | 成本金额 |
|---|---|---|
| 采购订单 | 参考成本/最近成本，仅参考 | 数量×参考成本 |
| 采购入库单 | 入库前/入库后成本 | 入库数量×成本单价 |
| 采购收货单 | 来源采购入库成本 | 收货数量×成本单价 |
| 采购退货单 | 当前成本或原入库成本 | 退货数量×成本单价 |
| 销售订单 | 当前成本预估 | 销售数量×预估成本 |
| 销售出库单 | 出库时当前成本 | 出库数量×成本单价 |
| 销售收货单 | 来源出库成本 | 签收数量×成本单价 |
| 销售退货单 | 原出库成本或当前成本 | 退货数量×成本单价 |
| 其他入库单 | 用户录入或系统带出 | 入库数量×成本单价 |
| 其他出库单 | 当前成本 | 出库数量×成本单价 |
| 报损单 | 当前成本 | 报损数量×成本单价 |
| 成本调整单 | 调整前/后成本 | 差异金额 |

### 12.3 展示权限

- 成本单价、成本金额受字段权限控制。
- 无成本权限用户不显示成本字段，也不导出成本字段。
- 系统内部仍必须存储和计算成本。

### 12.4 计算规则

- 销售类单据在订单阶段显示预估成本，出库后以实际出库成本为准。
- 采购入库审核后写入入库前成本、入库后成本。
- 其他出库和报损取审核时当前成本。
- 反审核时生成反向成本流水。


#### 支持修改字段

| 字段 | 是否支持 | 说明 |
|---|:---:|---|
| 客户名称 | 是 | 需校验重复 |
| 客户类型 | 是 | 字典值必须存在 |
| 客户等级 | 是 | 影响价格，修改后新订单生效 |
| 片区 | 是 | 必须为末级片区 |
| 线路 | 是 | 线路必须正常 |
| 业务员 | 是 | 人员必须为业务员 |
| 联系人/电话 | 是 | 电话格式校验 |
| 地址 | 是 | 可更新默认地址 |
| 结算方式 | 是 | 修改后新应收生效 |
| 信用额度 | 是 | 不可小于0 |
| 账期天数 | 是 | 按账期类型校验 |
| 状态 | 是 | 正常/停用/冻结 |

### 13.3 客户批量修改

支持列表勾选客户后批量修改：客户等级、客户类型、片区、线路、业务员、结算方式、账期天数、信用额度、状态。

规则：

- 批量修改前显示影响客户数量。
- 高风险字段如信用额度、结算方式需二次确认。
- 修改状态为冻结/停用时，提示未完成订单和应收余额。
- 批量修改写操作日志。

### 13.4 供应商导入修改

#### 支持修改字段

| 字段 | 是否支持 | 说明 |
|---|:---:|---|
| 供应商名称 | 是 | 校验重复 |
| 联系人/电话 | 是 | 联系信息 |
| 地址 | 是 | 地址 |
| 到货天数 | 是 | 新采购订单生效 |
| 结算方式 | 是 | 新应付生效 |
| 账期天数 | 是 | 预计付款日计算 |
| 默认采购员 | 是 | 人员必须为采购员 |
| 银行账户 | 是 | 可更新默认账户 |
| 发票信息 | 是 | 可更新默认发票信息 |
| 状态 | 是 | 正常/停用 |

### 13.5 供应商批量修改

支持批量修改：结算方式、账期天数、默认采购员、状态、到货天数、供应商分类。

### 13.6 导入校验规则

- 匹配不到客户/供应商时，该行失败。
- 字典值不存在时，该行失败。
- 业务员/采购员不存在或角色不匹配时，该行失败。
- 导入修改不允许修改主键ID。
- 支持部分成功，失败文件标注原因。
