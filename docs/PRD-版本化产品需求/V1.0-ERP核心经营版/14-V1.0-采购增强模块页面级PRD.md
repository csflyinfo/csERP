## 一、采购费用单页面

### 1.1 页面入口

`采购管理 → 采购费用单`

### 1.2 页面定位

采购费用单用于记录采购过程中发生的附加费用，并支持把费用分摊到采购入库单，从而重算商品入库成本。典型费用包括运费、装卸费、保险费、搬运费、港杂费等。

### 1.3 页面结构

```text
采购费用单列表
├─ 查询条件
├─ 费用单列表
├─ 批量操作：导出、审核、反审核
└─ 行操作：查看、编辑、审核、反审核、分摊明细、日志

采购费用单编辑页
├─ 基本信息
├─ 费用明细
├─ 分摊对象
├─ 分摊预览
├─ 应付/付款信息
└─ 附件与备注
```

#### 可选入库单字段

| 字段 | 说明 |

| 已分摊费用 | 历史分摊金额 |
| 本次可分摊 | 是否可选 |

### 3.4 分摊预览

系统根据分摊方式实时计算分摊结果。

| 字段 | 说明 |
|---|---|
| 采购入库单号 | 被分摊单据 |
| 商品 | 分摊到商品行时显示 |
| 分摊基数 | 金额/数量/重量 |
| 分摊比例 | 当前行基数/总基数 |
| 本次分摊金额 | 费用金额×比例 |
| 分摊后入库成本金额 | 原入库金额+分摊费用 |
| 分摊后成本单价 | 分摊后成本金额/入库数量 |

### 3.5 手工分摊规则

- 用户可手工修改每个分摊对象的本次分摊金额。
- 系统底部显示：费用金额、已分摊金额、未分摊金额。
- 未分摊金额必须为0才允许审核。
- 手工分摊金额不可小于0。

### 3.6 审核处理

审核时系统执行：

```text
1. 校验费用单状态
2. 校验费用金额 = 明细金额合计
3. 校验分摊金额 = 费用金额
4. 写入采购费用分摊记录
5. 更新采购入库单分摊费用金额
6. 重算采购入库成本
7. 更新库存成本
8. 如生成应付，则生成供应商/往来单位应付
9. 如已付款，则生成付款单或资金流水
10. 记录操作日志
```

### 3.7 反审核处理

反审核前校验：

- 未生成已核销应付。
- 未参与已结账期间。
- 未被后续成本调整锁定。

反审核后：

- 回退分摊金额。
- 回退成本影响或生成反向成本调整。
- 作废对应未核销应付。
- 记录操作日志。

## 四、采购费用单异常场景

| 场景 | 系统处理 |
|---|---|
| 未选择费用类型 | 阻止保存，提示费用类型必填 |
| 费用金额为0 | 阻止保存 |
| 收款对象类型为供应商但未选供应商 | 阻止保存 |
| 分摊金额不等于费用金额 | 阻止审核 |
| 按重量分摊但商品无重量 | 提示无法按重量分摊，可改按金额/数量 |
| 入库单已结账 | 不允许分摊 |
| 应付已核销后反审核 | 阻止反审核 |

## 七、采购发票编辑页

### 7.1 发票基本信息

| 字段 | 必填 | 规则 |
|---|:---:|---|
| 采购发票单号 | 是 | 系统生成PINV |
| 发票代码 | 否 | 按发票录入 |
| 发票号码 | 是 | 同供应商不可重复 |
| 发票类型 | 是 | 专票/普票/电子发票 |
| 供应商 | 是 | 正常供应商 |
| 开票日期 | 是 | 不可晚于当前日期太多，按参数控制 |
| 收票日期 | 否 | 默认当天 |
| 不含税金额 | 是 | >=0 |
| 税率 | 否 | 默认税率 |
| 税额 | 是 | >=0 |
| 含税金额 | 是 | 不含税+税额 |
| 认证状态 | 是 | 未认证/已认证/无需认证 |
| 附件 | 否 | 发票图片/PDF |
| 备注 | 否 | 说明 |

### 7.2 勾稽对象选择

可选择同供应商下未完全开票的采购收货单或应付单。

字段：采购收货单号、应付单号、收货日期、收货金额、已开票金额、未开票金额、本次勾稽金额、本次税额。

### 7.3 勾稽规则

- 本次勾稽金额不可超过发票未勾稽金额。
- 本次勾稽金额不可超过收货单未开票金额。
- 可一张发票勾稽多张采购收货单。
- 可一张采购收货单被多张发票分次勾稽。
- 金额差异允许保存但需提示，并生成差异说明。

### 7.4 审核处理

审核后：

1. 锁定发票基本信息。
2. 写入发票勾稽记录。
3. 更新采购收货单开票状态。
4. 更新应付单开票状态。
5. 记录操作日志。

### 7.5 作废处理

作废前校验：

- 发票未进入不可作废状态。
- 若已勾稽，需要回退勾稽状态。

作废后：

- 发票状态变已作废。
- 释放采购收货单/应付未开票金额。
- 记录作废原因和日志。

## 八、采购明细成本字段补充

### 8.1 采购订单明细

采购订单明细增加预估成本字段：

| 字段 | 说明 |
|---|---|
| 成本单价 | 商品当前成本或最近采购成本，仅参考 |
| 成本金额 | 采购数量×成本单价 |

### 8.2 采购入库明细

采购入库明细必须包含：

| 字段 | 说明 |
|---|---|
| 入库前成本单价 | 审核前库存成本 |
| 入库后成本单价 | 审核后移动加权成本 |
| 成本金额 | 入库数量×入库后成本 |
| 分摊费用金额 | 采购费用分摊金额 |
| 分摊后成本金额 | 原入库金额+分摊费用 |

### 8.3 采购收货明细

采购收货明细继承采购入库成本结果，用于应付和成本追溯。
