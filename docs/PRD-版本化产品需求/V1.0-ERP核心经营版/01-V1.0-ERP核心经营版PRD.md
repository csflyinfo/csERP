## 一、版本目标

### 1.1 产品目标

V1.0目标是让商贸经销企业完成最基础、最高频、最关键的日常经营管理：

```text
建档 → 采购进货 → 库存入账 → 销售开单 → 出库扣账 → 客户签收/确认 → 应收 → 收款核销
                                      │
                                      └→ 采购收货 → 应付 → 付款核销
```

V1.0不是“所有功能首版”，而是“可真实上线使用的经营底座”。

### 1.2 业务价值

| 用户 | 价值 |
|---|---|
| 老板 | 能看销售、库存、欠款、利润、资金，知道企业经营状况 |
| 内勤/业务员 | 能快速开单、查库存、查客户价格和欠款 |
| 采购员 | 能按需求向供应商下单，到货后形成库存和应付 |
| 仓库人员 | 能基于采购/销售单完成简化入库、出库 |
| 财务 | 能管理应收、应付、收款、付款、核销和账期 |

### 1.3 V1.0成功标准

1. 一个客户从下单到收款可以闭环。
2. 一个供应商从采购到付款可以闭环。
3. 库存余额、库存流水和业务单据可以互相追溯。
4. 应收应付金额与销售/采购单据来源一致。
5. 老板能通过基础报表看到销售、库存、应收应付、资金。
6. 采购费用、采购发票、费用单、往来单位应收应付、其他出入库、报损、成本调整可以纳入V1.0主流程。
7. 所有影响库存的业务单据明细必须记录成本单价和成本金额，具备成本追溯能力。
8. 单据编号、数量/单价/金额显示精度有统一配置，避免各模块口径不一致。
9. 所有数据网格支持字段顺序拖拽、字段隐藏、字段排序、底部数量/金额汇总，并按用户自动保存。
10. 所有业务单据支持导出主单或明细详情，导出字段遵循字段权限和用户字段设置。
11. 所有业务单据录入支持键盘快捷操作，满足高频录单场景。

## 二、角色与权限

### 2.1 角色清单

| 角色 | 主要工作 | 关键权限 |
|---|---|---|
| 系统管理员 | 初始化系统、用户、权限、参数 | 全部系统管理权限 |
| 老板/管理层 | 看经营数据、审批高风险操作 | 报表、看板、审批、敏感金额字段 |
| 销售内勤 | 电话开单、订单跟进、客户查询 | 客户、销售订单、库存查询、收款登记 |
| 业务员 | 管理客户、代客下单、催收 | 负责客户数据、销售订单、应收查看 |
| 采购员 | 采购下单、到货跟进 | 供应商、采购订单、采购入库、采购报表 |
| 仓库员 | 入库、出库、盘点简化操作 | 库存、采购入库、销售出库 |
| 财务 | 应收应付、收付款、核销 | 财务全部、资金账户、发票基础信息 |

### 2.2 权限规则

- 菜单权限控制模块入口。
- 功能权限控制新增、修改、删除、审核、反审核、导入、导出、打印。
- 数据权限支持按仓库、客户、业务员、供应商、货主过滤。
- 字段权限控制成本、毛利、采购价、客户欠款、供应商余额。
- 高风险动作，如低价销售、超信用审核、反核销、成本调整，必须具备专项授权或审批。

## 三、系统管理

### 3.1 权限组管理

#### 功能定位

权限组是权限模板。管理员预先配置销售组、采购组、仓库组、财务组、老板组等，创建用户时引用。

#### 页面入口

`系统管理 → 权限组管理`

#### 页面布局

```text
左侧：权限组列表
中间：模块权限树
右侧：功能权限 + 数据权限 + 字段权限
底部：保存 / 复制权限组 / 权限对比 / 导出
```

#### 字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 权限组编码 | 是 | 唯一，如 SALES、PURCHASE、FINANCE |
| 权限组名称 | 是 | 中文名称 |
| 是否系统内置 | 否 | 内置组不可删除 |
| 状态 | 是 | 正常/停用 |
| 备注 | 否 | 权限用途说明 |

#### 业务规则

- 权限组编码不可重复。
- 被用户引用的权限组不可删除。
- 取消模块权限后，该模块功能权限自动取消。
- 字段权限独立控制，即使能进入销售订单，也可隐藏毛利和成本字段。

### 3.2 用户管理

#### 页面入口

`系统管理 → 用户管理`

#### 功能

| 功能 | 说明 |
|---|---|
| 新建用户 | 绑定人员、手机号、权限组、数据范围 |
| 修改用户 | 修改资料、权限、状态 |
| 停用/启用 | 停用后不可登录 |
| 重置密码 | 重置为默认密码或发送短信 |
| 解锁 | 登录失败锁定后解锁 |
| 导入/导出 | 批量维护用户 |

#### 核心字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 登录账号 | 是 | 唯一 |
| 用户名称 | 是 | 页面显示名称 |
| 绑定人员 | 否 | 关联人员档案 |
| 手机号 | 是 | 登录/找回密码/通知 |
| 权限组 | 是 | 默认权限来源 |
| 数据范围 | 否 | 客户、仓库、业务员、货主 |
| 状态 | 是 | 正常/停用/锁定 |

#### 业务规则

- admin账号不可删除、不可停用。
- 一个员工只能绑定一个用户账号。
- 数据范围为空时默认按权限组规则；配置ALL表示不限制。
- 登录失败超过参数次数自动锁定。

### 3.3 系统参数

#### V1.0关键参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 商品编号生成规则 | 分类+流水 | 控制商品编号方式 |
| 销售审核是否自动锁库存 | 是 | 审核后占用可用库存 |
| 销售库存不足是否允许提交 | 否 | 首版建议禁止 |
| 信用额度控制模式 | 提醒 | 可设提醒/阻断/审批 |
| 最低售价控制模式 | 提醒+授权 | 低价需授权或审批 |
| 采购入库后是否自动生成采购收货单 | 是 | 建议自动生成 |
| 采购收货单是否自动审核 | 否 | 首版建议人工确认 |
| 销售出库后是否自动生成销售收货单 | 是 | 简化无TMS阶段流程 |
| 应收生成节点 | 销售收货单审核 | 固定口径 |
| 应付生成节点 | 采购收货单审核 | 固定口径 |
| 导出文件保留天数 | 7天 | 导出中心清理 |
| 数量显示位数 | 2 | 只可增大，不可改小 |
| 单价显示位数 | 2 | 只可增大，不可改小 |
| 金额显示位数 | 2 | 只可增大，不可改小 |
| 成本单价显示位数 | 4 | 只可增大，不可改小 |
| 单据编号规则 | 按单据类型配置 | 前缀+日期+流水 |

### 3.4 操作日志

所有关键操作必须记录：新增、修改、删除、审核、反审核、作废、导入、导出、打印、核销、反核销、登录失败。

字段包括：操作人、模块、动作、单据号、时间、IP、请求参数摘要、操作结果、失败原因。

### 3.5 通用网格与单据交互

V1.0所有列表和单据页面必须支持通用网格与键盘交互规范：

- 网格字段展示顺序可拖拽调整，退出自动保存，下次进入按用户顺序展示。
- 网格字段可设置显示/隐藏，无权限字段不可显示。
- 点击字段名称可进行升序、降序、取消排序。
- 数量、金额、成本金额等字段在网格底部显示合计。
- 所有业务单据支持导出主单、导出明细。
- 所有业务单据录入支持键盘快捷操作。

详细规则见 `17-V1.0-通用网格与单据交互规范.md`。

## 四、基础数据

### 4.1 商品档案

#### 功能定位

商品是采购、销售、库存、财务的核心基础对象。V1.0必须支持多单位、条码、价格、库存上下限、默认供应商、默认仓库和成本信息。

#### 页面入口

`基础资料 → 商品管理`

#### 页面结构

```text
商品列表
 ├─ 查询区：分类、品牌、状态、条码、商品名称、是否可售、是否可采购
 ├─ 列表区：商品编码、名称、规格、单位、分类、品牌、售价、参考进价、状态
 └─ 操作区：新增、编辑、批量编辑、导入、导出、停用、查看库存、历史采购、历史销售

商品详情
 ├─ 基本信息
 ├─ 多单位/条码
 ├─ 价格信息
 ├─ 采购信息
 ├─ 库存预警
 └─ 附件图片
```

#### 主表字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 商品编码 | 是 | 自动生成或手工录入，唯一 |
| 商品名称 | 是 | 不可重复或按参数控制重复 |
| 规格型号 | 否 | 规格、包装 |
| 商品分类 | 是 | 只能选择末级分类 |
| 品牌 | 否 | 品牌档案 |
| 基本单位 | 是 | 库存底层单位 |
| 条码 | 否 | 支持扫码开单 |
| 商品类型 | 是 | 正常/赠品/耗材/包装辅料 |
| 保质期天数 | 否 | 批次管理和临期预警 |
| 是否可售 | 是 | 否则不可销售开单 |
| 是否可采购 | 是 | 否则不可采购下单 |
| 是否可退 | 是 | 控制退货 |
| 标准售价 | 是 | 销售默认价 |
| 参考进价 | 否 | 采购参考价 |
| 最低销售价 | 否 | 低价控制 |
| 起订量 | 否 | 采购/销售下单校验 |
| 起订倍数 | 否 | 数量倍数校验 |
| 库存上限/下限 | 否 | 预警和补货参考 |
| 默认供应商 | 否 | 采购下单默认 |
| 默认仓库 | 否 | 开单默认仓库 |
| 状态 | 是 | 正常/停用 |

#### 多单位规则

| 单位类型 | 说明 |
|---|---|
| 基本单位 | 库存底层存储单位，如瓶 |
| 中单位 | 可选，如提 |
| 大单位 | 可选，如箱 |

- 每个单位可设置独立条码。
- 换算率必须大于0。
- 库存底层统一换算为基本单位。
- 页面可按业务单位显示。

#### 业务规则

- 有库存的商品不可删除，可停用但需无未完成业务。
- 停用商品不可采购、不可销售，但历史单据保留。
- 商品条码不可与其他商品单位条码重复。
- 低于最低售价时，销售订单必须提示或触发授权。

### 4.2 客户档案

#### 功能定位

客户是销售订单、应收账款、配送地址、价格政策和信用控制的主体。

#### 字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 客户编码 | 是 | 自动生成，唯一 |
| 客户名称 | 是 | 门店/公司名称 |
| 客户类型 | 否 | KA/流通/餐饮/团购等 |
| 客户等级 | 否 | 影响价格组 |
| 所属片区 | 否 | 业务员和报表维度 |
| 配送线路 | 否 | 后续TMS使用 |
| 负责业务员 | 否 | 数据权限和业绩归属 |
| 联系人/电话 | 是 | 联系信息 |
| 默认地址 | 是 | 发货地址 |
| 结算方式 | 是 | 现结/月结/账期 |
| 信用额度 | 否 | 超额控制 |
| 账期类型 | 否 | 固定天数/月结/周结等 |
| 发票抬头/税号 | 否 | 开票信息 |
| 状态 | 是 | 正常/停用/冻结 |

#### 客户账期规则

V1.0支持以下账期：

| 类型 | 说明 | 示例 |
|---|---|---|
| 现结 | 签收当天应收应结 | 到货付款 |
| 固定账期天数 | 签收日 + N天 | 签收后30天付款 |
| 月结固定日 | 每月截账，次月固定日付款 | 每月25日截账，次月10日付款 |
| 周结 | 按周截账，指定星期付款 | 每周日结算，下周三付款 |

#### 业务规则

- 冻结客户不可新建销售订单。
- 超信用额度时按系统参数提醒、阻断或审批。
- 客户地址可维护多条，销售订单必须选择一个收货地址。

### 4.3 供应商档案

供应商字段包括：供应商编码、名称、联系人、电话、地址、到货天数、结算方式、账期、默认采购员、发票信息、银行账户、状态。

业务规则：停用供应商不可新建采购订单；已有关联业务不可删除；供应商到货天数用于自动计算采购预计到货日。

### 4.4 仓库档案

字段包括：仓库编码、仓库名称、仓库类型、库存类型、成本分组、地址、负责人、状态。

成本分组规则：同一成本分组内同商品共享移动加权成本；不同成本分组独立核算。

### 4.5 价格体系

V1.0支持三层价格：

```text
客户专属价 > 客户等级价/价格组价 > 商品标准售价
```

客户专属价字段：客户、商品、单位、价格、生效日期、失效日期、状态。

## 五、采购管理

### 5.1 采购订单

#### 页面入口

`采购管理 → 采购订单`

#### 流程

```text
新建采购订单 → 保存草稿 → 提交/审核 → 形成采购在途 → 采购入库
```

#### 主表字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 采购单号 | 是 | PO+日期+流水 |
| 供应商 | 是 | 供应商档案 |
| 采购员 | 否 | 默认当前采购员 |
| 收货仓库 | 是 | 影响库存和成本分组 |
| 单据日期 | 是 | 默认当天 |
| 预计到货日 | 否 | 单据日期+供应商到货天数 |
| 结算方式 | 是 | 供应商账期 |
| 商品金额 | 是 | 明细汇总 |
| 税额 | 否 | 按税率计算 |
| 应付预估金额 | 是 | 商品金额+税额-折扣 |
| 状态 | 是 | 草稿/待审批/已审批/部分入库/入库完成/已关闭 |
| 备注 | 否 | 说明 |

#### 明细字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 商品 | 是 | 可采购商品 |
| 单位 | 是 | 采购单位 |
| 数量 | 是 | 大于0，校验起订量/倍数 |
| 单价 | 是 | 参考进价/历史价/手工价 |
| 税率 | 否 | 默认商品税率 |
| 金额 | 是 | 数量×单价 |
| 已入库数量 | 否 | 入库回写 |
| 赠品标记 | 否 | 0价赠品不计应付 |

#### 功能

| 功能 | 说明 |
|---|---|
| 新建 | 选择供应商、仓库、商品、数量、价格 |
| 快速添加商品 | 按供应商商品、历史采购商品、分类商品添加 |
| 导入 | Excel导入采购订单 |
| 审核 | 形成采购在途 |
| 反审核 | 未入库时允许 |
| 终止 | 剩余未到货不再采购 |
| 打印 | 打印采购订单 |
| 生成预付款 | 有预付约定时生成付款单草稿 |

#### 业务规则

- 已审核采购订单不可修改明细，需反审核后修改。
- 已入库采购订单不可反审核，只能终止剩余部分。
- 采购数量超过起订倍数规则时提示并要求调整。
- 审核后写入采购在途，入库后扣减在途。

### 5.2 采购入库

#### 页面入口

`采购管理 → 采购入库`

V1.0采用后台简化入库，不要求PDA。

#### 流程

```text
选择已审核采购订单 → 引入未入库商品 → 填实收数量/批次/库位可选 → 保存 → 审核入库
```

#### 审核动作

1. 校验数量、商品、仓库、批次。
2. 增加库存余额。
3. 生成库存流水。
4. 按成本分组计算移动加权成本。
5. 回写采购订单已入库数量。
6. 自动生成采购收货单。
7. 记录操作日志。

#### 业务规则

- 入库数量不可超过订单剩余数量；如需超收，V1.0先不支持或需主管授权。
- 批次商品必须录入生产日期和保质期。
- 已审核入库单不可直接修改，需反审核或做调整。
- 反审核前必须确认采购收货单未审核、未生成应付。

### 5.3 采购收货单与应付

采购收货单由采购入库单审核后自动生成。

```text
采购入库单审核 → 自动生成采购收货单 → 人工审核采购收货单 → 生成应付
```

字段：收货单号、来源入库单、采购订单、供应商、仓库、商品金额、税额、最终金额、状态、应付生成状态。

业务规则：

- 采购收货单审核后生成正式应付。
- 已生成应付后不可直接删除。
- 收货单金额作为供应商对账和付款依据。

### 5.4 采购退货

流程：

```text
新建采购退货申请 → 审核 → 采购退货出库 → 生成采购退货单 → 冲减应付/扣减库存
```

V1.0可简化为后台直接创建采购退货单并审核出库。

业务规则：

- 退货数量不可超过当前可用库存。
- 退货出库按当前成本或原入库成本，按系统参数控制；V1.0建议取当前成本。
- 采购退货审核后生成负向库存流水，并冲减供应商应付。

## 六、销售管理

### 6.1 销售订单/快速开单

#### 页面入口

`销售管理 → 销售订单`  
`销售管理 → 快速开单`

#### 流程

```text
选择客户 → 添加商品 → 价格匹配 → 库存校验 → 信用检查 → 保存（即占用库存）→ 审核 → 出库（释放占用并扣减）
```

#### 主表字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 销售单号 | 是 | SO+日期+流水 |
| 客户 | 是 | 客户档案 |
| 收货地址 | 是 | 客户地址 |
| 业务员 | 否 | 默认客户负责人 |
| 发货仓库 | 是 | 扣减库存仓库 |
| 单据日期 | 是 | 默认当天 |
| 要求送达日 | 否 | 后续TMS使用 |
| 结算方式 | 是 | 客户账期 |
| 商品金额 | 是 | 明细汇总 |
| 折扣金额 | 否 | 整单折扣 |
| 应收预估金额 | 是 | 签收前预估 |
| 收款金额 | 否 | 现结/预收 |
| 状态 | 是 | 草稿/待审核/已审核/已出库/已签收/已完成 |

#### 明细字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 商品 | 是 | 可售商品 |
| 单位 | 是 | 销售单位 |
| 数量 | 是 | 大于0 |
| 原单价 | 是 | 价格匹配结果 |
| 实际单价 | 是 | 可手工改价 |
| 折扣 | 否 | 单行折扣 |
| 金额 | 是 | 数量×实际价 |
| 价格来源 | 是 | 客户价/等级价/标准价/手工价 |
| 是否赠品 | 否 | 赠品单价为0 |
| 已出库数量 | 否 | 出库回写 |
| 已签收数量 | 否 | 收货回写 |

#### 价格匹配

```text
客户专属价（有效期内） → 客户等级对应价格组 → 商品标准售价 → 手工录入
```

#### 信用检查

```text
本次赊销金额 + 未核销应收 + 已审核未签收订单金额 > 信用额度 → 触发控制
```

处理方式：提醒、阻断、审批，按系统参数配置。

#### 库存检查

- 审核时检查可用库存。
- 可用库存不足时，V1.0默认阻断。
- 审核通过后生成库存锁定。

#### 快速开单体验要求

- 支持扫码添加商品。
- 支持客户常购商品快速选择。
- 支持快捷键：F2客户、F3商品、F5保存、F6审核、F7赠品、Ctrl+Enter提交。
- 同商品同单位同价格同销售类型自动合并。
- 同商品不同价格或赠品不合并。

### 6.2 销售出库

V1.0采用后台简化出库，不强制PDA。

流程：

```text
选择已审核销售订单 → 引入待出库商品 → 填实际出库数量 → 审核出库
```

审核动作：

1. 校验订单状态和锁定库存。
2. 扣减实物库存和锁定库存。
3. 生成库存流水。
4. 记录销售出库成本。
5. 回写销售订单出库状态。
6. 自动生成销售收货单（V1.0可视为客户确认收货前的待确认单）。

业务规则：

- 出库数量不可超过订单未出库数量。
- 出库时取当前成本单价，写入出库流水。
- 出库不生成正式应收，仅进入待签收/待确认状态。

### 6.3 销售收货单与应收

V1.0没有司机APP时，可由后台内勤确认客户收货。

流程：

```text
销售出库 → 自动生成销售收货单 → 后台确认签收数量/日期/金额 → 审核 → 生成应收
```

功能：

| 功能 | 说明 |
|---|---|
| 确认签收 | 录入实际签收数量 |
| 修改签收单价 | 客户现场议价时调整，需原因 |
| 调整签收日期 | 影响账期和账龄 |
| 部分签收 | 未签收部分进入拒收/退货处理 |
| 审核 | 生成正式应收 |

业务规则：

- 应收只由销售收货单审核生成。
- 签收数量可以小于出库数量。
- 签收金额变化后，应收按最终签收金额生成。

### 6.4 销售退货

流程：

```text
新建销售退货申请 → 审核 → 退货入库 → 销售退货单审核 → 库存增加/冲减应收
```

V1.0可简化为后台直接创建销售退货单。

业务规则：

- 必须选择原销售单或客户。
- 可退数量 = 原签收数量 - 已退数量。
- 退货审核后增加库存，并生成负向应收或冲减应收。
- 已收款场景下，退货金额可转预收款或生成退款申请。

## 七、库存管理

### 7.1 库存余额

页面入口：`库存管理 → 库存余额`

查询条件：货主、仓库、分类、品牌、商品、库存状态、是否仅看有库存。

列表字段：商品、仓库、实物库存、锁定库存、冻结库存、可用库存、采购在途、成本单价、库存金额。

业务规则：库存余额不可手工直接编辑，必须由业务单据、库存调整或盘点产生。

### 7.2 库存锁定

锁定场景：销售订单审核。释放场景：销售出库、订单取消、订单关闭。

字段：来源单据、商品、仓库、锁定数量、状态、创建时间、释放时间。

### 7.3 库存流水

所有库存变化必须生成流水。

字段：流水号、来源单据、商品、仓库、批次、方向、数量、成本单价、金额、变动后结存、操作人、发生时间。

规则：流水不可删除；反审核生成反向流水，不删除原流水。

### 7.4 成本计算

采购入库成本：

```text
新成本单价 = (现有库存金额 + 本次入库金额) / (现有库存数量 + 本次入库数量)
```

销售出库成本：取出库时成本。

### 7.5 库存调整

V1.0支持简单库存调整单，用于初始化、差异纠正。

流程：

```text
新建调整单 → 审批/审核 → 生成库存流水 → 更新库存余额
```

调整必须填写原因，且需要权限。

## 八、财务管理

### 8.1 应收管理

应收来源：销售收货单审核。

页面：应收明细、应收汇总、账龄分析。

字段：应收单号、来源单据、客户、应收金额、已收金额、未收金额、预计结款日、最近结款日、核销状态、逾期天数。

预计结款日按客户账期规则计算。

### 8.2 应付管理

应付来源：采购收货单审核、费用单审核。

字段：应付单号、来源单据、供应商、应付金额、已付金额、未付金额、预计付款日、核销状态、逾期状态。

### 8.3 收款管理

收款类型：销售收款、预收款、其他收入。

流程：

```text
新建收款单 → 选择客户/收款方式/资金账户 → 审核 → 增加资金账户 → 核销应收
```

支持一张收款单核销多张应收，也支持一张应收被多次收款核销。

### 8.4 付款管理

付款类型：采购付款、预付款、费用付款。

流程：

```text
新建付款单 → 选择供应商/付款方式/资金账户 → 审核 → 减少资金账户 → 核销应付
```

### 8.5 核销规则

- 核销金额不可超过收款/付款未核销余额。
- 核销金额不可超过应收/应付未结余额。
- 核销后更新单据状态：未核销、部分核销、已核销。
- 反核销必须有权限，且未结账。

### 8.6 资金账户

资金账户包括现金、银行卡、线上账户。收款审核增加余额；付款审核减少余额。所有资金变动生成资金流水。

### 8.7 应收结算与应付结算

V1.0除客户/供应商对账流程外，必须提供快速结算入口：

- 应收结算：支持客户、往来单位，快速选择未核销应收，生成收款单并核销。
- 应付结算：支持供应商、往来单位，快速选择未核销应付，生成付款单并核销。
- 结算单支持打印，作为收付款确认凭据。
- 折让金额必须有权限并填写原因。

### 8.8 费用单与往来单位

V1.0支持费用收入和费用支出：

- 费用支出可生成应付或直接付款。
- 费用收入可生成应收或直接收款。
- 费用对象支持客户、供应商、往来单位、员工和其他对象。
- 往来单位可独立形成应收、应付、收款、付款和结算。

### 8.9 采购费用与采购发票

- 采购费用用于记录采购运费、装卸费等，可分摊到采购入库单并重算成本。
- 采购发票用于供应商进项发票登记，可与采购收货单/应付进行勾稽。

### 8.10 其他出入库、报损与成本调整

- 其他入库用于不记往来的库存增加，如期初、样品、赠品入库。
- 其他出库用于不记往来的库存减少，如内部领用、样品出库。
- 报损单用于过期、破损、不可售商品出库报损。
- 成本调整单用于受控调整库存成本，不改变库存数量。
