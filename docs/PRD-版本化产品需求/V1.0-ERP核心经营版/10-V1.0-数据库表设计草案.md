# V1.0 ERP核心经营版 — 数据库表设计草案

> 文档版本：v1.0  
> 编写日期：2026-06-13  
> 适用版本：V1.0 ERP核心经营版  
> 文档定位：面向后端开发、数据库设计、接口设计、测试造数的业务数据模型草案  
> 说明：本文为产品级数据库草案，不替代最终数据库DDL；最终字段类型、索引、分区、审计字段由技术设计阶段确认。

## 一、全局设计约定

### 1.1 主键与编码

| 项 | 约定 |
|---|---|
| 主键 | 统一使用 `varchar(32)`，建议雪花ID/UUID去横线 |
| 业务单号 | 独立字段，如 `order_no`、`bill_no`，不可作为主键 |
| 编码 | 商品、客户、供应商、仓库等使用独立业务编码 |
| 外键 | 产品文档中标注逻辑外键，数据库是否强外键由技术架构决定 |

### 1.2 金额、数量、时间

| 类型 | 建议类型 | 说明 |
|---|---|---|
| 金额 | decimal(18,2) | 订单金额、应收应付、收付款 |
| 单价/成本 | decimal(18,6) | 成本单价、换算后单价 |
| 数量 | decimal(18,4) | 支持称重和小数数量 |
| 比率 | decimal(8,4) | 税率、折扣率、毛利率 |
| 日期 | date | 单据日期、业务日期 |
| 时间 | datetime / timestamp | 创建、审核、操作时间 |

### 1.3 通用审计字段

所有业务表建议统一包含：

| 字段 | 说明 |
|---|---|
| created_by | 创建人ID |
| created_name | 创建人名称，冗余 |
| created_at | 创建时间 |
| updated_by | 修改人ID |
| updated_name | 修改人名称，冗余 |
| updated_at | 修改时间 |
| deleted | 逻辑删除标记，0否1是 |
| tenant_id | 租户ID，SaaS化预留 |
| owner_id | 货主ID，业务需要时使用 |
| version | 乐观锁版本号，关键单据建议使用 |

### 1.4 状态字段约定

状态字段统一使用字符串枚举，避免纯数字难读。

示例：

```text
DRAFT / PENDING_AUDIT / AUDITED / PARTIAL_IN / COMPLETED / CLOSED / CANCELLED
```

### 1.5 金额冗余原则

业务单据主表允许冗余汇总金额，明细表保留行金额。审核时应校验：

```text
主表金额 = 明细金额汇总
```

### 1.6 单据明细单位、仓库、成本字段统一要求

所有含商品明细且可能影响库存、毛利、成本追溯的业务单据明细表必须包含：

| 字段 | 建议类型 | 说明 |
|---|---|---|
| warehouse_id | varchar(32) | 明细仓库ID，调拨单除外 |
| warehouse_name | varchar(100) | 明细仓库名称，调拨单除外 |
| business_unit_id | varchar(32) | 业务开单单位ID |
| business_unit_name | varchar(50) | 业务开单单位名称，如箱、瓶、包 |
| business_qty | decimal(18,4) | 开单数量，用户录入 |
| conversion_rate | decimal(18,6) | 业务单位到基本单位换算率 |
| base_unit_id | varchar(32) | 商品基本单位ID |
| base_unit_name | varchar(50) | 商品基本单位名称 |
| base_qty | decimal(18,4) | 基本单位数量 = 开单数量 × 换算率 |
| cost_price | decimal(18,6) | 基本单位成本单价 |
| cost_amount | decimal(18,2) | 成本金额 = 基本单位数量 × 基本单位成本单价 |

适用单据包括：采购订单、采购入库、采购收货、采购退货、销售订单、销售出库、销售收货、销售退货、其他入库、其他出库、报损单、库存调整单、成本调整单。调拨单由单据头维护调出/调入仓，明细记录业务单位、开单数量、换算率、基本单位数量。

### 1.7 显示精度配置

系统存储精度不随展示设置降低；用户可调整数量、单价、金额显示位数，但只可增大，不可改小。建议增加精度配置表或使用系统参数表维护。

## 十、后续技术设计需确认事项

1. 是否强制数据库外键。
2. 单据号生成方案。
3. 乐观锁和并发控制方案。
4. 库存扣减是否使用数据库行锁、Redis锁或库存服务统一扣减。
5. 成本重算是否异步化。
6. 应收应付是否支持红字单据独立表或同表负数。
7. 导入导出文件存储位置。
8. 审计字段是否统一由框架自动填充。
9. 多租户字段是否V1.0启用。
