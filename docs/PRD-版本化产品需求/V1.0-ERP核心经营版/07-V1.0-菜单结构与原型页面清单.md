## 一、设计原则

### 1.1 菜单设计原则

1. **高频优先**：销售开单、采购入库、库存查询、应收应付放在一级菜单显著位置。
2. **业务闭环分组**：按“基础资料、采购、销售、库存、财务、报表、系统”组织。
3. **少层级**：V1.0最多三级菜单，避免深层级找不到入口。
4. **角色可裁剪**：不同角色登录后只显示有权限菜单。
5. **单据列表统一交互**：所有业务单据保持统一的查询、列表、按钮、状态、操作日志设计。

### 1.2 页面设计标准

所有V1.0页面必须遵循 `17-V1.0-通用网格与单据交互规范.md`，包括：网格字段拖拽排序、字段显示/隐藏、点击表头排序、数量/金额底部汇总、主单/明细导出、单据录入快捷键。

所有V1.0页面应按以下结构设计（参考竞品ERP后台布局）：

```text
ERP后台
├─ 左侧一级图标导航
│  ├─ 首页
│  ├─ 采购
│  ├─ 销售
│  ├─ 仓配/库存
│  ├─ 营销
│  ├─ 管理
│  ├─ 财务
│  ├─ 报表
│  ├─ 档案
│  └─ 设置
├─ 二级模块树 / 业务树
│  ├─ 当前一级菜单下的模块入口
│  └─ 树状资料页面的分类树/片区树/费用类型树等
└─ 内容工作区
   ├─ 多页签：可同时打开多个模块并切换
   ├─ 查询筛选区：紧凑横向排列，不使用大卡片外框
   ├─ 工具栏：新建、删除、导入、导出、批量启停、搜索、重置
   ├─ 数据表格：字段必须按各模块PRD展示，支持字段设置、排序、分页
   └─ 详情/弹窗/抽屉/独立页
```

新建/编辑承载规则：

- 简单资料：小弹窗，字段少，字段竖向排列。
- 中等资料：右侧抽屉，保留列表上下文。
- 复杂档案/业务单据：独立页面或大窗口，支持单据头、明细、汇总、附件、日志。
- 树状资料：左树右表，新建时先确定上级节点。

### 1.3 单据页面统一按钮

所有业务单据列表导出按钮统一提供“导出主单”和“导出明细”；如数据量大，则进入导出中心异步生成。所有业务单据录入页必须支持键盘快捷操作。

| 按钮 | 适用状态 | 说明 |
|---|---|---|
| 新增 | 列表页 | 新建单据 |
| 保存草稿 | 编辑页 | 保存但不提交 |
| 提交审核 | 草稿 | 进入待审核 |
| 审核 | 待审核 | 审核通过并触发业务动作 |
| 反审核 | 已审核且无下游 | 回退状态 |
| 作废/关闭 | 未完成或异常 | 终止业务 |
| 打印 | 有单据号 | 打印单据 |
| 导入 | 列表页 | Excel导入 |
| 导出 | 列表页 | 导出中心异步导出 |
| 操作日志 | 列表/详情 | 查看审计记录 |

## 三、工作台页面

### 3.1 经营概览

#### 页面定位

老板、管理层、内勤进入系统后的默认首页，快速掌握经营情况和待处理事项。

#### 页面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 今日经营：销售额 | 订单数 | 毛利预估 | 收款额 | 应收余额 | 库存金额 │
├──────────────────────────────────────────────────────────────┤
│ 销售趋势图（近30天）              │ 应收账龄分布                 │
├───────────────────────────────────┼──────────────────────────────┤
│ TOP商品排行                       │ TOP客户排行                  │
├──────────────────────────────────────────────────────────────┤
│ 待办事项：待审核采购、待审核销售、待收款、库存预警、逾期应收       │
└──────────────────────────────────────────────────────────────┘
```

#### 指标口径

| 指标 | 口径 |
|---|---|
| 今日销售额 | 今日销售收货单审核金额或销售订单金额，可配置 |
| 今日订单数 | 今日新增销售订单数 |
| 今日收款额 | 今日审核收款单金额 |
| 应收余额 | 所有未核销应收未收金额 |
| 应付余额 | 所有未核销应付未付金额 |
| 库存金额 | 库存余额数量 × 当前成本 |
| 毛利预估 | 销售签收金额 - 销售出库成本 |

### 3.2 待办审批

展示当前用户待审批单据：采购订单、销售低价、超信用、库存调整、付款申请。

字段：单据类型、单号、申请人、金额、申请时间、超时状态、操作。

## 十一、统一视觉和交互建议

### 11.1 后台布局

- 左侧固定菜单。
- 顶部为面包屑、全局搜索、消息、用户信息。
- 内容区采用卡片式布局。
- 单据编辑页使用“头部信息 + 明细表格 + 底部金额汇总 + 操作按钮”。
- 所有数据网格支持字段顺序拖拽、字段显示/隐藏、字段宽度调整，并按用户自动保存。
- 点击网格字段名称可排序，数量/金额字段底部显示当前页合计和查询总合计。
- 所有业务单据支持导出主单、导出明细；导出字段遵循用户字段设置和权限控制。
- 所有单据录入支持快捷键，详见 `17-V1.0-通用网格与单据交互规范.md`。

### 11.2 状态颜色

| 状态 | 颜色建议 |
|---|---|
| 草稿 | 灰色 |
| 待审核 | 橙色 |
| 已审核 | 蓝色 |
| 已完成 | 绿色 |
| 已关闭 | 灰黑色 |
| 异常/驳回 | 红色 |
| 部分完成 | 紫色 |

### 11.3 金额与库存字段

- 金额统一右对齐，保留2位小数。
- 数量统一右对齐，最多4位小数。
- 成本、毛利字段受权限控制。
- 库存不足红色，库存预警橙色。
