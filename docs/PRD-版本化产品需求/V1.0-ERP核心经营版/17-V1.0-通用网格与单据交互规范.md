# V1.0 ERP核心经营版 — 通用网格与单据交互规范

> 文档版本：v1.0  
> 编写日期：2026-06-13  
> 适用范围：V1.0全部PC后台页面  
> 文档目的：统一所有数据网格、列表、业务单据录入、导出、排序、汇总、快捷键等基础交互能力

---

## 一、通用原则

### 1.1 适用范围

本规范适用于所有PC后台数据网格和业务单据页面，包括但不限于：

- 基础资料列表：商品、客户、供应商、仓库、往来单位、费用类型等。
- 业务单据列表：采购订单、采购入库、采购收货、销售订单、销售出库、销售收货、其他出入库、报损、费用单、收付款单等。
- 财务列表：应收、应付、核销记录、资金流水、结算单等。
- 报表列表：销售报表、采购报表、库存报表、财务报表。
- 单据录入明细表格：采购订单明细、销售订单明细、费用明细、库存调整明细等。

### 1.2 设计目标

1. 让每个用户可以按自己的工作习惯调整字段顺序。
2. 让高频操作员能少用鼠标，通过键盘完成录入。
3. 让数量、金额类数据在列表底部直接看到合计。
4. 让所有业务数据都可以导出主单或明细，便于对账、留档和线下分析。
5. 让字段显示、排序、宽度等个性化设置自动保存，下次进入继续生效。

## 二、数据网格字段展示设置

### 2.1 字段展示顺序设置

所有数据网格必须支持用户自定义字段展示顺序。

#### 交互方式

| 方式 | 说明 |
|---|---|
| 表头拖拽 | 用户直接拖拽列头改变列顺序 |
| 字段设置弹窗 | 点击“字段设置”按钮，在弹窗中拖拽排序 |
| 恢复默认 | 一键恢复系统默认字段顺序 |

#### 拖拽交互要求

- 鼠标按住表头字段名称可左右拖拽。
- 拖动过程中显示插入位置提示线。
- 松开后立即调整列顺序。
- 调整后自动保存用户偏好。
- 刷新页面或退出重新进入后，仍按用户上次顺序展示。

#### 字段设置弹窗

入口：列表右上角 `字段设置` 或表头右键菜单。

弹窗布局：

```text
字段设置
├─ 已显示字段
│  ├─ 拖拽排序
│  ├─ 勾选显示/隐藏
│  └─ 固定列设置
├─ 未显示字段
│  └─ 勾选恢复显示
├─ 操作按钮
│  ├─ 保存
│  ├─ 恢复默认
│  └─ 取消
```

### 2.2 字段显示/隐藏

所有数据网格必须支持设置字段不显示。

#### 规则

- 用户可在字段设置中取消勾选某个字段。
- 取消后该字段从当前列表隐藏。
- 隐藏设置自动保存，下次进入仍隐藏。
- 关键字段可设为系统必显，不允许隐藏。
- 无权限字段即使用户勾选也不可显示。

#### 必显字段建议

| 页面类型 | 必显字段 |
|---|---|
| 业务单据列表 | 单据号、状态、操作 |
| 基础资料列表 | 编码、名称、状态、操作 |
| 应收应付列表 | 单号、对象、金额、未结金额、状态、操作 |
| 库存列表 | 商品、仓库、实物库存、可用库存 |

### 2.3 字段宽度设置

所有数据网格建议支持拖拽调整列宽。

规则：

- 鼠标拖拽表头右边界调整宽度。
- 宽度设置自动保存。
- 可一键恢复默认列宽。
- 最小宽度不得小于系统设定，防止字段完全不可见。

### 2.4 固定列

高频列表建议支持固定列。

| 固定方向 | 说明 |
|---|---|
| 左固定 | 如选择框、单据号、商品编码 |
| 右固定 | 如操作列 |

用户可在字段设置中设置是否固定，系统也可强制某些列固定。

## 三、排序功能

### 3.1 表头排序

所有支持排序的字段，点击字段名称可排序。

#### 交互规则

| 操作 | 结果 |
|---|---|
| 第一次点击字段名 | 升序 |
| 第二次点击字段名 | 降序 |
| 第三次点击字段名 | 取消排序，恢复默认 |

排序图标：

```text
无排序：↕
升序：↑
降序：↓
```

### 3.2 支持排序字段

| 字段类型 | 是否建议排序 | 示例 |
|---|:---:|---|
| 日期时间 | 是 | 单据日期、创建时间、审核时间 |
| 编号 | 是 | 单据号、商品编码、客户编码 |
| 金额 | 是 | 订单金额、应收金额、未收金额 |
| 数量 | 是 | 库存数量、订单数量 |
| 状态 | 是 | 单据状态、核销状态 |
| 文本名称 | 可选 | 客户名称、商品名称 |
| 操作列 | 否 | 按钮 |

### 3.3 多字段排序

V1.0可先支持单字段排序。后续可支持按住Shift多字段排序。

### 3.4 排序保存

用户排序状态是否保存可按页面类型决定：

| 页面 | 建议 |
|---|---|
| 业务单据列表 | 保存最近排序 |
| 基础资料列表 | 保存最近排序 |
| 报表 | 不强制保存，可按查询条件默认 |
| 单据明细录入 | 不保存排序，保持录入顺序 |

## 四、网格底部汇总

### 4.1 功能要求

所有数据网格中，数量、金额字段应在表格底部显示汇总。

### 4.2 汇总显示位置

```text
表格数据行
------------------------------------------------
合计行：       数量合计      金额合计      成本金额合计
分页区：共xxx条，每页xx条
```

### 4.3 汇总字段范围

| 字段类型 | 是否汇总 | 示例 |
|---|:---:|---|
| 数量字段 | 是 | 采购数量、销售数量、库存数量 |
| 金额字段 | 是 | 订单金额、应收金额、付款金额 |
| 成本字段 | 有权限时 | 成本金额、库存金额、毛利 |
| 比率字段 | 不直接合计 | 毛利率、税率、折扣率 |
| 单价字段 | 不直接合计 | 销售价、采购价、成本单价 |

### 4.4 当前页合计与全部合计

V1.0建议支持两种合计：

| 合计类型 | 说明 |
|---|---|
| 当前页合计 | 当前分页已加载数据合计 |
| 查询结果总合计 | 符合当前查询条件的全部数据合计 |

显示方式：

```text
当前页合计：数量 120，金额 3,500.00
查询总合计：数量 2,350，金额 68,900.00
```

### 4.5 权限控制

- 无金额权限：金额合计隐藏。
- 无成本权限：成本金额合计隐藏。
- 无毛利权限：毛利合计隐藏。
- 导出时同样遵循字段权限。

## 五、数据网格个性化保存

### 5.1 保存内容

系统应自动保存用户对每个网格的个性化设置：

| 设置项 | 是否保存 |
|---|:---:|
| 字段显示/隐藏 | 是 |
| 字段顺序 | 是 |
| 字段宽度 | 是 |
| 固定列 | 是 |
| 排序字段 | 建议保存 |
| 每页条数 | 是 |
| 查询条件默认值 | 可选 |

### 5.2 保存维度

按以下维度保存：

```text
用户ID + 页面编码 + 网格编码
```

示例：

```text
userId=U001
pageCode=SALES_ORDER_LIST
gridCode=MAIN_GRID
```

### 5.3 自动保存时机

| 操作 | 保存时机 |
|---|---|
| 拖拽列顺序 | 松开鼠标后自动保存 |
| 隐藏/显示字段 | 点击保存字段设置后保存 |
| 调整列宽 | 鼠标松开后自动保存 |
| 修改每页条数 | 切换后保存 |
| 点击恢复默认 | 清除用户配置 |

### 5.4 默认配置

若用户没有个性化设置，则按系统默认字段配置展示。

### 5.5 跨设备规则

V1.0建议个性化配置跟随账号，而不是本地浏览器。用户更换电脑登录后仍使用自己的字段设置。

## 六、业务单据导出规范

### 6.1 导出范围

所有业务单据都必须支持导出：

| 导出类型 | 说明 |
|---|---|
| 导出主单 | 导出单据头信息，一张单据一行 |
| 导出明细 | 导出单据明细信息，一行商品/费用明细一行 |
| 导出主单+明细 | 可选，Excel多个Sheet或明细展开 |

### 6.2 必须支持导出的单据

| 模块 | 单据 |
|---|---|
| 采购 | 采购订单、采购入库、采购收货、采购退货、采购费用、采购发票 |
| 销售 | 销售订单、销售出库、销售收货、销售退货 |
| 库存 | 其他入库、其他出库、报损单、库存调整、成本调整 |
| 财务 | 应收、应付、费用单、收款单、付款单、应收结算、应付结算、核销记录 |
| 基础资料 | 商品、客户、供应商、往来单位、仓库、价格 |

### 6.3 导出按钮

业务单据列表统一提供：

```text
[导出主单] [导出明细] [导出当前页] [导出全部查询结果]
```

具体按钮可按页面复杂度合并为下拉菜单：

```text
导出 ▼
  ├─ 导出主单
  ├─ 导出明细
  ├─ 导出主单+明细
  └─ 导出当前页
```

### 6.4 导出字段规则

- 默认按当前网格字段显示顺序导出。
- 用户隐藏的字段默认不导出。
- 可在导出弹窗中选择“导出全部可导出字段”。
- 无权限字段不可导出。
- 成本、毛利、采购价、客户欠款、供应商余额等敏感字段必须受权限控制。

### 6.5 导出方式

- 小数据量可直接下载。
- 大数据量必须进入导出中心异步导出。
- 导出中心记录导出人、模块、条件、文件、状态、时间。

### 6.6 导出文件命名

```text
模块名称_导出类型_yyyyMMddHHmmss.xlsx
```

示例：

```text
销售订单_明细_20260613143025.xlsx
采购费用单_主单_20260613143110.xlsx
```

## 七、业务单据键盘快捷操作规范

### 7.1 适用范围

所有业务单据录入页面必须支持键盘快捷操作，包括：

- 采购订单
- 采购入库
- 采购费用单
- 销售快速开单
- 销售订单
- 销售出库
- 其他入库
- 其他出库
- 报损单
- 成本调整单
- 费用单
- 收款单
- 付款单
- 应收结算
- 应付结算

### 7.2 通用快捷键

| 快捷键 | 动作 | 说明 |
|---|---|---|
| Ctrl + S | 保存草稿/保存 | 当前单据保存 |
| Ctrl + Enter | 提交/审核 | 根据状态执行提交或审核 |
| Esc | 关闭弹窗/返回 | 有未保存内容需确认 |
| F2 | 聚焦主对象 | 客户/供应商/往来单位 |
| F3 | 聚焦商品搜索 | 商品类单据使用 |
| F4 | 打开历史/常用选择 | 常购商品、历史采购商品等 |
| F5 | 保存草稿 | 不提交审核 |
| F6 | 提交审核/审核 | 按状态判断 |
| F7 | 新增明细行 | 表格新增一行 |
| F8 | 删除当前明细行 | 需确认或仅未保存行直接删 |
| F9 | 重新计算金额 | 重算金额、税额、汇总 |
| F10 | 打印 | 已审核单据可打印 |
| Ctrl + D | 复制当前行 | 明细行复制 |
| Ctrl + ↑/↓ | 上下移动明细行 | 调整明细顺序 |

### 7.3 明细表格键盘操作

| 按键 | 动作 |
|---|---|
| Enter | 当前单元格确认并跳到下一可编辑单元格 |
| Tab | 跳到下一单元格 |
| Shift + Tab | 跳到上一单元格 |
| ↑ / ↓ | 上下移动行 |
| ← / → | 左右移动单元格 |
| Delete | 清空当前单元格或删除当前行，按字段类型决定 |
| Ctrl + C | 复制单元格内容 |
| Ctrl + V | 粘贴，需校验格式 |

### 7.4 商品快速录入

商品类单据支持：

```text
扫码/输入商品编码/输入简拼 → 回车 → 自动带出商品 → 输入数量 → 回车 → 输入单价 → 回车 → 新增下一行
```

### 7.5 快捷键冲突处理

- 系统快捷键不得与浏览器关键快捷键严重冲突。
- 如果浏览器拦截，页面应提供按钮替代。
- 快捷键说明可在页面右上角“快捷键帮助”查看。

### 7.6 快捷键帮助弹窗

所有业务单据页面建议提供：

```text
[快捷键帮助]
```

弹窗展示当前页面支持的快捷键。

## 八、单据录入通用体验规范

### 8.1 自动带出

单据选择主对象后自动带出相关信息：

| 对象 | 自动带出 |
|---|---|
| 客户 | 地址、业务员、结算方式、信用额度、欠款、价格等级 |
| 供应商 | 到货天数、结算方式、采购员、联系人 |
| 商品 | 单位、条码、价格、库存、成本、税率 |
| 仓库 | 成本分组、库存类型 |
| 往来单位 | 结算方式、账期、账户信息 |

### 8.2 自动计算

业务单据必须自动计算：

- 数量 × 单价 = 金额
- 金额 × 税率 = 税额
- 明细金额合计 = 主表金额
- 成本单价 × 数量 = 成本金额
- 应收/应付金额 = 业务金额 - 优惠/折让
- 结算后余额 = 未结金额 - 本次结算 - 折让

### 8.3 明细校验

- 商品不能为空。
- 数量必须大于0。
- 单价不能小于0。
- 金额不能小于0，红字业务除外。
- 库存出库数量不能超过可用库存。
- 成本调整后成本不能小于0。
- 必填批次商品必须填写批次/生产日期。

## 九、网格配置数据模型建议

### 9.1 用户网格配置表 sys_user_grid_config

| 字段 | 类型 | 必填 | 说明 |
|---|---|:---:|---|
| config_id | varchar(32) | 是 | 主键 |
| user_id | varchar(32) | 是 | 用户ID |
| page_code | varchar(100) | 是 | 页面编码 |
| grid_code | varchar(100) | 是 | 网格编码 |
| config_json | text | 是 | 字段顺序、隐藏、宽度、固定列、排序等 |
| updated_at | datetime | 是 | 更新时间 |

### 9.2 配置JSON示例

```json
{
  "columns": [
    {"field": "order_no", "visible": true, "width": 160, "fixed": "left", "sort": 1},
    {"field": "customer_name", "visible": true, "width": 180, "fixed": null, "sort": 2},
    {"field": "cost_amount", "visible": false, "width": 120, "fixed": null, "sort": 20}
  ],
  "pageSize": 50,
  "sortField": "order_date",
  "sortOrder": "desc"
}
```
