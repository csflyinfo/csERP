# V1.0 系统方管理后台 PRD

> 文档版本：v1.0  
> 所属版本：V1.0 ERP核心经营版  
> 使用对象：系统方运营、实施、技术支持、系统管理员  
> 重要边界：仅系统方人员可登录，客户、经销商业务用户、入驻商用户均不可进入  
> 原型文件：`prototype/system-admin-console/index.html`

## 一、产品定位

### 1.1 背景

ERP+WMS+TMS+B2B 系统存在两类后台：

1. **租户业务后台**：经销商、仓库、财务、业务员、入驻商等业务用户使用。
2. **系统方管理后台**：系统运营方、实施人员、技术支持、平台超级管理员使用。

系统方管理后台不承载具体经销商日常采购、销售、库存、财务业务，而是负责系统级配置、租户开户、系统菜单、功能授权、系统默认字典、默认打印模板、系统参数、安全审计、版本发布等平台治理能力。

### 1.2 产品目标

| 目标 | 说明 |
|------|------|
| 租户开户标准化 | 系统方可为客户开通租户、创建初始管理员、配置版本套餐 |
| 权限配置统一 | 统一维护系统菜单、功能点、按钮权限、数据权限模板 |
| 系统配置可控 | 控制全局参数、租户参数模板、功能开关、系统版本 |
| 默认数据统一 | 管理系统默认字典、默认打印横版、默认编号规则、默认审批模板 |
| 实施交付提效 | 新客户开户时一键初始化菜单、角色、字典、打印模板 |
| 安全可追溯 | 系统方操作全审计、敏感操作二次确认 |

### 1.3 系统边界

| 内容 | 系统方管理后台 | 租户业务后台 |
|------|----------------|--------------|
| 租户开户 | 负责 | 不可见 |
| 系统方账号 | 负责 | 不可见 |
| 业务用户 | 可代管/重置/锁定 | 租户管理员维护 |
| 菜单功能元数据 | 负责维护 | 只读取授权结果 |
| 默认字典 | 负责维护 | 租户可继承/扩展用户字典 |
| 默认打印模板 | 负责维护系统横版 | 租户可复制后自定义 |
| 业务单据 | 原则上不处理 | 租户业务用户处理 |
| 系统审计 | 查看系统方和租户关键日志 | 只能查看本租户日志 |

### 4.2 页面布局

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 系统方管理后台 / 工作台                                               │

├──────────────────────────────────────────────────────────────────────┤
```

### 4.3 指标定义

| 指标 | 说明 |
|------|------|
| 今日新增租户 | 今日开户租户数 |
| 活跃租户 | 近7天有登录或业务操作租户数 |
| 待初始化 | 已开户但未完成初始化租户数 |
| 异常接口 | 最近24小时接口失败次数 |

| 待发布配置 | 已修改但未发布的菜单、字典、模板 |

## 五、租户管理

### 5.1 功能定位

租户管理用于系统方为客户公司开通系统账号，配置租户版本、业务模块、默认菜单、初始管理员、数据容量、有效期和初始化模板。

### 5.2 租户开户流程

```text
新建租户 → 填写公司资料 → 选择版本套餐 → 配置模块功能 → 创建初始管理员
        │
        ▼
选择初始化模板 → 下发菜单/字典/打印模板/参数 → 完成开户 → 通知客户管理员
```

### 5.3 租户表字段

**租户表 (sys_tenant)**
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|:---:|------|
| tenant_id | varchar(32) | ✓ | 租户ID |
| tenant_code | varchar(50) | ✓ | 租户编码，唯一 |
| tenant_name | varchar(200) | ✓ | 公司/客户名称 |
| short_name | varchar(100) | | 简称 |
| contact_person | varchar(50) | ✓ | 联系人 |
| contact_mobile | varchar(20) | ✓ | 联系手机号 |
| industry_type | varchar(50) | | 行业：快消/食品/日化/建材/3C等 |
| package_id | varchar(32) | ✓ | 版本套餐ID |
| enabled_modules | text | ✓ | 启用模块JSON |
| max_user_count | int | | 最大用户数 |
| max_warehouse_count | int | | 最大仓库数 |
| expire_date | date | | 到期日期 |
| status | varchar(20) | ✓ | 待初始化/正常/停用/到期/冻结 |
| admin_account | varchar(50) | ✓ | 初始管理员账号 |
| init_status | varchar(20) | ✓ | 未初始化/初始化中/初始化完成/初始化失败 |
| created_by | varchar(32) | ✓ | 创建人 |
| created_at | datetime | ✓ | 创建时间 |

### 5.4 租户列表字段

| 列 | 说明 |
|----|------|
| 租户编码 | 可点击进入租户详情 |
| 租户名称 | 公司名称 |
| 联系人/电话 | 联系方式 |
| 版本套餐 | 启用版本 |
| 启用模块 | ERP/WMS/TMS/B2B等 |
| 用户数 | 已用/上限 |
| 到期日期 | 服务到期 |
| 初始化状态 | 未初始化/完成/失败 |
| 租户状态 | 正常/停用/冻结 |
| 操作 | 详情、初始化、停用、续期、功能开关 |

### 5.5 租户详情页

详情页采用独立页面，包含：

```text
基本信息
版本套餐
启用模块
用户概览
初始化记录
菜单授权
参数配置
打印模板
接口配置
操作日志
```

### 5.6 业务规则

- 租户编码全局唯一，创建后不可修改。
- 初始管理员手机号必须唯一。
- 停用租户后，租户业务用户不可登录；系统方仍可查看租户资料和日志。
- 租户初始化失败可重试，需保留失败日志。
- 到期租户可设置宽限期，超过宽限期禁止登录。

## 六、系统方账号管理

### 6.1 功能定位

系统方账号管理只管理系统运营方内部人员，不管理租户业务人员。租户用户在“业务用户代管”模块查询和处理。

### 6.2 系统方用户表

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| user_id | varchar(32) | ✓ | 用户ID |
| account | varchar(50) | ✓ | 登录账号 |
| user_name | varchar(100) | ✓ | 姓名 |
| mobile | varchar(20) | ✓ | 手机号 |
| email | varchar(100) | | 邮箱 |
| role_id | varchar(32) | ✓ | 系统方角色 |
| status | varchar(20) | ✓ | 正常/停用/锁定 |
| mfa_enabled | tinyint | | 是否启用二次验证 |
| last_login_time | datetime | | 最后登录时间 |
| created_at | datetime | ✓ | 创建时间 |

### 6.3 登录安全策略

| 策略 | 说明 |
|------|------|
| 密码复杂度 | 长度、大小写、数字、特殊字符 |
| 登录失败锁定 | 连续失败N次锁定 |
| MFA | 超级管理员、审计员必须开启 |
| IP白名单 | 可限制系统方后台访问IP |
| 异地登录提醒 | 发现异常登录推送告警 |

## 七、业务用户代管

### 7.1 功能定位

业务用户代管用于系统方支持人员在客户授权或故障处理场景下查询租户用户、重置密码、锁定/解锁账号、诊断登录问题。

### 7.2 功能列表

| 功能 | 说明 |
|------|------|
| 租户用户查询 | 按租户、账号、手机号、状态查询 |
| 重置密码 | 重置为随机密码或短信验证码登录 |
| 锁定/解锁 | 处理风险账号或登录失败锁定 |
| 登录诊断 | 查看最近登录失败原因、IP、设备、时间 |
| 代发通知 | 给租户管理员发送账号通知 |

### 7.3 业务规则

- 系统方不可直接查看用户密码，只能重置。
- 重置密码必须记录操作原因。
- 代管操作必须写入敏感操作日志。
- 对租户超级管理员操作需二次确认。

## 八、菜单与功能管理

### 8.1 功能定位

菜单与功能管理用于维护系统所有端的菜单树、页面、按钮、功能点、数据权限项。租户业务后台只读取菜单授权结果，不允许修改系统菜单元数据。

### 8.2 菜单树结构

```text
系统类型：ERP后台 / B2B后台 / 入驻商后台 / 管理通APP / 司机APP / PDA / 客户小程序
├─ 一级菜单
│  ├─ 二级菜单
│  │  ├─ 页面
│  │  │  ├─ 按钮：新增/编辑/删除/审核/导入/导出
│  │  │  └─ 数据权限：金额/成本/毛利/仓库/货主/客户范围
```

### 8.3 菜单表字段

**系统菜单表 (sys_menu_meta)**
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|:---:|------|
| menu_id | varchar(32) | ✓ | 菜单ID |
| parent_id | varchar(32) | | 上级菜单 |
| app_type | varchar(30) | ✓ | ERP/B2B/MERCHANT/APP/PDA/DRIVER/MINI |
| menu_code | varchar(100) | ✓ | 菜单编码 |
| menu_name | varchar(100) | ✓ | 菜单名称 |
| menu_type | varchar(20) | ✓ | 目录/菜单/页面/按钮 |
| route_path | varchar(200) | | 前端路由 |
| component_path | varchar(200) | | 组件路径 |
| icon | varchar(100) | | 图标 |
| permission_code | varchar(100) | | 权限编码 |
| sort_order | int | | 排序 |
| visible | tinyint | ✓ | 是否显示 |
| status | varchar(20) | ✓ | 正常/停用 |
| version_code | varchar(50) | | 所属版本 |

### 8.4 功能点表字段

**功能点表 (sys_function_meta)**
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|:---:|------|
| func_id | varchar(32) | ✓ | 功能ID |
| menu_id | varchar(32) | ✓ | 所属菜单 |
| func_code | varchar(100) | ✓ | 功能编码，如 add/edit/delete/audit/export |
| func_name | varchar(100) | ✓ | 功能名称 |
| func_type | varchar(20) | ✓ | 按钮/API/字段/数据范围 |
| api_path | varchar(200) | | 关联API |
| default_enabled | tinyint | ✓ | 默认是否启用 |
| status | varchar(20) | ✓ | 正常/停用 |

### 8.5 页面布局建议

```
左侧：系统类型 + 菜单树
右侧上：菜单基本信息
右侧中：按钮/功能点列表
右侧下：数据权限项/字段权限项
```

### 8.6 业务规则

- 菜单编码和功能编码全局唯一。
- 已下发租户的菜单停用时需提示影响租户数量。
- 菜单删除仅允许未下发、未被版本包引用时执行。
- 修改菜单路由需生成版本变更记录。

## 九、授权模板管理

### 9.1 功能定位

授权模板用于系统方维护不同角色、不同套餐、不同端的默认菜单功能权限。新租户开户时可一键下发授权模板。

### 9.2 模板类型

| 模板 | 说明 |
|------|------|
| 标准ERP模板 | 采购、销售、库存、财务基础权限 |
| WMS模板 | 仓库主管、仓库人员、PDA角色 |
| TMS模板 | 调度员、司机、配送主管 |
| B2B模板 | 运营、客服、商品、财务 |
| 入驻商模板 | 入驻商管理员、订单员、商品员 |
| 老板模板 | 经营看板和关键报表 |

### 9.3 授权模板表

| 字段 | 说明 |
|------|------|
| 模板编号 | 唯一 |
| 模板名称 | 如“标准经销商ERP模板” |
| 适用版本 | V1/V2/B2B等 |
| 适用角色 | 管理员/采购/销售/仓库/财务 |
| 菜单范围 | 授权菜单列表 |
| 功能范围 | 授权按钮/功能点 |
| 数据权限 | 金额、成本、仓库、货主、客户范围 |
| 状态 | 启用/停用 |

### 9.4 模板下发

```
选择租户 → 选择模板 → 预览授权差异 → 确认下发
        │
        ├── 新增租户：直接生成角色和权限
        └── 已有租户：可选择覆盖/追加/仅新增不覆盖
```

### 9.5 业务规则

- 模板修改不自动影响已下发租户，需手工发布。
- 下发前必须展示差异清单。
- 覆盖租户权限需二次确认。

## 十、系统配置

### 10.1 配置范围

| 配置 | 说明 |
|------|------|
| 全局参数 | 全系统级参数，如登录安全、文件大小、导出保留天数 |
| 租户参数模板 | 新租户默认参数，如库存锁定时间、自动审核开关 |
| 功能开关 | 模块级开关，如是否启用B2B、WMS、TMS、发票管理 |
| 编号规则模板 | 单据编号默认规则 |
| 系统公告 | 系统方发布给租户管理员的公告 |

### 10.2 功能开关字段

| 字段 | 说明 |
|------|------|
| 开关编码 | 如 ENABLE_B2B |
| 开关名称 | 是否启用B2B商城 |
| 适用范围 | 全局/租户/版本 |
| 默认值 | 开/关 |
| 是否可租户修改 | 是/否 |
| 影响说明 | 开关影响的模块 |

### 10.3 业务规则

- 全局参数修改需记录发布版本。
- 影响登录、安全、数据结构的配置需超级管理员权限。
- 功能开关关闭后，对应菜单和API均不可访问。

## 十一、系统字典管理

### 11.1 功能定位

系统字典管理用于维护系统内置字典类型和默认字典项。系统默认字典由系统方维护，租户不可删除，可在租户侧复制为用户字典扩展。

### 11.2 字典类型

| 字典类型 | 示例 |
|----------|------|
| 单据类型 | 采购订单、销售订单、采购发票、销售发票 |
| 单据状态 | 草稿、待审核、已审核、已完成、已关闭 |
| 操作类型 | 新增、修改、删除、审核、反审核、导入、导出 |
| 库存类型 | 正常仓、退货仓、临期仓、货损仓 |
| 配送状态 | 待装车、配送中、已签收、拒收 |
| 发票状态 | 未勾稽、部分勾稽、已勾稽、已红冲 |

### 11.3 字典字段

| 字段 | 说明 |
|------|------|
| 字典类型编码 | 如 BILL_STATUS |
| 字典类型名称 | 单据状态 |
| 字典项编码 | APPROVED |
| 字典项名称 | 已审核 |
| 排序 | 显示顺序 |
| 状态 | 正常/停用 |
| 是否系统内置 | 是/否 |
| 是否允许租户扩展 | 是/否 |

### 11.4 下发策略

- 新租户开户时自动下发系统默认字典。
- 系统字典更新可按租户批量下发。
- 租户已自定义的同类型字典不强制覆盖。

## 十二、系统默认打印横版管理

### 12.1 功能定位

系统默认打印横版管理用于系统方维护标准打印模板，包括采购订单、销售订单、销售送货单、采购收货单、采购发票勾稽单、销售发票、应收结算单、应付结算单等。

租户开户时系统默认模板自动下发，租户可复制后自定义。

### 12.2 模板类型

| 模板 | 说明 |
|------|------|
| 销售订单横版 | A4销售订单 |
| 销售送货单横版 | 配送随货单 |
| 销售小票 | 热敏小票 |
| 采购订单横版 | A4采购订单 |
| 采购入库单横版 | 入库确认单 |
| 采购费用分摊单 | 费用分摊打印 |
| 应收结算单 | 客户结算确认 |
| 应付结算单 | 供应商结算确认 |
| 调拨单 | 调拨打印 |
| 盘点单 | 盘点打印 |

### 12.3 打印模板字段

| 字段 | 说明 |
|------|------|
| 模板编码 | 唯一 |
| 模板名称 | 模板名称 |
| 业务模块 | 销售/采购/库存/财务 |
| 纸张类型 | A4横版/A4竖版/热敏 |
| 模板内容 | HTML/模板DSL |
| 变量清单 | 可引用字段 |
| 预览数据 | 模拟数据 |
| 状态 | 启用/停用 |
| 版本 | 模板版本 |

### 12.4 模板设计器要求

- 支持拖拽字段。
- 支持表头、明细表、合计区、签字栏。
- 支持条码/二维码。
- 支持Logo和水印。
- 支持打印预览。
- 支持复制为新模板。
- 支持下发到租户。

### 12.5 业务规则

- 系统默认模板不可被租户直接修改。
- 租户修改时先复制为租户自定义模板。
- 模板变量必须来自打印字段表。
- 停用模板前需检查是否被默认打印配置引用。

## 十三、审计与日志

### 13.1 日志类型

| 日志 | 说明 |
|------|------|
| 登录日志 | 系统方账号登录、失败、登出 |
| 操作日志 | 新增、修改、删除、审核、发布等操作 |
| 敏感操作日志 | 重置租户密码、停用租户、覆盖权限、发布功能开关 |
| 接口日志 | 系统集成接口调用 |
| 配置发布日志 | 菜单、字典、模板、参数发布记录 |

### 13.2 敏感操作二次确认

以下操作必须二次确认：

- 停用租户
- 删除系统方账号
- 重置租户超级管理员密码
- 覆盖租户权限
- 发布全局参数
- 停用菜单/功能点
- 删除系统字典项
- 下发默认打印模板覆盖租户模板

## 十四、版本与发布

### 14.1 功能定位

版本与发布模块用于管理系统版本、菜单变更、字典变更、模板变更、功能开关变更，并将变更发布到指定租户。

### 14.2 发布流程

```text
创建变更 → 选择变更内容 → 选择发布范围 → 预览影响 → 审核 → 发布 → 记录结果
```

### 14.3 发布范围

| 范围 | 说明 |
|------|------|
| 全部租户 | 所有正常租户 |
| 指定租户 | 选择部分租户 |
| 指定版本 | 选择某版本套餐租户 |
| 灰度租户 | 先发布给测试租户 |

### 14.4 发布结果

| 状态 | 说明 |
|------|------|
| 待发布 | 变更已创建未发布 |
| 发布中 | 正在执行 |
| 部分成功 | 部分租户失败 |
| 成功 | 全部成功 |
| 失败 | 全部失败或关键错误 |
