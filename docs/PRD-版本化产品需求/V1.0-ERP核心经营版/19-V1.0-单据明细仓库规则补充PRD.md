# V1.0 ERP核心经营版 — 单据明细仓库规则补充PRD

> 文档版本：v1.0  
> 编写日期：2026-06-13  
> 适用范围：V1.0所有库存影响类业务单据  
> 文档目的：统一各类出入库单据明细的“仓库”字段规则、系统参数、多仓控制、库存成本流水计算口径。

---

## 一、规则背景

V1.0业务单据中，采购、销售、其他出入库、报损、退货等单据都会影响库存、成本和库存流水。为避免只依赖单据头仓库导致明细级多仓场景无法表达，所有库存影响类单据明细需要增加“仓库”字段。

核心原则：

```text
所有库存、成本、库存流水计算均以明细仓库为准。
```

---

## 二、适用单据范围

以下单据明细必须增加“仓库”字段：

| 模块 | 单据 | 明细仓库要求 |
|---|---|---|
| 采购 | 采购订单 | 明细仓库默认取单据头收货仓库，可按参数控制是否可改 |
| 采购 | 采购入库单 | 明细仓库决定库存增加、成本计算、库存流水入库仓库 |
| 采购 | 采购收货单 | 继承采购入库明细仓库，用于追溯和结算展示 |
| 采购 | 采购退货单 | 明细仓库决定退货扣减哪个仓库库存 |
| 销售 | 销售订单 | 明细仓库默认取单据头发货仓库，用于库存锁定 |
| 销售 | 销售出库单 | 明细仓库决定库存扣减和出库成本 |
| 销售 | 销售收货单 | 继承销售出库明细仓库，用于应收和成本追溯 |
| 销售 | 销售退货单 | 明细仓库决定退货入库仓库 |
| 库存 | 其他入库单 | 明细仓库决定库存增加仓库 |
| 库存 | 其他出库单 | 明细仓库决定库存扣减仓库 |
| 库存 | 报损单 | 明细仓库决定报损扣减仓库 |
| 库存 | 库存调整单 | 明细仓库决定调整库存仓库 |
| 库存 | 成本调整单 | 明细仓库决定调整哪个仓库/成本分组的成本 |

## 三、调拨单特殊规则

调拨单不同于普通出入库单据。

V1.0调拨单按以下规则处理：

```text
一张调拨单只允许一个调出仓库和一个调入仓库。
调拨明细不单独编辑仓库。
调拨明细默认取单据头调出仓库和调入仓库。
```

原因：

- 调拨业务天然表达“从一个仓调到另一个仓”。
- 一张调拨单多调出仓/多调入仓会显著增加在途、成本和入库确认复杂度。
- V1.0先保持一单一出仓一入仓，后续版本如需支持复杂多仓调拨，再设计调拨批次/调拨任务拆分能力。

调拨明细仍需展示：

| 字段 | 说明 |
|---|---|
| 调出仓库 | 只读，取单据头调出仓库 |
| 调入仓库 | 只读，取单据头调入仓库 |
| 调拨数量 | 可编辑 |
| 成本单价 | 取调出仓当前成本 |
| 成本金额 | 调拨数量 × 成本单价 |

## 四、系统参数

### 4.1 新增参数

| 参数键 | 参数名称 | 默认值 | 可选值 | 说明 |
|---|---|---|---|---|
| ALLOW_MULTI_WAREHOUSE_BILL | 是否允许一张业务单据多仓 | NO | YES/NO | 控制采购、销售、其他出入库、报损等单据明细仓库是否可编辑 |

### 4.2 参数规则

#### 不允许多仓

```text
ALLOW_MULTI_WAREHOUSE_BILL = NO
```

规则：

- 单据头仓库必填。
- 明细仓库默认等于单据头仓库。
- 明细仓库只读，不可修改。
- 修改单据头仓库时，未审核单据的所有明细仓库同步更新。

#### 允许多仓

```text
ALLOW_MULTI_WAREHOUSE_BILL = YES
```

规则：

- 单据头仓库仍作为默认仓库。
- 新增商品明细时，明细仓库默认等于单据头仓库。
- 选择商品后，如商品档案有默认仓库，则优先带出商品默认仓库；没有商品默认仓库时取单据头仓库。
- 用户可手工修改明细仓库。
- 库存校验、锁定、扣减、入库、成本、流水均按明细仓库执行。

---

## 五、商品选择后的仓库带出规则

### 5.1 带出优先级

选择商品后，明细仓库按以下优先级带出：

```text
商品档案默认仓库 > 单据头仓库 > 系统默认仓库
```

### 5.2 不同参数下处理

| 参数 | 商品默认仓库 | 明细仓库结果 |
|---|---|---|
| 不允许多仓 | 不管商品默认仓库为何 | 明细仓库=单据头仓库，只读 |
| 允许多仓 | 商品有默认仓库 | 明细仓库=商品默认仓库，可编辑 |
| 允许多仓 | 商品无默认仓库 | 明细仓库=单据头仓库，可编辑 |

## 六、库存、成本、流水计算口径

### 6.1 库存计算

所有库存变化使用明细仓库：

```text
库存余额维度 = 货主 + 商品 + 明细仓库 + 批次 + 成本分组
```

### 6.2 成本计算

采购入库、其他入库、退货入库等入库类单据：

```text
按明细仓库所属成本分组计算移动加权成本。
```

销售出库、其他出库、报损等出库类单据：

```text
按明细仓库当前成本取出库成本。
```

### 6.3 库存流水

库存流水必须记录明细仓库：

| 字段 | 说明 |
|---|---|
| warehouse_id | 明细仓库ID |
| warehouse_code | 明细仓库编码 |
| warehouse_name | 明细仓库名称 |
| cost_group | 明细仓库对应成本分组 |

## 七、页面交互要求

### 7.1 单据头仓库

单据头仓库仍保留，用途：

- 作为默认仓库。
- 用于快速开单。
- 用于列表筛选。
- 用于单据总体展示。

### 7.2 明细仓库

所有库存影响单据明细表增加“仓库”列。

| 状态 | 显示/编辑规则 |
|---|---|
| 新建/草稿 | 根据系统参数决定是否可编辑 |
| 待审核 | 根据权限和参数决定是否可编辑 |
| 已审核 | 只读 |
| 已完成/已关闭 | 只读 |

### 7.3 明细仓库变更后的联动

用户修改明细仓库后，系统必须重新计算/刷新：

- 可用库存。
- 锁定库存。
- 批次可选范围。
- 当前成本单价。
- 成本金额。
- 库位可选范围（V1.5 WMS启用后）。

---

## 八、业务校验

| 校验 | 规则 |
|---|---|
| 明细仓库为空 | 不允许保存/审核 |
| 仓库停用 | 不允许选择 |
| 商品不可在该仓销售/采购 | 按商品仓库规则提示或阻断，V1.0可先提示 |
| 出库数量超过明细仓可用库存 | 阻断审核 |
| 批次不属于明细仓库 | 阻断保存/审核 |
| 成本分组不存在 | 阻断审核 |

## 九、原型更新要求

相关原型页面需要同步调整：

- 采购订单。
- 采购入库。
- 采购退货。
- 销售订单。
- 销售出库。
- 销售退货。
- 其他入库。
- 其他出库。
- 报损单。
- 库存调整单。
- 成本调整单。

明细网格统一增加列：

```text
仓库
```

调拨单单据头保持：

```text
调出仓库
调入仓库
```

调拨明细仓库字段只读展示，不单独编辑。

## 十、验收用例

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| WH-001 | 不允许多仓 | 单据头选择总仓，添加商品 | 明细仓库=总仓，只读 |
| WH-002 | 允许多仓 | 商品有默认仓库东区仓 | 明细仓库带出东区仓，可编辑 |
| WH-003 | 明细改仓 | 销售订单明细仓库从总仓改为东区仓 | 可用库存和成本按东区仓刷新 |
| WH-004 | 出库校验 | 明细仓库库存不足 | 阻断审核 |
| WH-005 | 采购入库 | 明细仓库为冷藏仓 | 库存增加到冷藏仓，成本按冷藏仓成本分组计算 |
| WH-006 | 调拨单 | 调出仓总仓，调入仓东区仓 | 明细取头部调出/调入仓，不能单独改仓 |
