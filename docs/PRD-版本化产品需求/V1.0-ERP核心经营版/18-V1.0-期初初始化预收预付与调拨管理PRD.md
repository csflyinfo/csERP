## 二、期初数据初始化

### 2.1 功能定位

期初数据初始化用于系统正式上线前，将企业原有系统或Excel中的基础经营数据导入新系统，保证上线当天库存、应收、应付、资金账户余额正确。

### 2.2 页面入口

`系统管理 → 数据初始化向导`

或独立一级菜单：

`初始化中心`

### 2.3 初始化范围

| 初始化对象 | 说明 | 是否V1.0必须 |
|---|---|:---:|
| 商品资料 | 商品基础档案、单位、条码、价格 | 是 |
| 客户资料 | 门店、账期、信用额度、地址 | 是 |
| 供应商资料 | 供应商、账期、账户、发票信息 | 是 |
| 仓库资料 | 仓库、成本分组 | 是 |
| 期初库存 | 商品、仓库、批次、数量、成本 | 是 |
| 期初应收 | 客户/往来单位未收款 | 是 |
| 期初应付 | 供应商/往来单位未付款 | 是 |
| 期初预收款 | 客户/往来单位预收余额 | 是 |
| 期初预付款 | 供应商/往来单位预付余额 | 是 |
| 期初资金账户 | 现金、银行、线上账户余额 | 是 |

### 2.4 初始化向导步骤

```text
步骤1：初始化说明与锁定检查
步骤2：基础资料导入
步骤3：期初库存导入
步骤4：期初应收导入
步骤5：期初应付导入
步骤6：期初预收/预付导入
步骤7：资金账户期初导入
步骤8：数据校验与试算平衡
步骤9：确认启用系统
```

### 2.5 向导页面布局

```text
初始化向导
├─ 左侧步骤条
│  1 初始化说明
│  2 基础资料
│  3 期初库存
│  4 期初应收
│  5 期初应付
│  6 预收/预付
│  7 资金账户
│  8 校验确认
│
└─ 右侧当前步骤内容
   ├─ 下载模板
   ├─ 上传文件
   ├─ 校验结果
   ├─ 失败原因下载
   └─ 下一步/上一步
```

### 2.6 期初库存导入字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 商品编码 | 是 | 必须存在于商品档案 |
| 商品名称 | 否 | 辅助校验 |
| 仓库编码 | 是 | 必须存在于仓库档案 |
| 批次号 | 批次商品必填 | 批次库存 |
| 生产日期 | 批次商品必填 | 效期管理 |
| 到期日期 | 条件必填 | 可由生产日期+保质期计算 |
| 单位 | 是 | 商品单位 |
| 期初数量 | 是 | 大于等于0 |
| 成本单价 | 是 | 大于等于0 |
| 期初成本金额 | 是 | 数量×成本单价 |
| 库位 | 否 | V1.5启用库位后使用 |

### 2.7 期初应收导入字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 对象类型 | 是 | 客户/往来单位 |
| 客户编码/往来单位编码 | 是 | 必须存在 |
| 应收日期 | 是 | 原业务日期 |
| 来源说明 | 是 | 旧系统期初/历史欠款 |
| 应收金额 | 是 | 原应收金额 |
| 已收金额 | 是 | 默认0或历史已收 |
| 未收金额 | 是 | 应收-已收 |
| 预计收款日 | 否 | 用于账龄 |
| 备注 | 否 | 说明 |

### 2.8 期初应付导入字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 对象类型 | 是 | 供应商/往来单位 |
| 供应商编码/往来单位编码 | 是 | 必须存在 |
| 应付日期 | 是 | 原业务日期 |
| 来源说明 | 是 | 旧系统期初/历史欠款 |
| 应付金额 | 是 | 原应付金额 |
| 已付金额 | 是 | 默认0或历史已付 |
| 未付金额 | 是 | 应付-已付 |
| 预计付款日 | 否 | 用于账龄 |
| 备注 | 否 | 说明 |

### 2.9 期初资金账户导入字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 资金账户编码 | 是 | 必须存在 |
| 账户名称 | 否 | 辅助校验 |
| 期初余额 | 是 | 可为0 |
| 余额方向 | 是 | 借/贷或正/负，V1.0建议正负数 |
| 备注 | 否 | 说明 |

### 2.10 初始化校验规则

| 校验项 | 规则 |
|---|---|
| 商品编码 | 必须存在且状态正常 |
| 仓库编码 | 必须存在且状态正常 |
| 客户/供应商/往来单位 | 必须存在且状态正常 |
| 数量 | 不可小于0 |
| 成本单价 | 不可小于0 |
| 金额 | 必须符合数量×单价或应收应付余额公式 |
| 重复数据 | 同商品+仓库+批次不可重复导入 |
| 已启用系统 | 系统启用后不可重复导入期初，需走调整单 |

### 2.11 启用控制

系统初始化未完成时：

- 可以维护基础资料。
- 可以导入期初数据。
- 不允许正式审核采购、销售、库存、财务业务单据。

点击“确认启用系统”后：

- 锁定期初数据。
- 生成期初库存流水。
- 生成期初应收/应付记录。
- 写入资金账户期初余额。
- 后续修改需走业务调整单。

## 三、预收款管理

### 3.1 功能定位

预收款是客户或往来单位提前支付给公司的款项，在未来产生应收后可抵扣应收。

### 3.2 页面入口

合并到：`财务管理 → 应收账款`

在应收账款模块中增加页签：

```text
应收明细 / 应收结算 / 预收款 / 收款记录 / 账龄分析
```

### 3.3 预收款来源

| 来源 | 说明 |
|---|---|
| 收款单-预收款 | 财务手工录入客户预收款 |
| 应收结算超收 | 收款金额大于应收结算金额，多余转预收 |
| 期初预收导入 | 初始化导入历史预收余额 |
| 销售退货转预收 | 已收款订单退货后金额转预收 |

### 3.4 预收款字段

| 字段 | 说明 |
|---|---|
| 预收单号 | 系统编号 |
| 对象类型 | 客户/往来单位 |
| 对象名称 | 客户或往来单位 |
| 预收日期 | 收款日期 |
| 预收金额 | 原始预收金额 |
| 已使用金额 | 已抵扣应收金额 |
| 可用余额 | 预收金额-已使用 |
| 来源单据 | 收款单/期初/退货 |
| 状态 | 可用/已用完/已关闭 |

### 3.5 预收款使用规则

- 同一客户的预收款只能抵扣该客户应收。
- 往来单位预收款只能抵扣该往来单位应收。
- 抵扣金额不可超过预收可用余额。
- 预收款抵扣应收时生成核销记录。
- 预收款余额参与客户账户余额展示。

## 四、预付款管理

### 4.1 功能定位

预付款是公司提前支付给供应商或往来单位的款项，在未来产生应付后可抵扣应付。

### 4.2 页面入口

合并到：`财务管理 → 应付账款`

在应付账款模块中增加页签：

```text
应付明细 / 应付结算 / 预付款 / 付款记录 / 账龄分析
```

### 4.3 预付款来源

| 来源 | 说明 |
|---|---|
| 付款单-预付款 | 财务手工录入供应商预付款 |
| 采购订单生成预付款 | 采购订单有预付约定时生成 |
| 应付结算超付 | 付款金额大于应付结算金额，多余转预付 |
| 期初预付导入 | 初始化导入历史预付余额 |

### 4.4 预付款字段

| 字段 | 说明 |
|---|---|
| 预付单号 | 系统编号 |
| 对象类型 | 供应商/往来单位 |
| 对象名称 | 供应商或往来单位 |
| 预付日期 | 付款日期 |
| 预付金额 | 原始预付金额 |
| 已使用金额 | 已抵扣应付金额 |
| 占用金额 | 被采购订单占用但未抵扣金额 |
| 可用余额 | 预付金额-已使用-占用 |
| 来源单据 | 付款单/采购订单/期初 |
| 状态 | 可用/已用完/已关闭 |

### 4.5 预付款使用规则

- 同一供应商预付款只能抵扣该供应商应付。
- 往来单位预付款只能抵扣该往来单位应付。
- 采购订单可指定使用预付款，占用但不立即核销。
- 采购订单取消、关闭、终止时释放未使用占用金额。
- 应付结算时可选择预付款抵扣。

## 五、调拨单

### 5.1 功能定位

调拨单用于仓库之间库存转移，支持调出、调入、调拨在途。V1.0先支持后台调拨，不要求PDA。

### 5.2 页面入口

`库存管理 → 调拨单`

### 5.3 调拨流程

```text
新建调拨单
    │
    ├─ 选择调出仓库、调入仓库
    ├─ 添加商品、数量、批次
    ├─ 审核调拨单
    ├─ 调拨出库：扣减调出仓库存，形成调拨在途
    └─ 调拨入库：增加调入仓库存，扣减调拨在途
```

V1.0可配置两种模式：

| 模式 | 说明 |
|---|---|
| 一步调拨 | 审核后同时扣调出仓、增调入仓 |
| 两步调拨 | 先调出形成在途，再确认调入 |

建议V1.0默认使用两步调拨，业务更清晰。

### 5.4 调拨单主表字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 调拨单号 | 是 | TR编号 |
| 调拨日期 | 是 | 默认当天 |
| 调出仓库 | 是 | 来源仓库 |
| 调入仓库 | 是 | 目标仓库，不可等于调出仓 |
| 调拨类型 | 是 | 普通调拨/库存类型调整 |
| 调拨模式 | 是 | 一步/两步 |
| 状态 | 是 | 草稿/待审核/已审核/已出库/已入库/已完成/已关闭 |
| 备注 | 否 | 说明 |

### 5.5 调拨明细字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 商品 | 是 | 调拨商品 |
| 单位 | 是 | 调拨单位 |
| 批次 | 批次商品必填 | 指定批次 |
| 调出仓可用库存 | 自动 | 用于校验 |
| 调拨数量 | 是 | 大于0且不超过可用库存 |
| 成本单价 | 自动 | 调出仓当前成本 |
| 成本金额 | 自动 | 数量×成本单价 |
| 调入成本 | 自动 | 默认等于调出成本 |
| 备注 | 否 | 行备注 |

### 5.6 审核与库存影响

#### 调拨审核

- 校验调出仓与调入仓不同。
- 校验库存可用数量。
- 锁定调出仓库存或直接进入出库。

#### 调拨出库

- 扣减调出仓实物库存。
- 生成调拨出库流水。
- 增加调拨在途。

#### 调拨入库

- 增加调入仓实物库存。
- 生成调拨入库流水。
- 扣减调拨在途。
- 调拨单状态变为已完成。

### 5.7 成本规则

| 场景 | 成本处理 |
|---|---|
| 同成本分组仓库调拨 | 成本不变 |
| 跨成本分组仓库调拨 | 调入仓按调出仓成本作为入库成本 |
| 调拨在途 | 不计入调入仓可用库存 |

## 六、应收账款与应收结算合并

### 6.1 新菜单结构

原：

```text
财务管理 → 应收账款
财务管理 → 应收结算
```

调整为：

```text
财务管理 → 应收账款
```

应收账款内含页签：

```text
应收明细
应收结算
预收款
收款记录
账龄分析
逾期预警
```

### 6.2 应收账款页面布局

```text
应收账款
├─ 页签：应收明细 / 应收结算 / 预收款 / 收款记录 / 账龄分析
├─ 查询条件
├─ 应收列表
├─ 结算侧栏或结算弹窗
└─ 操作：收款结算、核销、查看来源、导出
```

### 6.3 应收明细与结算关系

应收明细列表中支持直接勾选应收单，然后点击：

```text
收款结算
```

系统打开结算区：

- 选择收款方式。
- 选择资金账户。
- 输入本次收款金额。
- 可选择预收款抵扣。
- 可填写折让金额。
- 确认后生成收款单并核销。

### 6.4 应收结算支持预收款抵扣

结算时金额来源可包括：

| 来源 | 说明 |
|---|---|
| 本次实收 | 现金/银行/微信/支付宝等 |
| 预收款抵扣 | 使用客户预收余额 |
| 折让金额 | 财务折让，需权限 |

计算：

```text
应收未收金额 = 本次实收 + 预收抵扣 + 折让金额 + 结算后剩余
```

```text
付款结算
```

系统打开结算区：

- 选择付款方式。
- 选择资金账户。
- 输入本次付款金额。

### 7.3 应付结算支持预付款抵扣

| 来源 | 说明 |
|---|---|

| 折让金额 | 对方让利/抹零 |

计算：

```text
应付未付金额 = 本次实付 + 预付抵扣 + 折让金额 + 结算后剩余
```
