## 一、通用页面规范

### 1.1 列表页通用结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 页面标题  说明文字                              [主要操作按钮] │
├──────────────────────────────────────────────────────────────┤
│ 查询条件：常用条件...                         [查询] [重置]    │
│ 更多条件：展开/收起                                             │
├──────────────────────────────────────────────────────────────┤
│ 批量操作：[导入] [导出] [批量启用] [批量停用]                   │
├──────────────────────────────────────────────────────────────┤
│ 表格：选择框 | 编码 | 名称 | 状态 | 创建人 | 创建时间 | 操作      │
├──────────────────────────────────────────────────────────────┤
│ 分页：总数、每页条数、页码                                      │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 表单页通用结构

```text
基本信息
业务信息
扩展信息
附件/备注
底部操作：[保存草稿] [保存] [取消]
```

### 1.3 必备交互

- 新增/编辑表单必填项使用红色星号。
- 保存失败必须定位到错误字段。
- 删除/停用/审核等高风险操作必须二次确认。
- 导入失败必须可下载失败原因。
- 所有新增、修改、删除、导入、导出、停用、启用操作写入操作日志。

## 二、用户管理

### 2.1 页面入口

`系统管理 → 用户管理`

### 2.2 页面定位

管理所有可登录系统的账号，控制用户权限、数据范围和账号状态。

### 2.3 查询条件

| 条件 | 控件 | 默认 | 说明 |
|---|---|---|---|
| 账号/名称 | 输入框 | 空 | 支持账号、用户名称、手机号模糊搜索 |
| 手机号 | 输入框 | 空 | 精确/模糊搜索 |
| 权限组 | 下拉多选 | 全部 | 来源权限组 |
| 状态 | 下拉 | 全部 | 正常/停用/锁定 |
| 绑定人员 | 输入框 | 空 | 员工姓名模糊搜索 |
| 创建时间 | 日期范围 | 空 | 按创建时间筛选 |

### 2.4 列表字段

| 字段 | 说明 |
|---|---|
| 账号 | 登录账号，点击进入详情 |
| 用户名称 | 显示名称 |
| 手机号 | 脱敏显示，如138****8888 |
| 绑定人员 | 员工档案 |
| 权限组 | 权限模板 |
| 数据范围 | 简要展示：全部/指定仓库/指定客户等 |
| 状态 | 正常/停用/锁定 |
| 最后登录时间 | 最近一次登录 |
| 创建人 | 创建账号的人 |

### 2.5 新增/编辑表单

#### 基本信息

| 字段 | 必填 | 控件 | 校验 |
|---|:---:|---|---|

#### 数据范围

| 范围 | 控件 | 说明 |
|---|---|---|
| 货主范围 | 多选 | 默认全部 |

| 权限 | 说明 |
|---|---|

| 查看采购金额 | 控制采购金额字段 |

### 2.6 按钮操作

| 按钮 | 规则 |
|---|---|
| 新建用户 | 有用户新增权限 |
| 编辑 | 正常/停用/锁定均可编辑基础资料 |
| 停用 | admin不可停用；停用后不可登录 |

| 场景 | 提示 |

| 账号重复 | 登录账号已存在，请更换 |
| 手机号格式错误 | 请输入正确手机号 |
| 员工已绑定 | 该人员已绑定其他账号 |
| 权限组停用 | 所选权限组已停用，不可保存 |
| 停用admin | 系统内置管理员不可停用 |

### 2.8 验收用例

| 编号 | 场景 | 步骤 | 预期 |
|---|---|---|---|
| SYS-USER-001 | 新建用户 | 填写账号、手机号、权限组保存 | 用户创建成功，可登录 |
| SYS-USER-002 | 数据范围 | 设置用户仅可看A仓 | 登录后库存只显示A仓 |
| SYS-USER-003 | 字段权限 | 关闭成本权限 | 库存和销售页不显示成本/毛利 |
| SYS-USER-004 | 停用用户 | 停用账号后登录 | 登录失败，提示账号停用 |

## 三、权限组管理

### 3.1 页面入口

`系统管理 → 权限组管理`

### 3.2 页面布局

三栏结构：

```text
左侧：权限组列表
中间：菜单/模块树
右侧：功能权限、字段权限、数据权限
```

### 3.3 权限组字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 权限组编码 | 是 | 唯一，如 SALES |
| 权限组名称 | 是 | 如销售组 |
| 是否系统内置 | 否 | 内置不可删除 |
| 状态 | 是 | 正常/停用 |
| 备注 | 否 | 权限说明 |

### 3.4 功能权限项

每个模块至少包含：查看、新增、修改、删除、审核、反审核、关闭、导入、导出、打印、查看日志。

### 3.5 业务规则

- 权限组停用后，已关联用户不可继续使用该组权限，登录时提示权限组停用。
- 被用户引用的权限组不可删除。
- 修改权限组后，关联用户下次请求立即生效。
- 可复制权限组快速创建新权限组。

## 七、供应商资料

### 7.1 页面入口

`基础资料 → 供应商资料`

### 7.2 字段

供应商编码、名称、简称、联系人、电话、地址、到货天数、结算方式、账期天数、默认采购员、发票信息、收款账户信息、状态、备注。

### 7.3 收款账户信息

供应商资料必须支持维护多个收款账户。付款给供应商时，付款单需选择本次付款进入哪个供应商收款账户。

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 账户名称 | 是 | 如默认账户、备用账户 |
| 开户行 | 是 | 银行名称 |
| 银行账号 | 是 | 收款账号 |
| 收款户名 | 是 | 通常为供应商公司名称 |
| 是否默认账户 | 是 | 一个供应商只能有一个默认账户 |
| 状态 | 是 | 正常/停用 |
| 备注 | 否 | 账户说明 |

### 7.4 业务规则

- 停用供应商不可新建采购订单。
- 到货天数用于采购订单预计到货日。
- 供应商可维护多个收款账户、联系人和发票信息。
- 一个供应商必须最多只有一个默认收款账户；设置新的默认账户时，原默认账户自动取消默认。
- 停用的收款账户不可在付款单中选择。
- 供应商付款单选择供应商后，默认带出该供应商的默认收款账户，也允许用户切换为其他正常账户。
- 已有采购记录不可删除。

## 九、客户价格设置

### 9.1 页面入口

`基础资料 → 客户价格设置`

### 9.2 页面定位

客户价格设置不再直接维护单条客户专属价，改为“客户价格调整单 + 客户价格查询”两类页面：

1. **客户价格调整单**：通过单据方式批量调整某客户多个商品现价，审核后才确认生效。
2. **客户价格查询**：查询客户价格调整单及明细，支持按门店、商品、生效状态检索，并可停用已生效价格。

销售开单价格匹配仍遵循：客户有效专属价优先，高于客户等级价/价格组价和标准售价。

### 9.3 客户价格调整单列表

#### 查询条件

| 条件 | 控件 | 说明 |
|---|---|---|

| 单据日期 | 日期范围 | 默认本月 |
| 生效方式 | 下拉 | 全部/立即生效/定时生效 |
| 审核状态 | 下拉 | 草稿/待审核/已审核/已作废 |
| 制单人 | 下拉/搜索 | 按制单人筛选 |

#### 列表字段

| 字段 | 说明 |
|---|---|

| 明细数 | 调整商品数量 |

| 审核信息 | 审核人、审核时间、审核状态 |
| 操作 | 查看、编辑、审核、作废、导出 |

### 9.4 新建/编辑客户价格调整单

客户价格调整单属于中高复杂度批量维护单据，采用独立页面承载，不使用小弹窗。审核前可修改；审核后不可修改，只能作废或通过新调整单覆盖。

#### 单据头字段

| 字段 | 必填 | 控件 | 说明 |
|---|:---:|---|---|
| 客户 | 是 | 搜索选择 | 先选择客户；明细商品价格按该客户价格组或标准价带出原价 |
| 生效方式 | 是 | 单选 | 立即生效/定时生效 |
| 生效时间点 | 条件必填 | 日期时间 | 生效方式=定时生效时必填 |
| 价格有效范围 | 是 | 单选+日期 | 长期有效/指定日期范围；指定范围需填开始、结束日期 |
| 备注 | 否 | 文本域 | 500字以内 |

#### 明细字段

| 字段 | 必填 | 是否可编辑 | 说明 |
|---|:---:|:---:|---|
| 商品编号 | 是 | 否 | 商品档案编码 |
| 商品名称 | 是 | 否 | 商品名称 |
| 基本单位 | 是 | 否 | 商品库存基本单位 |
| 规格 | 否 | 否 | 商品规格型号 |
| 条码 | 否 | 否 | 商品默认条码 |
| 原价 | 是 | 否 | 对应该客户价格组默认价格；无价格组价时取商品标准价 |
| 现价 | 是 | 是 | 本次调整后的客户专属价，必须 ≥0 |
| 最新进价 | 否 | 否 | 最近采购入库/采购收货价格，受权限控制 |
| 成本价 | 否 | 否 | 当前成本价，受成本权限控制 |

#### 商品添加方式

| 方式 | 说明 |
|---|---|
| 表格录入 | 在明细表直接录入/扫描商品编号或条码，回车带出商品信息和原价 |
| 从商品档案添加 | 打开商品选择弹窗，按分类、品牌、关键字筛选后批量加入 |
| 导入商品 | 上传商品清单，按商品编号匹配并带出商品资料 |

#### 保存与审核

- 新建保存后返回客户价格调整单列表。
- 保存状态为草稿或待审核，不直接生效。
- 审核后价格调整单才确认，并按生效方式进入“已生效/待生效”状态。
- 审核时生成或更新客户价格明细；最新审核的调价自动覆盖同客户同商品的历史生效价，历史价格自动停用。
- 审核前允许修改单据头和明细；审核后不可修改现价。
- 作废已审核调整单时，仅作废该单据，不自动恢复被覆盖的历史价格，需重新制单调整。

### 9.5 批量导入生成调整单

支持批量导入横版字段生成客户价格调整单。

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 门店编号 | 是 | 对应客户编码 |
| 商品编号 | 是 | 对应商品编码 |
| 现价 | 是 | 调整后的价格 |

导入规则：

- 按门店编号分组生成一张或多张客户价格调整单。
- 同一门店 + 商品重复时，默认保留最后一行，并在导入校验结果中提示。
- 门店或商品不存在、停用、现价为空或小于0时，该行校验失败。
- 导入生成的调整单仍需人工审核后生效。

| 生效状态 | 下拉 | 全部/待生效/生效中/已停用/已过期 |
| 单号 | 输入框 | 来源客户价格调整单号 |
| 有效日期 | 日期范围 | 查询覆盖该日期范围的价格 |

#### 列表字段

| 字段 | 说明 |
|---|---|
| 单号 | 来源客户价格调整单号 |
| 客户编号/名称 | 门店编号与名称 |
| 单据日期 | 来源调整单日期 |
| 生效方式 | 立即生效/定时生效 |
| 有效范围 | 长期有效/起止日期 |
| 商品编号 | 商品编码 |
| 商品名称 | 商品名称 |

| 最新进价 | 最近进价，受权限控制 |
| 成本价 | 成本价，受权限控制 |
| 生效状态 | 待生效/生效中/已停用/已过期 |
| 操作 | 查看来源单、停用 |

#### 停用处理

- 可勾选一个或多个客户价格明细进行停用。
- 停用需二次确认并填写原因。
- 停用后该价格不再参与销售开单价格匹配。
- 停用操作记录操作人、操作时间和停用原因。

### 9.7 业务规则

- 同一客户、商品、基本单位在同一时间点只能有一个生效价格。
- 最新审核生效的调价自动覆盖前一条生效价，前一条自动停用。
- 定时生效单据审核后进入待生效，到达生效时间点后自动生效。
- 指定有效范围到期后自动变为已过期，不再参与销售开单。
- 原价取值顺序：客户对应价格组默认价格 → 商品标准价。
- 销售开单时优先匹配当前客户、商品、基本单位、生效中且在有效范围内的最新客户专属价。
- 成本价、最新进价字段按采购/成本权限控制显示和导出。

## 十二、V1.0增强基础资料规则

### 12.1 往来单位管理

V1.0往来单位不再只是基础档案，还必须支持应收、应付、收款、付款和结算。详细规则见 `13-V1.0-增强模块与统一规则详细PRD.md`。

页面入口：`基础资料 → 往来单位`

核心能力：

- 维护物流公司、物业、个人、服务商等非客户/供应商对象。
- 费用收入可生成往来单位应收。
- 费用支出可生成往来单位应付。
- 收款单、付款单支持选择往来单位。
- 应收结算、应付结算支持往来单位。

### 12.2 费用类型

页面入口：`基础资料 → 费用类型`

费用类型支持最多三级，用于费用单和采购费用单。字段包含：费用类型编码、名称、上级类型、方向、是否采购费用、是否参与成本、状态。

### 12.3 客户/供应商导入修改和批量修改

客户资料、供应商资料除新增导入外，必须支持导入修改和批量修改字段值：

- 客户支持批量修改客户等级、客户类型、片区、线路、业务员、结算方式、账期天数、信用额度、状态。
- 供应商支持批量修改结算方式、账期天数、默认采购员、状态、到货天数、银行账户和发票信息。
- 导入修改必须先预校验，失败行可下载失败原因。
- 高风险字段如信用额度、结算方式、状态修改需二次确认并记录操作日志。

### 12.4 单据编号规则与显示精度

系统管理需增加：

- `单据编号规则`：统一维护所有业务单据前缀、日期段、流水号位数和重置周期。
- `显示精度设置`：数量、单价、金额、成本单价显示位数可配置，只可增大，不可改小。
