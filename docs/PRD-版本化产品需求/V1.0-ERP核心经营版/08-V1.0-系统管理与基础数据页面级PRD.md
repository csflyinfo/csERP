> 文档版本：v1.0  
> 编写日期：2026-06-13  
> 适用版本：V1.0 ERP核心经营版  
> 文档目的：将系统管理与基础数据模块细化到可用于UI原型、前端开发、后端接口和测试用例编写的页面级颗粒度

## 一、通用页面规范

### 1.1 列表页通用结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 页面标题  说明文字                              [主要操作按钮] │
├──────────────────────────────────────────────────────────────┤
│ 查询条件：常用条件...                         [查询] [重置]    │
│ 更多条件：展开/收起                                             │
├──────────────────────────────────────────────────────────────┤
│ 批量操作：[导入] [导出] [批量启用] [批量停用]                   │
├──────────────────────────────────────────────────────────────┤
│ 表格：选择框 | 编码 | 名称 | 状态 | 创建人 | 创建时间 | 操作      │
├──────────────────────────────────────────────────────────────┤
│ 分页：总数、每页条数、页码                                      │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 表单页通用结构

```text
基本信息
业务信息
扩展信息
附件/备注
底部操作：[保存草稿] [保存] [取消]
```

### 1.3 必备交互

- 新增/编辑表单必填项使用红色星号。
- 保存失败必须定位到错误字段。
- 删除/停用/审核等高风险操作必须二次确认。
- 导入失败必须可下载失败原因。
- 所有新增、修改、删除、导入、导出、停用、启用操作写入操作日志。

## 二、用户管理

### 2.1 页面入口

`系统管理 → 用户管理`

### 2.2 页面定位

管理所有可登录系统的账号，控制用户权限、数据范围和账号状态。

### 2.3 查询条件

| 条件 | 控件 | 默认 | 说明 |
|---|---|---|---|
| 账号/名称 | 输入框 | 空 | 支持账号、用户名称、手机号模糊搜索 |
| 手机号 | 输入框 | 空 | 精确/模糊搜索 |
| 权限组 | 下拉多选 | 全部 | 来源权限组 |
| 状态 | 下拉 | 全部 | 正常/停用/锁定 |
| 绑定人员 | 输入框 | 空 | 员工姓名模糊搜索 |
| 创建时间 | 日期范围 | 空 | 按创建时间筛选 |

### 2.4 列表字段

| 字段 | 说明 |
|---|---|
| 账号 | 登录账号，点击进入详情 |
| 用户名称 | 显示名称 |
| 手机号 | 脱敏显示，如138****8888 |
| 绑定人员 | 员工档案 |
| 权限组 | 权限模板 |
| 数据范围 | 简要展示：全部/指定仓库/指定客户等 |
| 状态 | 正常/停用/锁定 |
| 最后登录时间 | 最近一次登录 |
| 创建人 | 创建账号的人 |
| 创建时间 | 创建时间 |
| 操作 | 编辑、重置密码、停用/启用、解锁、日志 |

### 2.5 新增/编辑表单

#### 基本信息

| 字段 | 必填 | 控件 | 校验 |
|---|:---:|---|---|
| 登录账号 | 是 | 输入框 | 唯一，字母数字下划线，3-30位 |
| 用户名称 | 是 | 输入框 | 1-50字 |
| 手机号 | 是 | 输入框 | 手机号格式 |
| 邮箱 | 否 | 输入框 | 邮箱格式 |

| 状态 | 是 | 单选 | 正常/停用 |
| 备注 | 否 | 文本域 | 500字以内 |

#### 数据范围

| 范围 | 控件 | 说明 |
|---|---|---|
| 货主范围 | 多选 | 默认全部 |
| 仓库范围 | 多选 | 仓库员通常限制仓库 |
| 客户范围 | 多选/按片区 | 销售人员限制客户 |

| 品牌范围 | 多选 | 控制商品品牌 |

#### 字段权限

| 权限 | 说明 |
|---|---|
| 查看销售金额 | 控制销售金额字段 |
| 查看采购金额 | 控制采购金额字段 |
| 查看成本 | 控制成本单价、库存金额 |
| 查看毛利 | 控制毛利和毛利率 |
| 查看客户欠款 | 控制应收余额 |
| 查看供应商余额 | 控制应付余额 |

### 2.6 按钮操作

| 按钮 | 规则 |
|---|---|
| 新建用户 | 有用户新增权限 |
| 编辑 | 正常/停用/锁定均可编辑基础资料 |
| 停用 | admin不可停用；停用后不可登录 |
| 启用 | 停用账号可启用 |
| 重置密码 | 二次确认，记录日志 |
| 解锁 | 仅锁定状态显示 |
| 导入 | 下载模板后上传 |

| 场景 | 提示 |
|---|---|
| 账号重复 | 登录账号已存在，请更换 |
| 手机号格式错误 | 请输入正确手机号 |
| 员工已绑定 | 该人员已绑定其他账号 |
| 权限组停用 | 所选权限组已停用，不可保存 |
| 停用admin | 系统内置管理员不可停用 |

### 2.8 验收用例

| 编号 | 场景 | 步骤 | 预期 |
|---|---|---|---|
| SYS-USER-001 | 新建用户 | 填写账号、手机号、权限组保存 | 用户创建成功，可登录 |
| SYS-USER-002 | 数据范围 | 设置用户仅可看A仓 | 登录后库存只显示A仓 |
| SYS-USER-003 | 字段权限 | 关闭成本权限 | 库存和销售页不显示成本/毛利 |
| SYS-USER-004 | 停用用户 | 停用账号后登录 | 登录失败，提示账号停用 |

## 三、权限组管理

### 3.1 页面入口

`系统管理 → 权限组管理`

### 3.2 页面布局

三栏结构：

```text
左侧：权限组列表
中间：菜单/模块树
右侧：功能权限、字段权限、数据权限
```

### 3.3 权限组字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 权限组编码 | 是 | 唯一，如 SALES |
| 权限组名称 | 是 | 如销售组 |
| 是否系统内置 | 否 | 内置不可删除 |
| 状态 | 是 | 正常/停用 |
| 备注 | 否 | 权限说明 |

### 3.4 功能权限项

每个模块至少包含：查看、新增、修改、删除、审核、反审核、关闭、导入、导出、打印、查看日志。

### 3.5 业务规则

- 权限组停用后，已关联用户不可继续使用该组权限，登录时提示权限组停用。
- 被用户引用的权限组不可删除。
- 修改权限组后，关联用户下次请求立即生效。
- 可复制权限组快速创建新权限组。

## 六、客户资料

### 6.1 页面入口

`基础资料 → 客户资料`

### 6.2 查询条件

客户编码/名称/手机号、渠道类型、客户等级、片区、线路、业务员、状态。

### 6.3 列表字段

客户编码、客户名称、渠道类型、联系人、手机号、片区、线路、业务员、客户等级、**价格组**、结算方式（派生 `settlementText`，按 [账期管理-产品说明](../../账期管理-产品说明.md) 摘要）、收货地址、信用额度、应收余额、逾期金额、状态、操作。

### 6.4 表单字段

采用 480 宽侧抽屉；下拉数据全部走后端真实数据源，不再用硬编码。

#### 基本信息

|字段|控件|说明|
|---|---|---|
|客户编码|输入框|新建可编辑；编辑锁定|
|客户名称|输入框（必填）||
|渠道类型|下拉|数据源 = 字典 `customer_channel`（V10 预置：零售商超/便利店/餐饮店/批发商/电商平台）|
|联系人 / 手机号|输入框||
|片区|下拉|数据源 = 片区管理里**末级片区**（无下级的片区）|
|线路|下拉|数据源 = 线路管理正常记录|
|业务员|下拉|`GET /base/employee/salesmen`，人员管理中 `is_salesman=true` 且 `status=NORMAL`|
|客户等级|下拉|金牌/银牌/铜牌/普通|
|**价格组**|下拉|数据源 = 价格组模块 `enabled=true` 且 `status=NORMAL`；首项「（空 - 取商品默认售价）」；新建默认空 |
|信用额度|数字||
|发票抬头 / 税号|输入框||
|**经度 / 纬度**|数字|收货地址地理坐标（DECIMAL 11,7 / 10,7）|
|**状态**|下拉（仅编辑显示）|正常 / 停用|
|**收货地址**|多行文本|独占一行|

#### 账期设置

内嵌 `SettlementPanel`，字段包括：结算方式（预付 / 货到付款 / 账期）、账期类型（固定 / 周结 / 半月结 / 月结）、账期天数、截账日、付款模式（A/B）、账期月数、付款日。**完整规则见 [账期管理-产品说明](../../账期管理-产品说明.md)**。

- 「货到付款」文案区分：客户抽屉显示「客户签收日」；供应商抽屉显示「入库签收日」。
- 「月结」选中时付款模式默认 = A。
- 单选控件 16px 大小，紧凑排布。

### 6.5 业务规则

- 冻结/停用客户不可下单
- 默认地址必须且只能有一个（V1.0 用单一 `shipping_address` 字段；多地址子表 V2.0）
- 保存/更新时若 `priceGroupCode` 引用了未启用的价格组会被后端拦截（后续实现）
- 结算方式变更后未结算单据按新规则重算结算日（见账期规范 §6.3）

## 七、供应商资料

### 7.1 页面入口

`基础资料 → 供应商资料`

### 7.2 字段

采用 480 宽侧抽屉；含子表「收款账户」网格。

|字段|控件|说明|
|---|---|---|
|供应商编码|输入框|新建可编辑；编辑锁定|
|供应商名称|输入框（必填）||
|简称|输入框||
|供应商类型|下拉|字典 `supplier_type`|
|联系人 / 电话 / 地址 / 备注|输入框 / 多行文本||
|到货天数|数字||
|默认采购员|下拉|`POST /base/employee/buyers`，人员管理中 `is_buyer=true` 且 `status=NORMAL`|
|**交货方式**|下拉|字典 `delivery_method`（预置：送货上门 / 到厂自提 / 物流站自提）；新建默认「送货上门」|
|**默认物流公司**|下拉|字典 `logistics_company`（在字典模块维护）|
|状态|下拉（仅编辑显示）|正常 / 停用|

**账期设置**：同客户，内嵌 `SettlementPanel`，货到付款文案显示「入库签收日」。

**去除的字段**：V6 起前端表单不再展示「发票抬头」「税号」（税务信息保留列以兼容旧数据，仅隐藏）。

### 7.3 收款账户（子表 · 网格）

供应商抽屉内嵌网格 `base_supplier_bank_account`，一供应商可维护多条：

|字段|说明|
|---|---|
|户名 | 必填|
|开户银行 | 银行名称|
|银行账号 | 必填|
|支行 | 可选|
|默认 | 单选（同一供应商只允许一个 `is_default=1`）|
|备注 | 可选|
|操作 | 删除 / 上移 / 下移|

**保存策略**：全量替换 — 保存供应商时先删除该供应商所有账户再重新插入，避免脏数据。付款单选择供应商后自动带出默认账户，可切换。

### 7.4 业务规则

- 停用供应商不可新建采购订单
- 到货天数用于采购订单预计到货日

- 交货方式和默认物流公司作为默认值带入采购订单，可在单据上调整

## 九、客户价格设置

### 9.1 页面入口

`基础资料 → 客户价格设置`

### 9.2 页面定位

客户价格设置不再直接维护单条客户专属价，改为“客户价格调整单 + 客户价格查询”两类页面：

1. **客户价格调整单**：通过单据方式批量调整某客户多个商品现价，审核后才确认生效。
2. **客户价格查询**：查询客户价格调整单及明细，支持按门店、商品、生效状态检索，并可停用已生效价格。

销售开单价格匹配仍遵循：客户有效专属价优先，高于客户等级价/价格组价和标准售价。

### 9.3 客户价格调整单列表

| 审核状态 | 下拉 | 草稿/待审核/已审核/已作废 |
| 制单人 | 下拉/搜索 | 按制单人筛选 |

#### 列表字段

| 字段 | 说明 |
|---|---|
| 单号 | 客户价格调整单号，双击行或点击单号查看详情 |
| 客户 | 客户编号 + 客户名称 |
| 单据日期 | 制单日期 |
| 生效方式 | 立即生效/定时生效；定时生效显示生效时间点 |
| 有效范围 | 长期有效/指定日期范围 |
| 明细数 | 调整商品数量 |
| 制单信息 | 制单人、制单时间 |
| 审核信息 | 审核人、审核时间、审核状态 |
| 操作 | 查看、编辑、审核、作废、导出 |

### 9.4 新建/编辑客户价格调整单

客户价格调整单属于中高复杂度批量维护单据，采用独立页面承载，不使用小弹窗。审核前可修改；审核后不可修改，只能作废或通过新调整单覆盖。

#### 单据头字段

| 字段 | 必填 | 控件 | 说明 |
|---|:---:|---|---|
| 客户 | 是 | 搜索选择 | 先选择客户；明细商品价格按该客户价格组或标准价带出原价 |
| 生效方式 | 是 | 单选 | 立即生效/定时生效 |
| 生效时间点 | 条件必填 | 日期时间 | 生效方式=定时生效时必填 |
| 价格有效范围 | 是 | 单选+日期 | 长期有效/指定日期范围；指定范围需填开始、结束日期 |
| 备注 | 否 | 文本域 | 500字以内 |

#### 明细字段

| 字段 | 必填 | 是否可编辑 | 说明 |
|---|:---:|:---:|---|
| 商品编号 | 是 | 否 | 商品档案编码 |
| 商品名称 | 是 | 否 | 商品名称 |
| 基本单位 | 是 | 否 | 商品库存基本单位 |
| 规格 | 否 | 否 | 商品规格型号 |
| 条码 | 否 | 否 | 商品默认条码 |

| 成本价 | 否 | 否 | 当前成本价，受成本权限控制 |

#### 商品添加方式

| 方式 | 说明 |
|---|---|
| 表格录入 | 在明细表直接录入/扫描商品编号或条码，回车带出商品信息和原价 |
| 从商品档案添加 | 打开商品选择弹窗，按分类、品牌、关键字筛选后批量加入 |
| 导入商品 | 上传商品清单，按商品编号匹配并带出商品资料 |

#### 保存与审核

- 新建保存后返回客户价格调整单列表。
- 保存状态为草稿或待审核，不直接生效。
- 审核后价格调整单才确认，并按生效方式进入“已生效/待生效”状态。
- 审核时生成或更新客户价格明细；最新审核的调价自动覆盖同客户同商品的历史生效价，历史价格自动停用。
- 审核前允许修改单据头和明细；审核后不可修改现价。
- 作废已审核调整单时，仅作废该单据，不自动恢复被覆盖的历史价格，需重新制单调整。

### 9.5 批量导入生成调整单

支持批量导入横版字段生成客户价格调整单。

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 门店编号 | 是 | 对应客户编码 |
| 商品编号 | 是 | 对应商品编码 |
| 现价 | 是 | 调整后的价格 |

导入规则：

- 按门店编号分组生成一张或多张客户价格调整单。
- 同一门店 + 商品重复时，默认保留最后一行，并在导入校验结果中提示。
- 门店或商品不存在、停用、现价为空或小于0时，该行校验失败。
- 导入生成的调整单仍需人工审核后生效。

### 9.6 客户价格查询

#### 查询条件

| 条件 | 控件 | 说明 |
|---|---|---|
| 门店/客户 | 搜索选择 | 支持客户编号、名称 |
| 商品 | 搜索选择 | 支持商品编号、名称、条码 |
| 生效状态 | 下拉 | 全部/待生效/生效中/已停用/已过期 |
| 单号 | 输入框 | 来源客户价格调整单号 |
| 有效日期 | 日期范围 | 查询覆盖该日期范围的价格 |

#### 列表字段

| 字段 | 说明 |
|---|---|
| 单号 | 来源客户价格调整单号 |
| 客户编号/名称 | 门店编号与名称 |
| 单据日期 | 来源调整单日期 |
| 生效方式 | 立即生效/定时生效 |
| 有效范围 | 长期有效/起止日期 |
| 商品编号 | 商品编码 |
| 商品名称 | 商品名称 |
| 基本单位 | 商品基本单位 |
| 规格 | 商品规格 |
| 条码 | 商品默认条码 |
| 原价 | 价格组默认价格或标准价 |
| 现价 | 当前客户专属价 |
| 最新进价 | 最近进价，受权限控制 |
| 成本价 | 成本价，受权限控制 |
| 生效状态 | 待生效/生效中/已停用/已过期 |
| 操作 | 查看来源单、停用 |

#### 停用处理

- 可勾选一个或多个客户价格明细进行停用。
- 停用需二次确认并填写原因。
- 停用后该价格不再参与销售开单价格匹配。
- 停用操作记录操作人、操作时间和停用原因。

### 9.7 业务规则

- 同一客户、商品、基本单位在同一时间点只能有一个生效价格。
- 最新审核生效的调价自动覆盖前一条生效价，前一条自动停用。
- 定时生效单据审核后进入待生效，到达生效时间点后自动生效。
- 指定有效范围到期后自动变为已过期，不再参与销售开单。
- 原价取值顺序：客户对应价格组默认价格 → 商品标准价。
- 销售开单时优先匹配当前客户、商品、基本单位、生效中且在有效范围内的最新客户专属价。
- 成本价、最新进价字段按采购/成本权限控制显示和导出。

- 操作：启用 / 停用（切换 `is_active`）
- 筛选：商品编码/名称、是否启用

停用仅影响展示与开单引用，不删除记录。

### 13.2 价格组调价单

页面入口：`基础资料 → 价格组调价单`。

**新建/编辑走专用抽屉**（PriceAdjustDrawer），流程 `草稿 DRAFT → 待审核 PENDING → 已审核 APPROVED / 已驳回 REJECTED`。

- 单据头：调价单号（自动 `TJ + yyyyMMdd + 3位流水`）、价格组（必选下拉，仅启用中）、备注
- 明细：小/中/大三个单位新价格（NULL 表示不调整）；每行至少一个单位有价
- 明细来源：
  - **手动添加**：商品选择器（搜索 + 多选）
  - **Excel 导入**：列 `商品编码 / 商品名称 / 小单位新价格 / 中单位新价格 / 大单位新价格`；提供模板下载

按状态展示不同按钮：

|状态|列表操作|抽屉按钮|
|---|---|---|
|DRAFT|查看 / 提交 / 删除|保存草稿 / 保存并提交审核|
|PENDING|查看 / 审核通过 / 驳回|审核通过 / 驳回|
|APPROVED / REJECTED|查看|只读|

审核通过时：`upsert base_price_group_item`（有则更价格，无则首次设价）+ 写变价日志 (`ADJUST_INIT` 首次 / `ADJUST_UPDATE` 后续)。

### 13.3 价格组变价查询

页面入口：`基础资料 → 价格组变价查询`。

只读列表 + 多维筛选。

- 列：`变价时间 / 调价单号 / 价格组 / 商品编码 / 商品名称 / 单位级别 / 变价前 / 变价后 / 变动幅度 / 变更类型 / 操作人 / 备注`
- 筛选：价格组、商品编码/名称、调价单号、操作人
- **变动幅度**：`(变价后 - 变价前) / 变价前 × 100%`；首次设价显示"首次设价"而非百分比
- 导出：xlsx，上限 10000 条

### 13.4 数据模型

新增 4 张表（Flyway V5）：

|---|---|
|`base_price_group_item`|价格组商品价格，`(goods_code, price_group_code, unit_level)` 三键；含 `is_active`|

|`base_price_change_log`|变价日志，含 order_id / old_price / new_price / change_type|

## 十四、数据字典模块

### 14.1 页面入口

`系统管理 → 用户数据字典`

### 14.2 页面结构

**左右布局**：

- 左侧网格：字典类型列表（数据源 `sys_dictionary_type`）
- 右侧网格：所选字典类型下的字典值（数据源 `sys_dictionary`，按 `dict_type` 过滤）

### 14.3 字典类型（左侧）

**V1.0 全部字典类型由系统预置，不允许在界面新建/编辑/删除**。V7 及后续 seed：

|dict_type|dict_type_name|is_system|
|---|---|---|
|delivery_method|交货方式|1|
|logistics_company|物流公司|1|
|customer_channel|客户渠道|1|
|supplier_type|供应商类型|1|
|settlement_method|结算方式|1|

新增类型需 DBA/开发通过 Flyway 迁移添加。

### 14.4 字典值（右侧）

选中左侧类型后展示其字典值列表。

**字段**：

|字段|说明|
|---|---|
|dict_code|字典编码。**系统预置值按顺序号从 0 递增**（V8 起：如交货方式 0/1/2）|
|dict_name|字典名称|
|sort_order|排序|
|is_system|系统预置值。仅允许改名称/顺序/停用，不允许删除或改编码|
|remark|备注|
|status|正常 / 停用|

**操作**：新建、编辑、停用、启用、删除（仅非系统值可删）、**导入**（Excel 批量新增）、**导出**（xlsx）。

### 14.5 公共取值 API

**后端**：`GET /base/dictionary?type=xxx` → `[{ code, name, sortOrder }]`，仅返回 `status=NORMAL`。

**前端**：`utils/dictionary.js` 封装：

```js
import { getDict, invalidateDict } from '@/utils/dictionary'

const list = await getDict('delivery_method')   // [{ code, name, sortOrder }]
invalidateDict('delivery_method')               // 字典维护后主动失效缓存
```

带 5 分钟内存缓存；字典维护页面保存后调用 `invalidateDict(type)` 使缓存失效。

### 14.6 业务规则

- 停用的字典值在所有引用位置的下拉里**不再出现**，但已保存的历史数据展示不受影响
- 引用了某字典值的业务记录不阻止字典值停用（软停），但可校验删除
- 字典编码全局在同一 `dict_type` 内唯一
