# V1.0 ERP核心经营版 — 业务单位与基本单位换算规则PRD

> 文档版本：v1.0  
> 编写日期：2026-06-13  
> 适用范围：采购、销售、库存、退货、报损、调拨等所有涉及商品数量的业务单据  
> 文档目的：统一“业务开单单位”和“库存底层基本单位”的关系，支持经销商按箱、件、包、瓶等不同业务单位开单，同时保证库存、成本、批次、流水按基本单位统一核算。

---

## 一、核心结论

经销商 ERP 不应固定只能按小单位或大单位开单。V1.0统一采用：

```text
业务开单允许选择业务单位；库存底层统一换算为基本单位。
```

即：

```text
用户可按箱、件、包、瓶等业务单位开单
系统库存、成本、批次、库存流水统一按商品基本单位计算
```

---

## 二、适用业务单据

以下单据明细均需支持业务单位开单，并保存基本单位换算结果：

| 模块 | 单据 | 默认业务单位 |
|---|---|---|
| 采购 | 采购订单 | 默认大单位；无大单位时取商品默认采购单位；再无则取基本单位 |
| 采购 | 采购入库 | 继承采购订单业务单位，可调整 |
| 采购 | 采购退货 | 默认原采购/入库单位，可调整 |
| 销售 | 销售订单 | 默认小单位/商品默认销售单位，可选择大/中/小单位 |
| 销售 | 销售出库 | 继承销售订单业务单位，可调整 |
| 销售 | 销售退货 | 默认原销售单位，可调整 |
| 库存 | 其他入库 | 默认基本单位，可选择大/中/小单位 |
| 库存 | 其他出库 | 默认基本单位，可选择大/中/小单位 |
| 库存 | 报损单 | 默认基本单位，可选择大/中/小单位 |
| 库存 | 库存调整单 | 默认基本单位，可选择大/中/小单位 |
| 库存 | 调拨单 | 默认基本单位，可选择大/中/小单位 |
| 库存 | 成本调整单 | 不改变数量；如展示数量，按基本单位展示 |

## 三、商品单位模型

商品支持：

```text
基本单位
大单位
中单位
```

示例：

```text
基本单位：瓶
大单位：箱，1箱 = 24瓶
中单位：提，1提 = 12瓶
```

### 3.1 基本单位

基本单位是库存、批次、成本、流水的底层计算单位。

所有库存数量最终都折算为：

```text
基本单位数量
```

### 3.2 业务单位

业务单位是用户在单据明细中选择的开单单位。

业务单位可以是：

```text
基本单位
大单位
中单位
```

### 3.3 单位主档维度（V1.0 现行方案）

单位主档（`base_unit`）在 V1.0 采用「一物两标记」的形态，只维护两个业务开关：

|主档字段|界面标签|语义|
|---|---|---|
|`can_middle_unit`|是否中单位|勾选后该单位可被商品多单位矩阵的「中单位」下拉引用|
|`can_large_unit`|是否大单位|勾选后该单位可被商品多单位矩阵的「大单位」下拉引用|

约束：

- 基本单位下拉在商品档案里始终展示**所有 status=NORMAL 的单位**，不受两个开关影响。原因：任何合法计量单位都可能作为某个商品的最小库存计量单位（瓶、粒、片、袋…）。
- 中单位下拉仅列出 `can_middle_unit=1` 的单位；大单位下拉仅列出 `can_large_unit=1` 的单位。
- 同一单位可以同时勾选中、大两个开关（例如「提」既可当中单位也可当大单位）。
- 「可作为基本单位」不再出现在 V1.0 前端表单；后台保存时该字段恒为 `1`，仅为老数据/接口兼容保留。

停用（`status=STOPPED`）的单位在所有商品单位下拉里都不再出现。

## 四、单据明细必须保存的单位字段

所有涉及商品数量的单据明细必须保存：

| 字段 | 必填 | 说明 |
|---|:---:|---|
| business_unit_id | 是 | 开单单位ID，即用户选择的业务单位 |
| business_unit_name | 是 | 开单单位名称，如箱、瓶、包 |
| business_qty | 是 | 开单数量，用户录入 |
| conversion_rate | 是 | 业务单位到基本单位的换算率 |
| base_unit_id | 是 | 商品基本单位ID |
| base_unit_name | 是 | 商品基本单位名称 |
| base_qty | 是 | 基本单位数量 = 开单数量 × 换算率 |

### 4.1 示例

```text
商品：农夫山泉
业务单位：箱
开单数量：10
换算率：24
基本单位：瓶
基本单位数量：240
```

## 五、数量计算规则

### 5.1 基本公式

```text
基本单位数量 = 开单数量 × 换算率
```

### 5.2 单价与金额

业务单价按业务单位录入：

```text
业务金额 = 开单数量 × 业务单价
```

折算基本单位单价：

```text
基本单位单价 = 业务单价 / 换算率
```

### 5.3 成本计算

库存成本按基本单位计算：

```text
成本金额 = 基本单位数量 × 基本单位成本单价
```

如页面展示业务单位成本，可计算：

```text
业务单位成本单价 = 基本单位成本单价 × 换算率
```

## 六、默认单位带出规则

### 6.1 采购订单

采购订单添加商品时默认单位：

```text
商品默认采购单位 > 大单位 > 基本单位
```

原因：经销商采购通常按箱、件等大包装订货。

### 6.2 销售订单/销售快速开单

销售添加商品时默认单位：

```text
商品默认销售单位 > 基本单位 > 大单位
```

V1.0若商品未维护默认销售单位，默认取基本单位。

### 6.3 其他出入库、报损、库存调整

默认：

```text
基本单位
```

但允许用户切换大/中/小单位。

### 6.4 调拨单

默认：

```text
基本单位
```

允许选择大/中/小单位；调拨库存数量最终按基本单位计算。调拨仓库仍按单据头调出仓和调入仓处理。

## 七、页面交互要求

### 7.1 明细字段展示

所有相关单据明细表必须展示：

```text
商品
仓库（调拨单除外，调拨单展示调出/调入仓）
业务单位
开单数量
换算率
基本单位
基本单位数量
业务单价
金额
成本单价
成本金额
批次
备注
```

### 7.2 单位切换联动

用户修改业务单位后，系统必须联动：

- 换算率。
- 基本单位数量。
- 业务单价显示。
- 金额。
- 成本金额。
- 起订量/起订倍数校验。
- 库存可用数量展示。

### 7.3 库存校验

出库类单据必须按基本单位校验可用库存：

```text
明细基本单位数量 <= 明细仓库基本单位可用库存
```

不得用业务单位数量直接比较，避免单位不一致导致错误。

## 八、库存、批次、流水口径

### 8.1 库存余额

库存余额统一按基本单位存储。

可在页面中辅助展示业务单位折算，但底层数据以基本单位为准。

### 8.2 批次库存

批次数量按基本单位存储。

### 8.3 库存流水

库存流水必须记录：

```text
业务单位
业务数量
换算率
基本单位
基本单位数量
```

库存流水方向和结存数量按基本单位计算。

## 九、业务校验

| 校验项 | 规则 |
|---|---|
| 业务单位为空 | 不允许保存/审核 |
| 换算率为空或小于等于0 | 不允许保存/审核 |
| 基本单位数量小于等于0 | 不允许保存/审核 |
| 出库基本单位数量大于可用库存 | 阻断审核，避免负库存 |
| 单位不属于商品单位体系 | 阻断保存 |
| 起订量/起订倍数不满足 | 提示或阻断，按系统参数控制 |

## 十一、验收用例

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| UNIT-001 | 采购默认大单位 | 采购订单添加有大单位商品 | 默认单位为大单位，如箱 |
| UNIT-002 | 销售默认基本单位 | 销售订单添加商品 | 默认单位为商品默认销售单位/基本单位 |
| UNIT-003 | 切换单位 | 将单位从瓶改为箱 | 换算率、基本单位数量、金额联动变化 |
| UNIT-004 | 出库库存校验 | 1箱=24瓶，出库10箱 | 按240瓶校验库存 |
| UNIT-005 | 库存流水 | 审核出库10箱 | 流水记录业务数量10箱、基本数量240瓶 |
| UNIT-006 | 调拨单 | 调拨10箱 | 库存按240瓶调拨，仓库取单据头调出/调入仓 |
