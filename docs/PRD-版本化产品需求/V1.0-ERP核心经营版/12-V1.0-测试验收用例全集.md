## 一、测试范围

V1.0测试范围包括：

1. 系统管理：用户、权限、参数、日志、导入导出。
2. 基础数据：商品、客户、供应商、仓库、价格、资金账户。
3. 采购：采购订单、采购入库、采购收货、采购退货。
4. 销售：销售快速开单、销售订单、销售出库、销售收货、销售退货。
5. 库存：库存余额、库存锁定、库存流水、批次、成本。
6. 财务：应收、应付、收款、付款、核销、资金流水。
7. 报表：经营概览、销售、采购、库存、财务基础报表。

## 二、验收标准总则

### 2.1 P0上线准入

| 检查项 | 标准 |
|---|---|
| 主流程 | 采购到应付、销售到应收、收付款核销必须100%通过 |
| 数据一致性 | 库存余额=库存流水汇总，应收应付=来源单据金额 |
| 权限 | 菜单、按钮、字段、数据范围生效 |
| 审计 | 审核、反审核、核销、导入导出均有操作日志 |
| 异常 | 库存不足、超信用、低价、重复单据有明确提示 |
| 导入导出 | 失败原因可下载，导出进入导出中心 |
| 报表 | 报表合计与明细一致 |

### 2.2 测试数据建议

| 数据 | 建议 |
|---|---|
| 商品 | 正常商品、赠品、批次商品、停用商品、不可售商品 |
| 客户 | 现结客户、账期客户、超信用客户、冻结客户 |
| 供应商 | 正常供应商、停用供应商、不同到货天数供应商 |
| 仓库 | 总仓、退货仓、不同成本分组仓库 |
| 库存 | 有库存、无库存、低于下限、批次库存 |
| 财务 | 未核销、部分核销、已核销、逾期应收 |

## 十二、全链路验收剧本

### 12.1 采购到付款

```text
1. 新增供应商、商品、仓库、资金账户
2. 新建采购订单：商品100箱，单价20
3. 审核采购订单
4. 采购入库100箱并审核
5. 检查库存：实物+100，成本=20
6. 检查采购收货单自动生成
7. 审核采购收货单
8. 检查应付生成：2000
9. 新建付款单2000并审核
10. 付款核销应付
11. 检查应付已核销，资金账户减少2000
```

预期：采购、库存、成本、应付、付款、资金流水全部正确。
