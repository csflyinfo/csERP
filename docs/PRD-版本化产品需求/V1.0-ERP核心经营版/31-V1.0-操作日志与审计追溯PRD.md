## 1. 功能定位

所有业务操作可追溯：**增、删、改、查、导入、导出、打印**全部记录；修改类操作留下**改前/改后**值；
每张业务单据可查看自己的操作记录时间线；日志集中可查、可按保留天数自动清理；登录独立成表；
敏感操作可标记，成本/价格对非管理员脱敏。

## 2. 日志范围与「查」的边界

- **记录**：新增、修改、删除、审核/反审核、停用/启用、作废、核销、导入、导出、打印、单据详情查看。
- **不记录**：列表查询、搜索、刷新、下拉选项、分页拉取等纯读动作（避免日志洪泛）。
- **「查」只记单据详情查看**，受参数 `OP_LOG_ENABLE_DETAIL_VIEW` 控制（默认关）；敏感模块（成本/价格/资金）
  无论开关如何恒记。

## 3. 数据模型（V92）

- `sys_operation_log_runtime`：在旧 8 列基础上增加 `operator_id/operator_account/module_name/action_name/
  biz_type/biz_id/request_ip/request_url/request_method/cost_time_ms/fail_reason/sensitive/
  before_value(CLOB)/after_value(CLOB)/operation_content`；索引 `(biz_type,biz_no)`、`(operator_account)`、`(sensitive)`。
  旧 `detail` 列保留兼容存量与 TMS。
- `sys_login_log`：登录/登出、成功失败、IP、UA、应用类型。
- 系统参数：`OP_LOG_RETENTION_DAYS=180`、`LOGIN_LOG_RETENTION_DAYS=180`、`OP_LOG_ENABLE_DETAIL_VIEW=0`、
  `OP_LOG_SLOW_THRESHOLD_MS=3000`。

## 4. 改前改后规则

- 仅 **关键字段** 做字段级 diff（状态/金额/数量/单价/成本/往来单位/仓库/日期/结算方式 等，清单见 `KeyFields`）。
- **明细行** 按行级 diff：新增/修改/删除，按 detail_id 优先、否则 goods_code 配对。
- 备注等非关键字段变化只标注「**非关键字段有修改**」，不留具体值。
- 命中敏感字段（成本/采购价/标准售价/最低售价/建议零售价/信用额度 等）整条置 `sensitive=Y`；
  password/token/secret/pwd 一律 `***`。
- 商品/客户/供应商/仓库/采购订单/销售订单 主表字段与订单明细行字段清单在 `KeyFields` 中维护。

## 5. 单据操作时间线

- 业务用户接口 `/operation-log/bill-timeline`（登录即可），按 `biz_type + biz_no` 时间正序返回该单据全部日志，含解析后的 diff。
- 前端每张单据/主数据列表行有「记录」按钮，打开右侧 1/4 宽小抽屉时间线，点击遮罩空白处关闭。
- biz_type 覆盖：采购订单/入库/收货/退货、销售订单/出库/签收/退货/拒收、其他入出库、报损、盘点、调拨、
  收款/付款/费用、快速开单、商品/客户/供应商/仓库。

## 6. 集中查询与导出（管理员）

- `/system/operation-log/page`：SQL 级过滤（模块/动作/操作人/业务号/单据类型/结果/敏感/时间区间/关键字）+ COUNT/LIMIT 分页。
- `/system/operation-log/detail/{logId}`：全字段 + 解析后的 before/after；敏感改前改后仅管理员可见原值，非管理员脱敏。
- 导出、手动清理；登录日志分页/导出。
- 管理端日志页操作人显示**账号**；操作列只保留「详情」，点击看改前改后对比。

## 7. 登录日志与自动清理

- 登录成功/失败、登出写 `sys_login_log`（含 IP/UA），不再双写操作日志。
- 定时任务每日 03:30 按保留天数清理两张表（Java 层算截止时间、分批删），清理后写一条 CLEANUP 日志。

## 8. 权限与脱敏

- `/system/**` 仅 ADMIN；`/operation-log/**` 登录用户可用（单据用户看自己单据的时间线）。
- 敏感日志 `sensitive=Y`；非管理员在时间线/详情接口看到的敏感字段值由后端脱敏为 `***`。
- 日志写入 `REQUIRES_NEW` 独立事务 + 全 try/catch：**审计失败绝不影响业务**，业务回滚后审计仍保留。

## 9. 验收用例

1. 建/改/审核采购单、销售单：时间线含 新增/修改/审核；修改展示主表 + 明细行 diff；只改备注显示「非关键字段有修改」。
2. 商品改标准售价：日志 `sensitive=Y`，非管理员看值为 `***`，管理员可见原值；停用/删除记录状态 diff。
3. 成本调整审核：敏感日志；导入商品记 IMPORT（含成功/失败行数）；导出/打印打点落库。
4. 错误密码登录 → 登录日志 FAIL + IP；正确登录 → SUCCESS。
5. 管理端按 模块/动作/操作人/时间/结果/敏感/关键字 过滤；调小保留天数点「立即清理」，旧日志删除并出现 CLEANUP。
