> 文档版本：v1.0  
> 编写日期：2026-06-13  
> 适用版本：V1.0 ERP核心经营版  
> 覆盖模块：其他入库、其他出库、报损单、成本调整单、库存明细成本字段

---

## 一、库存增强模块总览

### 1.1 模块范围

| 模块 | 页面入口 | 定位 |
|---|---|---|
| 其他入库 | 库存管理 → 其他入库 | 不记往来的库存增加 |
| 其他出库 | 库存管理 → 其他出库 | 不记往来的库存减少 |
| 报损单 | 库存管理 → 报损单 | 过期、破损、不可售商品报损出库 |
| 成本调整单 | 库存管理 → 成本调整单 | 调整库存成本，不改变库存数量 |

### 1.2 统一规则

- 所有库存增强单据必须有单据编号、状态、审核人、审核时间、操作日志。
- 所有单据明细必须包含成本单价、成本金额。
- 审核后才影响库存或成本。
- 已审核单据不可直接修改。
- 已结账期间不可反审核。
- 不记往来单据不生成应收应付。

## 二、其他入库页面

### 2.1 页面入口

`库存管理 → 其他入库`

### 2.2 页面定位

其他入库用于处理非采购、非销售退货、非调拨且不形成应付的库存增加。

### 2.3 适用场景

| 场景 | 说明 |
|---|---|
| 期初库存 | 系统上线初始库存录入 |
| 样品入库 | 不形成供应商应付的样品 |
| 赠品入库 | 无采购结算的赠品 |
| 盘外发现 | 临时发现账外库存 |
| 内部加工入库 | 简化处理的内部产出 |
| 其他原因 | 需手工说明 |

### 2.4 列表查询条件

| 条件 | 控件 | 默认 | 说明 |
|---|---|---|---|
| 入库日期 | 日期范围 | 本月 | 业务日期 |
| 其他入库单号 | 输入框 | 空 | 精确/模糊 |
| 入库仓库 | 下拉 | 全部 | 仓库 |
| 入库原因 | 下拉 | 全部 | 期初/样品/赠品等 |
| 商品 | 输入框 | 空 | 包含商品 |
| 状态 | 多选 | 全部 | 草稿/待审核/已审核/已关闭 |
| 创建人 | 下拉 | 全部 | 制单人 |

### 2.5 列表字段

| 字段 | 说明 |
|---|---|
| 其他入库单号 | 点击详情 |
| 入库日期 | 业务日期 |
| 入库仓库 | 仓库名称 |
| 入库原因 | 原因类型 |
| 商品种类数 | SKU数 |
| 入库总数量 | 明细数量合计 |
| 入库成本金额 | 成本金额合计 |
| 是否影响成本 | 是/否 |
| 状态 | 草稿/待审核/已审核 |
| 审核人/时间 | 审核信息 |
| 操作 | 查看、编辑、审核、反审核、打印、日志 |

### 2.6 编辑页布局

```text
其他入库单
├─ 基本信息：单号、日期、仓库、原因、是否影响成本
├─ 商品明细：商品、单位、数量、单价、金额、成本单价、成本金额、批次
├─ 金额汇总：总数量、总金额、成本金额
├─ 附件备注
└─ 操作按钮：保存、提交、审核、取消
```

### 2.7 主表字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 其他入库单号 | 是 | OI编号 |
| 入库日期 | 是 | 默认当天 |
| 入库仓库 | 是 | 正常仓库 |
| 入库原因 | 是 | 字典 |
| 是否影响成本 | 是 | 默认是 |
| 状态 | 是 | 草稿/待审核/已审核 |
| 备注 | 否 | 说明 |

### 2.8 明细字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 商品 | 是 | 正常商品 |
| 单位 | 是 | 商品单位 |
| 数量 | 是 | >0 |
| 单价 | 是 | 入库成本参考价 |
| 金额 | 是 | 数量×单价 |
| 成本单价 | 是 | 影响成本时必填 |
| 成本金额 | 是 | 数量×成本单价 |
| 批次号 | 批次商品必填 | 批次 |
| 生产日期 | 批次商品必填 | 生产日期 |
| 到期日期 | 自动 | 生产日期+保质期 |
| 备注 | 否 | 行备注 |

### 2.9 审核影响

- 增加库存余额。
- 增加批次库存。
- 生成库存流水，方向为IN。
- 是否重算成本取决于“是否影响成本”。
- 不生成应付。

### 2.10 业务规则

- 商品停用不可入库。
- 数量必须大于0。
- 批次商品必须录入生产日期。
- 影响成本时成本单价不可为空。
- 审核后不可修改。

## 三、其他出库页面

### 3.1 页面入口

`库存管理 → 其他出库`

### 3.2 页面定位

其他出库用于处理非销售、非采购退货、非报损且不形成应收的库存减少。

### 3.3 适用场景

| 场景 | 说明 |
|---|---|
| 内部领用 | 公司自用商品 |
| 样品出库 | 给客户或业务员试用 |
| 借出出库 | 临时借出 |
| 活动消耗 | 市场活动、促销活动消耗 |
| 包材耗用 | 包装材料内部使用 |
| 其他原因 | 手工说明 |

### 3.4 查询条件

出库日期、其他出库单号、仓库、出库原因、领用部门、领用人、商品、状态。

### 3.5 列表字段

其他出库单号、出库日期、仓库、出库原因、领用部门、领用人、商品种类数、出库数量、成本金额、状态、操作。

### 3.6 主表字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 其他出库单号 | 是 | OO编号 |
| 出库日期 | 是 | 默认当天 |
| 出库仓库 | 是 | 正常仓库 |
| 出库原因 | 是 | 内部领用/样品/活动等 |
| 领用部门 | 否 | 部门 |
| 领用人 | 否 | 人员 |
| 状态 | 是 | 草稿/待审核/已审核 |
| 备注 | 否 | 说明 |

### 3.7 明细字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 商品 | 是 | 正常商品 |
| 单位 | 是 | 商品单位 |
| 当前可用库存 | 自动 | 用于校验 |
| 出库数量 | 是 | >0且≤可用库存 |
| 成本单价 | 自动 | 当前成本 |
| 成本金额 | 自动 | 出库数量×成本单价 |
| 批次 | 批次商品可选/必填 | 按策略 |
| 备注 | 否 | 行备注 |

### 3.8 审核影响

- 扣减库存余额。
- 扣减批次库存。
- 生成库存流水，方向OUT。
- 成本取审核时当前成本。
- 不生成应收。

### 3.9 业务规则

- 出库数量不可超过可用库存。
- 过期品报损应优先使用报损单，不建议走其他出库。
- 审核后不可修改。
- 已结账不可反审核。

## 四、报损单页面

### 4.1 页面入口

`库存管理 → 报损单`

### 4.2 页面定位

报损单用于对过期、破损、霉变、不可售商品做损耗出库，记录公司损失。

### 4.3 适用场景

| 报损类型 | 说明 |
|---|---|
| 过期报损 | 超过保质期 |
| 临期不可售 | 临期且无法销售 |
| 破损报损 | 包装破损、商品损坏 |
| 霉变污染 | 商品变质 |
| 质量异常 | 内部确认不可售 |
| 其他 | 需填写说明 |

### 4.4 查询条件

报损日期、报损单号、仓库、报损类型、商品、批次、状态、申请人、审核人。

### 4.5 列表字段

报损单号、报损日期、仓库、报损类型、申请人、商品种类数、报损总数量、报损成本金额、状态、审核人、审核时间、操作。

### 4.6 编辑页布局

```text
报损单
├─ 基本信息：单号、日期、仓库、报损类型、申请人、部门
├─ 商品明细：商品、批次、效期、可用库存、报损数量、成本单价、成本金额
├─ 附件：报损照片、说明文件
├─ 金额汇总：总数量、总成本金额
└─ 操作按钮：保存、提交、审核、反审核
```

### 4.7 主表字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 报损单号 | 是 | DO编号 |
| 报损日期 | 是 | 默认当天 |
| 仓库 | 是 | 报损仓库 |
| 报损类型 | 是 | 过期/破损等 |
| 申请人 | 是 | 默认当前用户 |
| 部门 | 否 | 申请部门 |
| 报损总数量 | 自动 | 明细合计 |
| 报损成本金额 | 自动 | 明细成本合计 |
| 状态 | 是 | 草稿/待审核/已审核 |
| 报损说明 | 否 | 500字以内 |

### 4.8 明细字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 商品 | 是 | 报损商品 |
| 单位 | 是 | 商品单位 |
| 批次 | 批次商品必填 | 指定批次 |
| 生产日期 | 自动 | 批次带出 |
| 到期日期 | 自动 | 批次带出 |
| 当前可用库存 | 自动 | 用于校验 |
| 报损数量 | 是 | >0且≤可用库存 |
| 成本单价 | 自动 | 当前成本 |
| 成本金额 | 自动 | 报损数量×成本单价 |
| 报损原因 | 是 | 明细原因 |
| 附件 | 否 | 图片 |

### 4.9 审核影响

- 扣减库存。
- 生成报损库存流水。
- 记录成本金额作为损失。
- 不生成应收应付。
- 进入报损报表。

### 4.10 业务规则

- 报损数量不可超过可用库存。
- 报损金额超过审批阈值时走审批流。
- 过期商品可从库存预警一键生成报损单。
- 报损单审核后不可修改。
- 报损反审核需有权限且未结账。

## 五、成本调整单页面

### 5.1 页面入口

`库存管理 → 成本调整单`

### 5.2 页面定位

成本调整单用于调整库存成本单价或库存成本金额，不改变库存数量。

### 5.3 查询条件

调整日期、调整单号、仓库、商品、调整方式、状态、创建人、审核人。

### 5.4 列表字段

成本调整单号、调整日期、仓库、成本分组、调整方式、商品种类数、调整前金额、调整后金额、差异金额、状态、操作。

### 5.5 主表字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 成本调整单号 | 是 | CA编号 |
| 调整日期 | 是 | 默认当天 |
| 仓库 | 是 | 调整仓库 |
| 成本分组 | 自动 | 仓库带出 |
| 调整方式 | 是 | 按单价/按金额 |
| 调整原因 | 是 | 必填 |
| 状态 | 是 | 草稿/待审核/已审核 |
| 备注 | 否 | 说明 |

### 5.6 明细字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 商品 | 是 | 有库存商品 |
| 批次 | 否 | 可指定批次 |
| 当前库存数量 | 自动 | 不可修改 |
| 调整前成本单价 | 自动 | 当前成本 |
| 调整前库存金额 | 自动 | 当前金额 |
| 调整后成本单价 | 按单价调整必填 | 不小于0 |
| 调整后库存金额 | 按金额调整必填 | 不小于0 |
| 成本单价差异 | 自动 | 调整后-调整前 |
| 调整差异金额 | 自动 | 调整后金额-调整前金额 |
| 备注 | 否 | 行备注 |

### 5.7 审核影响

- 不改变库存数量。
- 更新库存余额成本单价和库存金额。
- 生成成本调整记录。
- 影响后续出库成本。
- 记录操作日志。

### 5.8 业务规则

- 调整原因必填。
- 调整后成本不能小于0。
- 无库存商品默认不可调整成本。
- 成本调整单审核后不可修改。
- 已结账期间不可反审核。
- 成本字段受权限控制。

## 六、库存增强模块异常场景

| 场景 | 处理 |
|---|---|
| 其他出库库存不足 | 阻止审核 |
| 报损数量超过可用库存 | 阻止保存/审核 |
| 成本调整后成本小于0 | 阻止保存 |
| 其他入库批次商品未填生产日期 | 阻止审核 |
| 已审核单据修改 | 阻止，需反审核 |
| 已结账期间反审核 | 阻止 |
| 无成本权限查看单据 | 隐藏成本单价/成本金额 |

## 七、页面级验收用例

| 编号 | 页面 | 场景 | 预期 |
|---|---|---|---|
| INV-OI-001 | 其他入库 | 新建其他入库并审核 | 库存增加，不生成应付 |

| INV-CA-001 | 成本调整 | 按单价调整成本 | 库存数量不变，成本金额变化 |
| INV-CA-002 | 成本调整 | 调整后成本小于0 | 阻止保存 |
| INV-COST-001 | 成本字段权限 | 无成本权限查看报损单 | 成本单价/成本金额隐藏 |
