## 一、财务增强模块总览

### 1.1 模块范围

| 模块 | 页面入口 | 定位 |
|---|---|---|
| 费用单 | 财务管理 → 费用单 | 费用收入/支出，可生成应收/应付或直接收付款 |
| 应收结算 | 财务管理 → 应收结算 | 对客户/往来单位快速收款并核销 |
| 应付结算 | 财务管理 → 应付结算 | 对供应商/往来单位快速付款并核销 |
| 往来单位应收 | 财务管理 → 往来单位应收 | 非客户对象应收管理 |
| 往来单位应付 | 财务管理 → 往来单位应付 | 非供应商对象应付管理 |

### 1.2 财务增强关系

```text
费用收入 → 应收 → 应收结算/收款核销 → 收款单 → 资金流水
费用支出 → 应付 → 应付结算/付款核销 → 付款单 → 资金流水
```

## 二、费用单页面

### 2.1 页面入口

`财务管理 → 费用单`

### 2.2 页面定位

费用单用于记录企业经营中的费用收入和费用支出，可关联客户、供应商、往来单位、员工或其他对象。费用单可根据配置生成应收、应付，也可以直接生成收款、付款和资金流水。

### 2.3 费用单类型

| 类型 | 说明 | 后续影响 |
|---|---|---|
| 费用收入 | 公司应向对方收取费用 | 生成应收或直接收款 |
| 费用支出 | 公司需要支付费用 | 生成应付或直接付款 |
| 内部费用 | 不形成往来对象 | 仅记录费用，后续凭证增强 |

### 2.4 查询条件

| 条件 | 控件 | 默认 | 说明 |
|---|---|---|---|
| 费用日期 | 日期范围 | 本月 | 业务日期 |
| 费用单号 | 输入框 | 空 | 精确/模糊 |
| 费用方向 | 下拉 | 全部 | 收入/支出 |
| 费用类型 | 下拉树 | 全部 | 费用类型 |
| 往来对象类型 | 下拉 | 全部 | 客户/供应商/往来单位/员工/无 |
| 往来对象 | 搜索选择 | 全部 | 按对象类型筛选 |
| 是否生成往来 | 下拉 | 全部 | 是/否 |
| 是否直接收付款 | 下拉 | 全部 | 是/否 |
| 状态 | 多选 | 全部 | 草稿/待审核/已审核/已关闭 |
| 创建人 | 下拉 | 全部 | 制单人 |

### 2.5 列表字段

| 字段 | 说明 |
|---|---|
| 费用单号 | 点击详情 |
| 费用日期 | 业务日期 |
| 费用方向 | 收入/支出 |
| 费用类型 | 费用分类 |
| 往来对象类型 | 客户/供应商/往来单位等 |
| 往来对象 | 对象名称 |
| 费用金额 | 金额合计 |
| 税额 | 税额 |
| 是否生成往来 | 是/否 |
| 往来单据 | 应收单/应付单号 |
| 是否直接收付款 | 是/否 |
| 收付款单号 | 收款单/付款单 |
| 状态 | 草稿/待审核/已审核 |
| 操作 | 查看、编辑、审核、反审核、日志 |

## 三、费用单编辑页

### 3.1 页面布局

```text
费用单编辑页
├─ 基本信息：费用方向、费用类型、对象类型、对象、日期
├─ 费用明细：费用项目、数量、单价、金额、税率、税额
├─ 往来/收付款设置：生成应收/应付、直接收付款、资金账户
├─ 附件备注：发票、合同、照片
└─ 操作：保存草稿、提交审核、审核、取消
```

### 3.2 主表字段

| 字段 | 必填 | 控件 | 规则 |
|---|:---:|---|---|
| 费用单号 | 是 | 只读 | FE编号 |
| 费用日期 | 是 | 日期 | 默认当天 |
| 费用方向 | 是 | 单选 | 收入/支出 |
| 费用类型 | 是 | 下拉树 | 正常费用类型 |
| 往来对象类型 | 是 | 下拉 | 客户/供应商/往来单位/员工/无 |
| 客户 | 条件必填 | 搜索 | 对象类型为客户 |
| 供应商 | 条件必填 | 搜索 | 对象类型为供应商 |
| 往来单位 | 条件必填 | 搜索 | 对象类型为往来单位 |
| 费用金额 | 是 | 自动 | 明细合计 |
| 税额 | 否 | 自动 | 明细税额合计 |
| 是否生成往来 | 是 | 开关 | 生成应收/应付 |
| 是否直接收付款 | 是 | 开关 | 直接生成收款/付款 |
| 收付款方式 | 条件必填 | 下拉 | 直接收付款时必填 |
| 资金账户 | 条件必填 | 下拉 | 直接收付款时必填 |
| 状态 | 是 | 只读 | 草稿/待审核/已审核 |
| 备注 | 否 | 文本域 | 500字以内 |

### 3.3 明细字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 费用项目 | 是 | 如“办公室租金” |
| 费用类型 | 是 | 可继承主表 |
| 数量 | 否 | 可为空 |
| 单价 | 否 | 可为空 |
| 金额 | 是 | 数量×单价或手工录入 |
| 税率 | 否 | 税率 |
| 税额 | 否 | 自动计算 |
| 备注 | 否 | 明细说明 |

### 3.4 审核影响

| 条件 | 审核结果 |
|---|---|
| 费用收入 + 生成往来 | 生成应收 |
| 费用支出 + 生成往来 | 生成应付 |
| 费用收入 + 直接收款 | 生成收款单并增加资金 |
| 费用支出 + 直接付款 | 生成付款单并减少资金 |
| 不生成往来且不直接收付款 | 仅记录费用 |

### 3.5 业务规则

- 费用金额必须等于明细金额合计。
- 生成往来时必须选择对象。
- 直接收付款时必须选择资金账户。
- 费用支出直接付款时校验资金账户余额。
- 已生成应收/应付且已核销时，不允许反审核。
- 已结账期间不可反审核。

## 四、往来单位应收页面

### 4.1 页面入口

`财务管理 → 往来单位应收`

### 4.2 页面定位

管理非客户对象产生的应收款，如物流赔款、废品收入、员工还款等。

### 4.3 查询条件

往来单位、应收单号、来源单据、应收日期、预计收款日、核销状态、逾期状态。

### 4.4 列表字段

| 字段 | 说明 |
|---|---|
| 应收单号 | AR编号 |
| 往来单位 | 对象名称 |
| 来源单据 | 费用单等 |
| 应收日期 | 业务日期 |
| 应收金额 | 金额 |
| 已收金额 | 已核销 |
| 未收金额 | 剩余 |
| 预计收款日 | 账期计算 |
| 逾期天数 | 当前日期-预计收款日 |
| 核销状态 | 未/部分/已核销 |
| 操作 | 查看来源、收款、核销记录 |

### 4.5 业务规则

- 往来单位应收可由费用收入生成。
- 往来单位应收可通过收款单核销。
- 往来单位应收可进入应收结算。
- 应收金额不可直接修改，需冲销或红字费用单调整。

### 5.1 页面入口

### 5.2 页面定位

管理非供应商对象产生的应付款，如房租、物业、物流运费、服务费等。

### 5.3 查询条件

往来单位、应付单号、来源单据、应付日期、预计付款日、核销状态、逾期状态。

### 5.4 列表字段

应付单号、往来单位、来源单据、应付日期、应付金额、已付金额、未付金额、预计付款日、逾期天数、核销状态、操作。

### 5.5 业务规则

## 六、应收结算页面

### 6.1 页面入口

`财务管理 → 应收结算`

### 6.2 页面定位

应收结算用于对客户或往来单位快速收款并核销，简化“先建收款单再核销”的操作路径。

### 6.3 页面布局

```text
应收结算
├─ 结算对象区：对象类型、客户/往来单位、结算日期
├─ 待结算应收列表：可勾选
├─ 本次结算区：收款方式、资金账户、收款金额、折让金额
├─ 汇总区：应收合计、已选合计、本次收款、折让、结算后余额
└─ 操作：生成收款单并核销、仅生成收款单、打印结算单
```

### 6.4 查询条件

| 条件 | 说明 |
|---|---|
| 对象类型 | 客户/往来单位 |
| 结算对象 | 客户或往来单位 |
| 应收日期 | 应收发生日期 |
| 预计收款日 | 到期日期 |
| 逾期状态 | 未到期/逾期 |
| 来源单据类型 | 销售收货单/费用单等 |

### 6.5 待结算应收字段

| 字段 | 说明 |
|---|---|
| 选择 | 勾选结算 |
| 应收单号 | 应收记录 |
| 来源单据 | 销售收货单/费用单 |
| 单据日期 | 业务日期 |
| 预计收款日 | 账期计算 |
| 应收金额 | 原金额 |
| 已收金额 | 已核销 |
| 未收金额 | 可结算金额 |
| 本次结算金额 | 默认未收金额，可改 |
| 折让金额 | 可填，需权限 |
| 逾期天数 | 风险提示 |

### 6.6 结算信息字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 结算单号 | 是 | ARS编号 |
| 结算日期 | 是 | 默认当天 |
| 收款方式 | 是 | 现金/微信/支付宝/银行 |
| 资金账户 | 是 | 入账账户 |
| 本次收款金额 | 是 | 实收金额 |
| 折让金额 | 否 | 财务折让 |
| 折让原因 | 折让时必填 | 原因说明 |
| 备注 | 否 | 说明 |

### 6.7 操作规则

#### 生成收款单并核销

系统自动：

1. 生成收款单。
2. 审核收款单。
3. 生成资金流水。
4. 生成核销记录。
5. 更新应收已收/未收金额。
6. 生成应收结算单。

#### 仅生成收款单

系统只生成收款单，不自动核销，后续可到收款核销页面处理。

### 6.8 业务规则

- 只能选择同一对象的应收。
- 本次结算金额不可超过未收金额。
- 本次收款金额 + 折让金额 不可超过已选未收合计。
- 折让金额需权限，且必须填写原因。
- 结算完成后不可修改；如需撤销，走反核销。

## 七、应付结算页面

### 7.1 页面入口

`财务管理 → 应付结算`

### 7.2 页面定位

应付结算用于对供应商或往来单位快速付款并核销，简化付款处理。

### 7.3 页面布局

```text
应付结算
├─ 结算对象区：对象类型、供应商/往来单位、结算日期
├─ 待结算应付列表：可勾选
├─ 本次结算区：付款方式、资金账户、付款金额、折让金额
├─ 汇总区：应付合计、已选合计、本次付款、折让、结算后余额
└─ 操作：生成付款单并核销、仅生成付款单、打印结算单
```

### 7.4 待结算应付字段

应付单号、来源单据、单据日期、预计付款日、应付金额、已付金额、未付金额、本次结算金额、折让金额、逾期天数。

### 7.5 结算信息字段

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 结算单号 | 是 | APS编号 |
| 结算日期 | 是 | 默认当天 |
| 付款方式 | 是 | 现金/银行/其他 |
| 资金账户 | 是 | 出账账户 |
| 本次付款金额 | 是 | 实付金额 |
| 折让金额 | 否 | 供应商让利/抹零 |
| 折让原因 | 折让时必填 | 原因说明 |
| 备注 | 否 | 说明 |

### 7.6 业务规则

- 只能选择同一供应商或往来单位的应付。
- 本次付款金额不可超过资金账户可用余额，除非有授权。
- 本次结算金额不可超过应付未付金额。
- 折让金额需权限。
- 结算后自动生成付款单、资金流水和核销记录。

## 八、收款单/付款单增强

### 8.1 收款单增强

收款单对象类型扩展：

| 对象类型 | 说明 |
|---|---|
| 客户 | 销售收款、预收款 |
| 往来单位 | 往来单位应收收款 |
| 其他 | 其他收入 |

收款单必须支持：

- 选择往来单位。
- 核销往来单位应收。
- 作为应收结算自动生成结果。

### 8.2 付款单增强

付款单对象类型扩展：

| 对象类型 | 说明 |
|---|---|
| 供应商 | 采购付款、预付款 |
| 往来单位 | 往来单位应付付款 |
| 其他 | 其他费用付款 |

付款单必须支持：

- 选择供应商时自动带出该供应商默认收款账户。
- 支持在付款单中切换供应商其他正常收款账户。
- 付款单保存/审核时固化收款账户快照：账户名称、开户行、银行账号、收款户名。
- 停用的供应商收款账户不可选择。
- 选择往来单位。
- 核销往来单位应付。
- 作为应付结算自动生成结果。

## 九、异常场景

| 场景 | 处理 |
|---|---|
| 费用单金额与明细合计不一致 | 阻止保存/审核 |
| 费用收入生成应收但未选对象 | 阻止审核 |
| 费用支出生成应付但未选对象 | 阻止审核 |
| 直接付款资金账户余额不足 | 阻止或授权 |
| 应收结算选择多个对象 | 阻止 |
| 应付结算选择多个对象 | 阻止 |
| 折让无权限 | 隐藏或阻止 |
| 已核销费用单反审核 | 阻止 |
| 往来单位停用后新建费用单 | 不可选择 |
