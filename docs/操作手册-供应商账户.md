## 一、这套模块管什么

供应商在系统里有三本往来账，集中在 **财务管理 → 供应商账户**：

| 余额 | 含义 | 对应总账科目 | 主要来源 |
|---|---|---|---|
| **应付余额** | 尚欠供应商的货款（含税） | 2202 应付账款（供应商辅助） | 采购收货立应付、付款/核销冲减、期初 QCAP |
| **预付余额** | 已付给供应商、尚未核销应付的钱 | 1123 预付账款（供应商辅助） | 付款单「预付付款」、预付退款冲减、预付核销 FX、厂家费用转预付（DX-OTHER）、期初/补录 QCYF |
| **费用余额** | 已申报给厂家、**尚未兑现**的厂家费用（代垫/返利等） | 1221 其他应收款（供应商辅助） | 厂家费用单 JF 立账、兑现单 DX 冲减、红字 JF 冲减 |

菜单地图：

| 菜单 | 干什么 |
|---|---|
| 财务管理 → **供应商账户** | 三余额查询、账户流水（应付/预付/费用三个页签）、数据修复（按权限） |
| 财务管理 → **厂家费用单**（JF） | 向厂家申报费用：代垫（关联客户费用单 FE）/ 其他费用（返利、补贴）；导入、手工行、审核、红字、历史补录 |
| 财务管理 → **厂家费用兑现单**（DX） | 厂家兑现费用：现金结算 CASH / 冲应付 OFFSET / 其他核销 OTHER；打印扣款通知单 |
| 付款单（付款类型=预付付款/预付退款） | 预付付款与退款，入供应商预付账与资金账 |
| 财务管理 → **预付核销单**（FX） | 用预付余额冲应付单（镜像客户预收核销 XH） |
| 财务管理 → 供应商应付期初 | 应付期初与**期初预付列**同批建账；页内「期初预付补录」按钮是上线后漏录通道 |

权限点：`fin.supplier_account.*`、`fin.factory_expense.*`、`fin.factory_settle.*`、
`fin.prepay_writeoff.*`，以及 `fin.init_ap.*`（期初与补录复用）。三余额受字段权限
**VIEW_AP_BALANCE** 控制，没有该字段权限的角色在供应商档案、账户列表里看到的余额为空。

## 二、供应商账户怎么看

- 列表每供应商一行，三个余额都是蓝色链接，点开是**流水抽屉**，分应付/预付/费用三个页签，默认近三个月，可改快捷期间；
- 流水列给出**此前余额、本笔发生额、本笔后余额**，业务类型一律显示中文名（采购立账、付款核销、预付付款、
  预付核销、厂家费用立账/红字/兑现、厂家费用账扣、费用转预付……），单据号（CGSH/CGTH/FK/FX/JF/DX/QCYF…）可联查原单；
- 余额是可由流水重建的真值缓存。若因直改数据库等异常导致余额与流水不符，用有 `fin.supplier_account.repair`
  权限的账号点「**数据修复**」按流水重算（修复本身写操作日志）；正常业务不需要动。

## 三、日常业务流程

### 3.1 预付付款 / 预付退款（付款单）

付款单新增时选**付款类型**：

- **预付付款（PREPAY）**：不选应付单、不做核销，审核后 借 1123（供应商辅助）/ 贷 资金，供应商**预付余额增加**、资金减少；
- **预付退款（PREPAY_REFUND）**：厂家把预付退回来，借 资金 / 贷 1123（现金流量固定「收到其他与经营活动有关的现金」）；
  退款金额**不能超过该供应商预付余额**，超额审核被中文拦截；
- **结算付款（SETTLE，默认）**：老样子核销应付，与预付无关。

### 3.2 预付核销单 FX（预付冲应付）

菜单：财务管理 → 预付核销单。左侧主单选供应商后显示其**可用预付余额**，右侧列出该供应商未结应付单
（到期日升序、空到期日排最后），勾选并填本次核销额，审核后：借 2202 / 贷 1123（均挂供应商辅助），
AP 未付余额与预付余额同时下降，fin_reconcile_record 写真值核销记录（应付账龄、供应商汇总即时正确）。
FX 可反审核（红字冲回），也可作废（CANCELLED）。

### 3.3 厂家费用单 JF（向厂家申报）

1. 新建 JF，选供应商、费用日期、经手人/部门；`external_voucher_no` 登**厂家确认单号/协议号/票据号**
   （以后税务核对、月结对账都靠它）；
2. 明细三种来源，可混用：
   - **选客户费用单 FE 明细行（代垫 ADVANCE）**：只列已审核、未被别的 JF 占用的 FE 行；
     **一张 FE 只能被一张 JF 关联**（整单占用，不支持一张 FE 分次申报）；一张 JF 可关联多张 FE；
     带回后行金额**允许改小**，差额视为我方自行承担、不再向厂家申报（列表红字提示）；
     贷方科目默认取 FE 行原路费用科目（原路冲回），可改；
   - **导入 Excel / 手工行（其他费用 OTHER）**：返利、补贴、奖励等；贷方科目取费用类型档案配置，
     缺省 **5401 主营业务成本**（平销返利冲成本），可改 5301/5051 等；
3. 税额登记位（含税总额、税额、不含税额）只**登记备查**，V1 凭证不拆税（见第四章）；
4. 保存 PENDING → 勾选后左下角批量「审核」（也可单张审）。审核后供应商**费用余额增加**，
   状态变为「待兑现 / 部分兑现 / 已兑现」；总账事件池自动生成 借 1221 / 贷 费用科目 的凭证；
5. **上线历史补录单**：系统参数 P0190（默认关）打开后，新建界面出现「上线历史补录单」勾选。
   补录单只立费用余额、**不生成总账凭证**（避免和 1221 启用期初双计），记账日期取上线当月未封账日；窗口期过后关掉 P0190。

### 3.4 厂家费用兑现单 DX（厂家怎么把钱给我们）

新建 DX 选供应商后，**上半区永远是 JF 待兑现行**（勾选、填本次兑现额），按兑现方式下半区不同：

| 方式 | 下半区 | 审核效果 |
|---|---|---|
| **CASH 现金结算** | 资金多行（现金/银行卡等资金档案账户） | 借 资金（现金流量固定「收到其他与经营活动有关的现金」，项目代码 CF03）/ 贷 1221；费用余额下降 |
| **OFFSET 冲应付（账扣）** | 该供应商未结应付单勾选（到期日升序 FIFO，自动填未付额，可改），可关联多张应付单 | 借 2202 / 贷 1221；写真值核销，AP 未付下降、费用余额下降；**无资金流动** |
| **OTHER 其他核销** | 一个对方科目：1123 费用转预付 / 1405 厂家货补 / 5601·5602 费用减免 / 5711 坏账（原因必填） | 借 对方科目（1123 挂供应商辅助）/ 贷 1221；选 1123 时供应商**预付余额增加**，可填关联预付付款单号 |

- **上下两区合计必须相等**（差 < 0.005），不平「保存并审核」置灰，鼠标悬停提示差额；
- 审核后 JF 的已兑现/未兑现额、兑现状态自动重算；DX 可反审核（自动红字），反审核后 JF 占用恢复。

### 3.5 扣款通知单（月结对账凭据）

DX 列表/抽屉可**打印、导出扣款通知单**：CASH 含资金到账明细；OFFSET 含被冲销的应付单明细
（CGSH 单号、账单日、金额）与勾稽的 JF 明细（费用类型、客户、协议号、金额），底部带签字栏。

### 3.6 申报后金额要调整：反审核还是红字 JF

- **费用日期未封账**且 JF 没有仍生效的 DX 兑现：直接**反审核**（回 PENDING），改完重新审核；
  已兑现过的要先反审核对应 DX；
- **已封账，或需要留痕**（厂家驳回、申报 100 核准 98 等）：开**红字 JF**（引用原单号、金额为负）。
  红冲额以原单剩余未兑现额为限（已兑现部分不能红冲）；红字单冲减费用余额、不可再被兑现；
  红字**不释放 FE 关联**（保留申报轨迹）；确需就同一 FE 重新申报的，红字冲回后新建 JF 走**手工行**
  并在备注注明原 FE 单号。

### 3.7 期初预付与上线后补录

- 新账套：供应商应付期初模板里直接填「**期初预付金额**」列，与应付同批过账（QCYF 流水 + 可选 QCAP 应付单），详见期初手册第四章；
- **已上线库漏录**：供应商应付期初页点「**期初预付补录**」，独立批号、可多批、只生 QCYF 流水，
  守卫是当天未封账 + 总账当月未月结；详见期初手册第六章。

## 四、税务口径与调整分录（务必会计先读）

**V1 全程含税总额管理**：JF、DX 不开销项/红字发票单、不做进项转出与纳税申报联动；
票据号登 JF 的 `external_voucher_no`。涉及税金的两张凭证由会计在**总账模块手工编制**：

1. **现金兑现并向厂家开具服务费/促销费发票**（产生纳税义务）：
   `借：1221 其他应收款—XX厂家（供应商辅助）　贷：应交税费—应交增值税（销项税额）/ 对应收入科目`
   （DX-CASH 本身已做 借资金/贷1221，税金部分是补登一笔；具体科目按企业适用税率与收入性质确定）
2. **平销返利账扣（OFFSET）按税法应做进项税额转出**：
   `借：主营业务成本（5401）　贷：应交税费—应交增值税（进项税额转出）`
   （DX-OFFSET 凭证只结 2202/1221 往来，税金在此补；需要红字信息表的按正常红字发票流程走）
3. 代垫客户费用 FE 自身的进项待认证（222103）沿用费用单模板，与 JF 链路无关。

### 示例：申报 100，厂家只认 98（2 元差异）

业务背景：JF 申报陈列费 100，厂家复核只核准 98。两种处理按责任归属二选一：

**方案 A：厂家驳回 2，我方不再追究**

1. DX 按 **98** 兑现（按厂家付款方式选 CASH 或 OFFSET；假设账扣）：借 2202 98 / 贷 1221 98；
2. 对原 JF 开**红字 JF −2**（备注厂家核驳 2 元，引用原单号）：借 费用科目 −2 / 贷 1221 −2，费用余额清零；
3. 若该 2 元对应进项需处理，会计在总账按进项转出/红字信息表手工补凭证。

**方案 B：2 元由我方自行承担（费用化，厂家视同全额兑现）**

1. DX 上半区 JF 本次兑现填 **100**；下半区拆两行/两张单：98 走 CASH 或 OFFSET，**2 走 OTHER → 5601（或 5711 坏账，原因必填）**；
   系统生成 借 资金/2202 98 + 借 5601 2 / 贷 1221 100，费用余额清零；
2. 会计在总账补税务调整分录（同上 1/2，视开票与返利性质）。

> 选哪个方案看商务责任：厂家核驳用方案 A（有红字轨迹），我方自愿承担用方案 B（费用转出）。

## 五、业财对账、日结与总账边界

### 5.1 业财对账（总账 → 业财对账，五组）

| 组 | 总账口径 | 业务口径 | 性质 |
|---|---|---|---|
| 应收 1122 | 1122 借余 | 应收单未收合计 | 硬平衡 |
| 应付 2202 | 2202 贷余 | 应付单未付合计 | 硬平衡 |
| 预付 1123 | 1123 借余（供应商辅助） | 供应商账户预付余额合计（含 QCYF 补录） | **提示性** |
| 厂家费用 1221 | 1221 供应商辅助**累计形成额**（期末借余 + 本年贷方兑现累计） | EXPENSE 流水 FACTORY_EXP_FORM/RED/REVERSE 累计 | **提示性** |
| 资金 | is_cash 科目 | 资金账户余额 | 硬平衡 |

- **1221 勾稽公式**：累计形成额 = 期末未兑现余额 + 本年已兑现贷方累计；
  业务侧即「费用余额 + 已兑现发生额」。注意已全额兑现（借贷相等）的供应商仍出现在明细里，不能漏；
- 顶部标志：「✓ 三组硬平衡」只看应收/应付/资金；预付/厂家费用不平只亮橙色提示，**不阻断月结**。
  卡片上有「提示性对账」徽章与差异说明，展开可按供应商逐户对。

### 5.2 允许的账财边界：总账手工凭证不回业务账

会计直接在总账用 1123/1221 供应商辅助做手工凭证（补税金、科目重分类、押金备用金等）**不会回写业务账**，
这是系统的既定边界。这类凭证会让业财对账出现差异——差异只要能按「总账手工凭证 + 凭证号」逐户解释即可；
非厂家性质的其他应收（员工备用金、押金）不要挂供应商辅助，避免混进 1221 厂家费用组。

### 5.3 日结向导与定版台账

- 日结向导第 5 步应付滚存下方新增三项提示：账户预付（1123）合计、费用余额（1221）合计、
  2202 负应付重分类合计；**只提示、不参与硬勾稽**；
- 应付定版台账与 RJ 日结单每个供应商三列分列：**预付（2202重分类）/ 预付余额（1123账户）/ 费用余额（1221）**；
- **资产负债表预付账款 = 1123 账户余额 + 2202 负余额重分类额**，两个口径不要求相等；
- 同一供应商两边都挂钱时出**红色双计提示**：通常是同一笔预付既以负应付挂在 2202、又通过期初/补录录进了 1123，
  请财务核对后冲掉一边。

## 六、供应商停用/删除守卫与档案余额

- 停用或删除供应商前，系统要求该供应商业务**全部完结**，任一存在即中文拒绝并列出数量：
  三余额（应付/预付/费用）任一不为 0、有未结应付单、有已审未全兑 JF、有未作废 DX/FX；
  按提示先结清/反审核/作废对应单据再操作；
- **两个停用入口同守一套规则**：行内「删除」走确认弹窗；档案里没有独立停用按钮，停用请走
  「编辑 → 状态下拉选停用 → 保存」。编辑保存改为停用态时后端同样执行五守卫，被拒不产生任何改动，
  弹窗提示「保存失败：无法停用供应商…」。
- 供应商档案列表的「应付余额」列**改取供应商账户真值**（旧档案余额列已停用写入，仅留历史）；
  账户三余额均受字段权限 **VIEW_AP_BALANCE** 控制。

## 七、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| DX 保存并审核按钮是灰的 | 上下两区合计不等（含 5711 未填原因）；按标题提示把差额调平 |
| DX 冲应付选不到某张应付单 | 已被核销完、未审核，或不是该供应商；账扣候选只列未结 AP（到期日升序） |
| JF 审核提示已被兑现不能反审核 | 先反审核该 JF 的 DX（已红冲部分不拦）；已封账日的改走红字 JF |
| FE 选择器里找不到某张客户费用单 | FE 未审核，或整单已被另一张 JF 关联（一张 FE 只能申报一次）；重新申报走红字+手工行 |
| 预付退款审核被拒「超过预付余额」 | 退款金额大于该供应商当前预付余额；先查账户流水是否已核销/转预付 |
| 业财对账 1221/1123 有差额但业务看着平 | 多为总账手工凭证或押金/备用金挂了供应商辅助；按供应商明细逐户对凭证号，可解释即正常（提示性组不阻断） |
| 停用供应商被拒 | 按中文提示结清余额/单据后再停（见第六章） |
| 已日结/月结后发现期初预付漏录 | 不要动应付期初初始化（已锁定）；走页内「期初预付补录」，多批可补，可整批反建账 |
| 看不到余额数字 | 角色缺字段权限 VIEW_AP_BALANCE，找系统管理员授权后重新登录 |
