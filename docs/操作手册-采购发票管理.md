# 采购发票管理 — 系统说明及操作手册

> 适用版本：V1.3（PRD-30，Flyway V93：审核后继续勾稽、勾稽金额/税率可编辑）
> 适用对象：采购内勤、往来会计、财务主管
> 配套文档：设计方案见 `docs/采购发票管理-设计方案.md`，落地记录见 `docs/优化记录-PRD30-采购发票管理.md`

## 一、模块是做什么的

商贸批发业务中，**货先到、票后到**是常态：供应商的货收了、应付账款也立了，但增值税发票可能隔几周甚至几个月才来。本模块解决三个问题：

1. **录入发票**：供应商发票到手后，登记发票号码、**发票金额（票面价税合计）**等信息；
2. **勾稽 / 取消勾稽**：把发票上的商品与该供应商**已入库未开票的商品行**按**数量**勾对（哪张票开的是哪批货的哪几个商品、各多少数量），勾错了随时移除；
3. **来票跟踪与报表**：随时回答「哪些货来了票、哪些没来票、来票率多少、该催谁开票」。

**操作主流程：录入发票 → 勾稽发票 →（勾错可）取消勾稽 → 审核。** 录入时只要求填发票金额，**不强制当场勾稽**——票到了先登记，核对清楚后再勾稽。

### ⚠️ 一条核心原则：票账分离

| 发票模块**做**的事 | 发票模块**不做**的事 |
|---|---|
| 登记进项发票信息与发票金额 | ❌ 不生成应付账款（应付在**采购收货单审核**时已按含税金额生成） |
| 按商品行勾稽、记录来票状态 | ❌ 不影响付款、不改变库存成本 |
| 统计来票率、税额、未票余额 | ❌ 价格差错不走发票改，走「采购改价单」 |

发票审核只做一件账务相关的事：把收货单和应付账款上的**来票跟踪标记**（未来票 / 部分来票 / 已来票）回写上去。**审核后勾稽有变动（补勾、改数量/金额、取消勾稽）点「保存勾稽」即增量回写，不必反审核**；作废、反审核则只把本发票自己贡献的来票额精确剥除（同一收货单上其他发票勾稽的部分不受影响）。

> 金额口径与采购全模块一致，为**价内税**：收货单单价为含税单价，勾稽金额默认 = 本次开票数量 × 含税单价（**可手工改金额**）；税额 = 含税金额 × 税率 ÷ (1 + 税率)。

## 二、菜单入口

| 菜单 | 位置 | 用途 |
|---|---|---|
| **采购发票** | 采购管理 → 采购发票 | 发票台账：录入、勾稽、审核、认证、作废 |
| **采购来票跟踪(按单据)** | 报表中心 | 每张收货单的来票情况，催票主表 |
| **采购来票跟踪(按商品)** | 报表中心 | 每个商品的来票情况，按商品催票 |
| **供应商来票统计** | 报表中心 | 每个供应商的来票率、进项税额、认证进度 |
| **未勾稽发票** | 报表中心 | 票已审核但还没对应完货（发票金额未勾完）的发票 |
| **勾稽差异明细** | 报表中心 | 勾稽尾差/置平差异清单 |

此外，**采购管理 → 采购收货单**列表和**财务管理 → 应付账款**列表中都有「来票状态 / 来票金额」列，不用进发票模块也能一眼看到哪些单没来票。打开已审核的**采购收货单详情**，单据信息区显示「来票状态 / 已来票金额（含税）」，商品明细表逐行显示**已开票数量 / 已开票金额 / 未开票金额**——发票勾稽审核（或审核后保存勾稽、反审核、作废）后按商品行实时回写，可直接与供应商按行对票。

> 报表中心菜单点不开/看不到时，按 `Ctrl+F5` 强制刷新浏览器加载最新版本（菜单随版本更新）。

## 三、名词与状态说明

### 3.1 发票自身状态（状态）

| 状态 | 含义 | 可做的操作 |
|---|---|---|
| **草稿** | 录入后未审核，数据可随意改，**不影响任何来票状态** | 编辑、勾稽/取消勾稽、审核、删除 |
| **已审核** | 审核通过，来票状态已回写到收货单/应付，**主信息锁定** | 查看、**继续勾稽/改勾稽（保存勾稽）**、**认证**、**追加备注**、反审核、作废 |
| **已作废** | 发票作废（如开错、退回），来票回退，**票号继续占用不可复用** | 仅查看 |

### 3.2 勾稽状态（发票金额 vs 已勾稽金额）

| 状态 | 判定 |
|---|---|
| **未勾稽** | 没有任何勾稽商品行（票先录入、货还没勾） |
| **部分勾稽** | 已勾稽金额与发票金额有差额（差额 > 1 元） |
| **已勾稽** | 已勾稽金额与发票金额一致（差额 ≤ 1 元容差） |

列表与抽屉页脚实时显示：**发票金额、税额、已勾稽金额、未勾稽金额、勾稽状态**。

### 3.3 认证状态

| 状态 | 含义 |
|---|---|
| **未认证** | 默认，发票尚未在增值税发票综合服务平台勾选认证 |
| **已认证** | 已认证抵扣。**已认证发票不可反审核、不可作废**（税务上只能走红字发票流程，二期支持） |
| **无需认证** | 如增值税普通发票、不抵扣的情形 |

认证状态只能在发票**已审核**后登记。

### 3.4 来票状态（收货单 / 应付账款上的标记）

| 状态 | 判定 |
|---|---|
| **未来票** | 来票金额为 0 |
| **部分来票** | 已来票一部分，尚有余额（差额 > 1 元） |
| **已来票** | 来票金额与收货金额一致（差额 ≤ 1 元容差） |

## 四、日常操作流程

### 4.1 录入发票（先把票登记进来）

**路径：采购管理 → 采购发票 → 「新建发票」**

打开发票抽屉后填写**发票信息**：

| 字段 | 必填 | 说明 |
|---|---|---|
| 采购发票单号 | 自动 | 保存后自动生成，`PINV` 开头 |
| 发票号码 | ✅ | 税票上的发票号码；同供应商同红蓝方向唯一，**作废票号也不可复用** |
| 发票代码 | | 全电发票（数电票）没有代码，可空 |
| 发票类型 | ✅ | 增值税专用发票 / 增值税普通发票 / 电子发票 / 全电发票 |
| 供应商 | ✅ | 选定后才能勾稽该供应商的未开票商品；⚠️ 保存后供应商不可更改，选错请删除草稿重建 |
| 开票日期 | ✅ | 税票上的开票日期 |
| 收票日期 | | 实际收到发票的日期 |
| **发票金额（含税价税合计）** | ✅ | **按发票票面价税合计填写**。这是发票的基准金额，勾稽金额不能超过它（+1 元容差） |
| 认证状态 | 审核后可改 | 草稿期固定为未认证 |
| 购买方抬头 / 购买方税号 | | 我方开票信息，备查验用 |
| 备注 | | 草稿期可直接填写；审核后见 4.5「追加备注」 |

填完点 **「保存」** 即完成录入（草稿状态）。**此时可以一行都不勾稽**——票到了但还没核对对应哪批货时，先把票录进来，核对后再勾稽。

> 抽屉页脚实时显示：发票金额、税额（按勾稽明细估算）、已勾稽金额、未勾稽金额、勾稽状态。

### 4.2 勾稽发票（弹窗选择未开票商品行）

在发票抽屉中点 **「+ 勾稽商品」**，**弹出勾稽商品窗口**，窗口中列出该供应商的**未开票商品列表**（来源：该供应商所有**已审核收货单**中、尚有未开票数量的商品行）：

| 列 | 含义 |
|---|---|
| **进货单号** | 采购订单号（CGDD…） |
| **入库单号** | WMS 入库单号（CGRK…，无入库环节时显示收货单号） |
| **入库日期** | 收货/入库日期 |
| **商品编号 / 商品名称 / 规格 / 单位** | 商品档案信息 |
| **数量 / 单价 / 金额** | 该收货商品行的收货数量、**含税单价**、含税金额 |
| **税率** | 该收货商品行的税率（如 13%），勾稽后默认带入勾稽明细 |
| **已开票数量** | 该商品行已被其他发票（含草稿，不含作废）勾稽的数量 |
| **未开票数量** | 剩余可勾稽数量（红色），即本次还能开多少 |
| **已开票金额** | 该商品行已被其他发票（含草稿，不含作废）勾稽的**含税金额** |
| **未开票金额** | 剩余可勾稽的**含税金额**（红色），即本次还能开多少钱 |

操作：

1. 可用商品编号/名称关键字**搜索**过滤；
2. 勾选本张发票对应的商品行（可跨收货单多选——一张票对应多张收货单/多个商品），点 **「添加选中（N）」**；
3. 添加后进入下方勾稽表，**「本次开票数量」默认等于未开票数量**、**「本次金额」默认等于未开票金额**（全额勾稽；源单据上的已勾稽金额实时回写，所以带出的就是真实剩余额）。一张收货单分多次开票时，把数量/金额改成本次实际开票值即可；
4. **本次金额**默认带出剩余未开票金额，改数量后随数量联动（数量 × 含税单价）；**也可以直接手工改金额**（票面金额与收货金额有小差异时按票填）；
5. **税率默认从收货单明细带入**，票面税率与收货不一致时可直接改（如 13% 改 9%）；**本次税额**按「金额 × 税率 ÷ (1+税率)」自动算出并实时显示；
6. 勾稽表下方实时校验：本次数量必须 > 0 且不能超过未开票数量，勾稽合计不能超过发票金额。

**防重复占量**：已被其他发票（含未审核草稿）勾稽的数量/金额会立即从「未开票数量 / 未开票金额」中扣除，两张票不会勾到同一批货、同一笔钱。

### 4.3 取消勾稽

勾错了（选错商品行、数量填多、票货对应关系搞错）：

- 在勾稽表中点该行 **「取消勾稽」**，商品行即移除；
- 取消后该商品行**立即回到未开票商品列表**，未开票数量恢复，可以重新勾稽或留给别的发票；
- 草稿期取消后点「保存」即可；**已审核发票取消/增改勾稽行后点「保存勾稽」**，来票状态即时增量回写，**无需反审核**（见 4.6）。

### 4.4 勾稽明细（抽屉内唯一明细表，铺满窗口下部）

- 抽屉下方只保留 **一张「勾稽明细」表**，表格区域**铺满抽屉下部**（记录少时不拉高、记录多时表内滚动，表头固定）：每行 = 本发票勾稽某收货单上的某商品。明细表只展示**身份列 + 四个开票列**：进货单号、入库单号、入库日期、商品编号、商品名称、规格、单位，以及 **税率**（可改，默认带源单据税率）、**本次开票数量**（可改）、**本次开票金额**（可改，默认带未开票金额）、**本次税额**（自动算）；
- **输入框下方的余量提示**：编辑态下，「本次开票数量」输入框正下方显示小字 `未开票 {数量}`、「本次开票金额」正下方显示 `未开票 ¥{金额}`——即该商品行当前还能开票的数量/金额上限，填数时直接对照：本次数量/金额超过这两个值保存时会被拒绝。源单据数量、单价、已开票/未开票数量与金额等全量信息在「+ 勾稽商品」选单弹窗中查看（弹窗保留全部列）；
- 勾稽明细全部来自「+ 勾稽商品」弹窗选择，**不再提供手工补行**——发票只登记有收货依据的商品行，保证票货一致；
- 数量红线：**本次开票数量必须 > 0，且不得超过源单据数量、不得超过未开票数量**，行内即时红字提示；**保存与审核时后端再次校验**，超量直接拒绝（提示「商品 X 在收货单 Y 的未开票数量仅 Z，本次填写 W」）；
- 金额红线：**勾稽合计不得超过发票金额**（+1 元容差）；同一收货单上多张发票合计超过收货金额（超 1 元容差）也会拒绝；
- 本次税额 = 本次金额 × 税率 ÷ (1+税率)，头税额/不含税金额由系统按勾稽明细自动汇总，无需手工维护。

### 4.5 审核、认证与追加备注

**审核**：草稿核对无误后点 **「审核」**（或列表行操作「审核」）。

- 系统弹出确认框，显示发票金额、已勾稽金额、勾稽状态；
- 审核时会**按数量二次校验**未开票数量（防止保存草稿期间被别的发票抢先勾稽）；
- 审核通过后：收货单、应付账款的来票金额按勾稽数量×单价累加，来票状态变为 **部分来票 / 已来票**；发票转「已审核」，**主信息锁定**。
- 尾差容差：某收货单本次勾稽与未票金额差额 **≤ 1 元** 时系统**自动置平结清**，尾差记入「勾稽差异明细」报表；超出 1 元的多勾直接拒绝。

**审核后可做的三件事**（发票号码/供应商/发票金额等主信息锁定，以下不受影响）：

1. **继续勾稽 / 调整勾稽**：见 4.6，点「保存勾稽」即回写，无需反审核；
2. **认证操作**：点「认证」登记已认证，或「撤销认证」改回；普票可选「无需认证」。**已认证发票不可反审核、不可作废**；
3. **追加备注**：抽屉底部「追加备注」区填写内容后点「保存备注」，新内容自动追加到原备注后（以「；」分隔），无需反审核。

### 4.6 审核后继续勾稽（保存勾稽，无需反审核）

发票审核后发现勾稽要调整——补勾了商品、数量填多填少、金额按票面改、勾错行要取消——**直接在已审核发票的抽屉里改，不必反审核**：

1. 打开已审核发票（列表行「查看」，或在「未勾稽发票」报表点【勾稽】），勾稽明细区仍可编辑：可「+ 勾稽商品」补行、改「本次开票数量/本次开票金额/税率」（输入框下方有未开票余量提示供对照）、点「取消勾稽」移除行；
2. 改完点工具栏 **「保存勾稽」**：
   - 系统按最新勾稽重新计算并**增量回写**收货单/应付的来票金额与来票状态（未来票/部分来票/已来票），发票勾稽状态（未勾稽/部分勾稽/已勾稽）同步刷新；
   - 数量、金额红线与草稿期一致（超未开票数量、勾稽合计超发票金额、跨发票合计超收货金额均拒绝，且**拒绝时不会半写**，原状态不变）；
   - 头税额/不含税额按最新勾稽重算；
3. **多张发票勾稽同一张收货单互不影响**：本发票保存勾稽/反审核/作废时，只动自己贡献的那部分来票额，别的发票已勾的金额不会被冲掉。

> 已作废发票勾稽区只读，不可再保存勾稽。

### 4.7 反审核 / 作废 / 删除

| 操作 | 入口 | 条件与效果 |
|---|---|---|
| **反审核** | 已审核发票行操作 / 抽屉按钮 | **精确剥除本发票贡献的来票额**（同一收货单上其他发票勾稽的部分保留），发票回到草稿，可改主信息/勾稽。已认证不可反审核 |
| **作废** | 已审核发票行操作 / 抽屉按钮 | 必须**填写作废原因**；同样精确剥除本发票来票额并释放勾稽数量；作废后仅可查看。已认证不可作废 |
| **删除** | 草稿行操作「删除」/ 抽屉「删除草稿」 | 仅草稿可删，删除后不可恢复 |

反审核/作废后，对应商品行的未开票数量**立即释放**，重新出现在未开票商品列表里，可以被新的发票勾稽。

> 提示：只是勾稽要调整（补勾/改数量金额/取消行）时用 4.6「保存勾稽」即可，**不必反审核**；反审核适用于要改发票号码、供应商、发票金额等主信息的情形。

### 4.8 列表查询

台账列表列：采购发票单号、发票号码、发票类型、供应商、开票日期、**发票金额、税额、已勾稽金额、未勾稽金额、勾稽状态**、认证状态、状态、操作。

筛选条件：**开票日期区间、发票号码、供应商、发票类型、勾稽状态（未勾稽/部分勾稽/已勾稽）、认证状态、状态**；支持「导出」Excel。

行内操作按状态自动收敛：

- 草稿：**编辑 · 审核 · 删除**
- 已审核：**查看 · 认证/撤销认证 · 反审核 · 作废**
- 已作废：**查看**

## 五、报表怎么用

所有报表均在 **报表中心**，只读，支持筛选与导出。

### 5.1 采购来票跟踪（按单据）— 催票主表

- **数据范围**：全部已审核采购收货单。
- **列**：收货单号、收货日期、采购单号（进货单号）、供应商、仓库、收货金额、来票金额、未票金额、来票率、来票状态、**账龄天数**（自收货日起算）、关联发票号。
- **典型用法**：每月初筛「来票状态 = 未来票 / 部分来票」，按账龄从大到小排序，导出发给采购员向供应商催票。

### 5.2 采购来票跟踪（按商品）— 按商品催票

- 按商品汇总收货与来票的**数量**、金额。
- 典型用法：财务要按产品线统计进项缺口，或某商品长期没来票需要核查。

### 5.3 供应商来票统计 — 付款前必看

- **列**：供应商、收货金额、来票金额、未票金额、来票率、**发票份数、进项税额、已认证税额、未认证份数**。
- 典型用法：
  - 付款审批前看该供应商未票余额，票没到的可协商先票后款；
  - 月末看「未认证份数」，提醒及时认证抵扣，避免超期；
  - 与供应商对账时核对收货额与来票额。

### 5.4 未勾稽发票 — 票到了没对应完货

- 列出已审核但勾稽状态为「未勾稽 / 部分勾稽」的发票（发票金额尚有未勾稽余额）。
- **行内【勾稽】按钮**：点击直接弹出该发票的发票抽屉，**勾稽操作与采购发票模块完全一致**——可「+ 勾稽商品」补行、调整本次开票数量/金额/税率、取消勾稽，改完点「保存勾稽」即增量回写来票状态（无需反审核）；保存后报表自动刷新，已勾稽完的发票从本表消失。也可在抽屉内直接做认证、反审核、作废。
- 两种常见原因：**票先到、货还没收/没审核**（等收货审核后，直接在本报表点【勾稽】补勾稽即可）；**票多开了**（联系供应商处理，1 元内置平、超 1 元差异留痕）。

### 5.5 勾稽差异明细 — 尾差台账

- 列出审核时自动置平的勾稽尾差：发票号、收货单号、收货金额、勾稽前已来票、本次勾稽金额、差异金额。
- 典型用法：月末复核尾差是否都在 1 元容差内，异常大额差异追查。

## 六、典型业务场景速查

| 场景 | 操作 |
|---|---|
| **货票同到，全额开票** | 录入发票（填票面金额）→「+ 勾稽商品」勾选对应商品行（默认全额）→ 保存 → 审核 |
| **票晚到（最常见）** | 货到时正常做收货单审核；收货单在报表中一直是「未来票」；票到后录入发票、勾稽商品、审核，状态自动变「已来票」 |
| **票到了但还没核对对应哪批货** | 先录入发票（只填金额保存），台账中勾稽状态为「未勾稽」；核对清楚后编辑，「+ 勾稽商品」补勾再审核 |
| **一张发票对应多张收货单** | 勾稽选单时跨收货单勾选多个商品行一并添加 |
| **一张收货单分多次开票** | 第一张票勾稽时把「本次开票数量」改成部分数量；收货单显示「部分来票」；第二张票到时再勾剩余数量 |
| **勾稽选错/数量填错** | 草稿期直接点该行「取消勾稽」，商品行回到未开票列表，重选或改数量即可；**已审核也一样改，改完点「保存勾稽」**（见 4.6） |
| **审核后才发现要补勾/改勾稽** | 不用反审核：打开已审核发票，「+ 勾稽商品」补行或改数量/金额/税率，点「保存勾稽」即回写来票状态 |
| **几毛钱尾差** | 不用处理，审核时 1 元内容差自动置平，尾差进差异报表 |
| **发票开错（未认证）** | 已审核的直接「作废」（填原因），重新录入正确发票；草稿直接删除 |
| **发票开错（已认证/已跨月）** | 系统拦截作废操作，联系供应商开红字发票（红字流程二期上线） |
| **审核后要补充说明** | 无需反审核，抽屉底部「追加备注」直接保存 |

## 七、常见提示与处理

| 提示 / 现象 | 原因与处理 |
|---|---|
| 「+ 勾稽商品」列表为空 / 提示没有未开票商品 | 收货单还没审核，或该供应商商品已全部开票完毕；先去采购收货单模块审核 |
| 保存/审核被拒：未开票数量仅 X，本次填写 Y | 该商品行已被其他发票（含草稿）勾稽或数量填多了；调小「本次开票数量」，或取消其他发票的重复勾稽 |
| 审核被拒：勾稽合计超过发票金额 | 勾稽的钱比发票票面还多，核对发票金额是否填错、勾稽数量是否过大 |
| 审核被拒：请取消勾稽后修改再审核 | 草稿保存期间未开票数量被别的发票抢先占用，按提示取消相关行后重新选择 |
| 认证后不能反审核/作废 | 先「撤销认证」；已申报抵扣的按红字流程处理 |
| 保存提示发票号码已存在 | 同一供应商发票号码唯一，**作废的票号也不可复用**，核对是否重复登记 |
| 草稿保存后发现供应商选错 | 供应商保存后锁定，删除草稿重新录入 |
| 审核后发现勾稽有误（补勾/数量/金额/税率/取消行） | **直接在抽屉里改，点「保存勾稽」即可**，无需反审核；要改发票号码/供应商/发票金额等主信息才需「反审核」回草稿（已认证的先撤销认证） |
| 保存勾稽被拒：收货单 X 未票金额仅 Y，本次勾稽后合计 Z 超出容差 | 同一张收货单已被别的发票勾了大部分，本票勾稽金额填多了；调小本次金额/数量后重新保存 |
| 报表中心看不到发票报表菜单 | 按 `Ctrl+F5` 强制刷新浏览器加载最新菜单 |

## 八、本期边界（暂不支持）

以下能力在二期/三期，表结构已预留：

1. **红字发票**与采购退货的勾稽（退货来票冲减）；
2. **认证期限预警**（开票后 N 天未认证自动提醒）；
3. 供应商对账单「是票开票」自动关联；
4. OCR 取票、发票自动查验（三期）。

本期发票均为蓝字进项发票；收到红字发票先在纸面/税务侧处理，系统中暂以备注说明。
