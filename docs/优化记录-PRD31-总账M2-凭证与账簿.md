## 关键规则落地

1. **凭证号**：审核时生成「字-yyyyMM-4 位」，同期同字取 MAX+1；反审核后原号作废、再审核占新号；作废/红冲留号不补（冒烟实测：0001 反审核后再审核得 0002，作废 0003 留号，后续顺排）。
2. **期间锁定**：只有「进行中」期间可录单/审核/过账；启用月之前「已结账」、之后「未开始」一律拦截。
3. **红冲口径（重要）**：原凭证状态置「已冲销」，红字凭证 is_red=TRUE、金额取负、直接过账；**账簿发生额取数包含「已冲销」原单**（与红字凭证轧差为净 0），即 `status IN ('已过账','已冲销')`；序时账同样展示。作废凭证（从未过账）不进任何账簿。
4. **分录校验**：至少 2 条、借贷必相等（差 < 0.005）、每行只能借或贷一方、金额非负、科目必须末级且启用、科目配置的辅助维度必填且未配置维度不得传值、数量核算科目必须录数量；摘要留空时继承凭证摘要。
5. **实时聚合口径**：期初取 fin_init_balance（启用期期初借/贷/数量+年累发生），发生额取已过账+已冲销分录；启用年年初余额 = 期初净额 − 年累发生净额；父级科目金额按编码前缀（4/6/8/10 位）逐级汇总；全零科目不出余额表。
6. **分页注意**：`PageResult.of` 会用 PageRequest.filters 做内存模糊匹配，已在 SQL 过滤的结构化参数不能进 filters（pageNo/dateFrom 等会被当检索词），controller 侧传空 map。
