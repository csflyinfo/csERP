## 关键问题与风险

> 状态更新：2026-07-16 — 阶段一优化已完成 8 项（详见 [`优化记录-V1.0-阶段一.md`](./优化记录-V1.0-阶段一.md)），另 #5 完成 A–D（Flyway 接入 + MERGE/ALTER/INDEX 全部改写为 MySQL 兼容），E–H（真 MySQL 联调）待 Docker 环境。

### 🔴 高风险

|#|问题|影响|建议|状态|
|---|---|---|---|---|
|1|**后端接口无授权控制** — Spring Security 所有请求 `permitAll()`，仅靠 JWT 验证登录态|任何登录用户可访问任意接口|增加基于角色的接口级授权|✅ 已改|
|2|**前端 Token 存储键不一致** — `erp-token` vs `erp-demo-token`|登录后路由守卫可能无法识别已登录状态|统一为一个键|✅ 已改|
|3|**依赖版本全用 "latest"** — package.json 所有核心依赖未锁定版本|`npm install` 可能获取不兼容版本|锁定具体版本号|✅ 已改|
|4|**密码明文风险** — 支持明文密码回退，虽会自动升级但首次暴露|密码安全性不足|强制 BCrypt，禁止明文回退|✅ 已改|

### 🟡 中风险

|#|问题|影响|建议|状态|
|---|---|---|---|---|
|5|**H2 → MySQL 迁移** — 开发用 H2，生产用 MySQL，语法差异（如 MERGE INTO）|切换时可能出问题|尽早切换到 MySQL 开发|🟢 A–D 已完成，E–H 待联调|
|6|**前端双 HTTP 客户端** — Axios 和 Fetch 并存，401 处理逻辑不同|维护成本高，行为不一致|统一为一个 HTTP 层|✅ 已改|
|7|**无 TypeScript** — 前端全部 JavaScript|大型项目缺乏类型安全|至少核心模块迁 TS|🟡 待办|
|8|**配置文件巨大** — module-config.js + module-api.js 超千行|维护困难|按模块拆分配置文件|🟡 待办|
