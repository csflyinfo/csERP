## 2. 已确认/落地的业务口径

### 财务 5 表（#20～#24）

1. **时点回放**：账龄表是时点报表，只认 `filters.cutoff`（默认今天）；立账日 ≤ 截止日才参与，核销/付款按发生时刻在截止日前回放，截止日后动作一律不计。
2. **桶边界**：到期日 ≤ 截止日为逾期，未到期（到期日晚于截止日，含当天）单列；逾期分 1-30 / 31-60 / 61-90 / 91-180 / 180+ 五桶；负余额（预收/预付）归未到期。
3. **含税口径**：应收/应付/回款/付款全部含税；红冲/取消审核流水为红字负行。
4. **往来恒等式**：#23 期初 + 本期新增 − 本期回款（+减免展示列）= 期末；#24 期初 + 本期新增 − 本期付款 + 折让/核销 = 期末；不依赖当前余额反推，全部由 `fin_reconcile_record` 实算。
5. **#24 默认期间（K2）**：截止昨天，起始=截止日上月同日的前一天（与一/二期 K2 相同的「上月同日退一天」）。
6. **信用额度占用率** ≥ 80% 前端标红；#21 已收票/未收票金额取当前台账状态。
7. **现金日记账**：期初余额 → 逐笔流水（独立滚算）→ 日小计 → 月/年合计，独立滚算余额与台账 `balance_after` 逐笔校验，差 1 分标 `MISMATCH` 红字；账户多选、收支方向/项目/对方/单号过滤；默认自然月本月。

### 库存分析（#6/#7）

1. **缺货判定（满足其一）**：① 可用+采购在途 ≤ 0；② 可用+在途低于库存下限（系统无独立安全库存字段，`stock_lower_limit` 即安全库存）；③ 可销天数（可用 ÷ 近 30 天签收日均）小于主供应商交货周期。
2. **在途口径**与 #5 采购预测完全一致：已审核未终止采购订单行 − 已审核入库实收（按基础单位换算）。
3. **建议补货量** = 库存下限 + 日均 × 交货周期 − 可用 − 在途。
4. **连续缺货/流失估算**：按日结快照回推连续缺货天数；估算流失销量 = 断货段内最高日均（近似断货前日均）× 连续天数。测试/预发同样按日结跑快照，**不做流水倒推开关**（Q6）。
5. **周转率**：周转率（次）= 期间销售成本（K8 签收配比成本，按签收日落期间）÷ 平均库存成本（期初取开始日前一天快照、期末取截止日快照）；周转天数 = 期间日历天数 ÷ 周转率；**呆滞**=期末有库存且零周转，或周转天数 > 系统参数 `REPORT_SLOW_TURNOVER_DAYS`（P0183，默认 60，区间 1～3650）。默认周转率升序（最慢在前，NULL 置尾），合计/合计行周转率按总成本÷总平均库存加权，天数由加权率反推。
6. 两表均支持「按商品汇总 / 商品+仓库」粒度切换；仓库/分类/品牌/温区/商品/供应商/采购员过滤；数据范围按仓库+商品隔离。

### 综合分析（#17）

1. KPI（采购入库净额、签收净额、毛利额/率、签收单数、客户数、客单价、期末库存金额）均带**等长上一期间环比**；趋势支持按日/按月，销售/毛利为签收口径、采购为入库口径；结构区为分类销售占比饼图、TOP20 商品（金额/毛利切换）、TOP10 客户。
2. 明细表每行一个商品：采购数量/金额、签收数量/金额、去重客户数、签收单数（`v_rpt_sales_detail` 正数账单数）、配比成本、毛利/率、期末库存数量金额、可销天数；支持异步导出。
3. 图表跨总量聚合屏不挂行级数据范围（同工作台口径），金额按字段码脱敏。

### 绩效 2 表（#18/#19）

1. **#18 直接汇总八类已完成作业事实**（不依赖 `wms_performance_daily` 日报——该日报仅覆盖收货/上架两类，拣货/复核/盘亏等列恒为 0）：收货=结束收货（`received_at`）、上架=`DONE/finished_at`、拣货=`PICKED/picked_at`、复核=`PASS/checked_at`（出库 NG 落 `wms_exception`，不写复核表）、补货=`DONE/finished_at`、盘点=`APPROVED/finished_at`、调整=`APPROVED/approved_at`、异常=`wms_exception/created_at`；作业归属日一律取**完成时刻日期**；仓库取任务表仓库名（WMS 全表按名称隔离）。
2. 一人期内跨岗按「仓库 × 人 × 岗位」拆行（收货 RECEIVER / 上架 PUTAWAY / 拣货 PICKER / 复核 CHECKER，补货+盘点+调整+异常归 KEEPER）。
3. **盘盈盘亏金额** = Σ（差异数量 × 成本），成本取批次移动平均（按商品+仓+批次），取不到回退商品仓均价；异常表无仓库列，由波次/入库任务回填，均无则归空仓。
4. **作业时长**仅拣货（`claimed_at→picked_at`）、上架（`started_at→finished_at`）、补货（`started_at→finished_at`）三段可算（系统无开始/回车里程字段，不产出工时/里程列）；作业效率 = 可计量作业总行数 ÷ 作业小时；差错率 = 异常单数 ÷ 作业总行数。
5. **#19 司机归因只认调度单司机**（`tms_dispatch.driver_id`，不使用 `sign_user`——未挂调度/后台代签会错归系统账号）：计划单数按调度日；签收/拒收单数、签收数量、货值、客户数按**签收日**（DELIVERED/PARTIAL/RETURNED 计签收，REJECTED 计拒收，RESCHEDULED 不计）；趟次=非取消行程；随车退货=`WAREHOUSED`；代收货款=已审核交账单现金+线上，实际缴款=`actual_submit`，差异=`diff_amount`；行驶时长=`depart_time→complete_time`；里程（无回车读数）与准时率（无预约时段承诺字段）本期不做。货值/代收按字段权限脱敏（可对司机屏蔽金额）。

## 3. H2 兼容要点（均已实测验证）

- **窗口 CTE + 绑定参数缺陷**：H2 2.2.224 下「含 JOIN/子查询的 CTE 被上层窗口函数 CTE 消费、且谓词用绑定参数」时结果集被错误置空（同 SQL 改日期字面量即正常）。#6 历史/趋势路径与一期台账一样走 `SqlLiterals` 零参字面量渲染，日期来自服务端解析的 `LocalDate`，文本参数做单引号转义；阈值（库存下限/交货周期）用标量子查询取，档案 JOIN 全部移到窗口之后。
- **DECIMAL 除法精度相减**：`DECIMAL(p,2)/DECIMAL(p,4)` 结果标度为负会被舍入到十位，可销天数等比率比较统一 `CAST(... AS DOUBLE)`。
- Java 文本块尾空格会被裁导致 SQL 片段粘连（如 `SELECTg.goods_code`），拼接处一律用普通字符串显式写空格。
- ORDER BY 中输出列别名不能用表达式包裹（`CASE WHEN 别名 IS NULL` 报列不存在），需要 NULL 置尾时直接用 `NULLS LAST`。
- `value` 是保留字，#17 分类饼图别名加双引号。
