## 四、核心业务域

### 4.1 采购与应付域

```
采购预测(AI) → 采购订单 → 收货(PDA) → 采购收货单(成本计算) → 应付账款
                                              │
                    采购退货 ← 退货出库(PDA) ← 退货申请
                                              │
                    采购改价 ──→ 成本重算 + 应付调整
                    采购费用分摊 ──→ 入库成本重算
```

**核心数据对象**：采购订单 · 采购收货单 · 采购退货单 · 供应商应付 · 采购改价单 · 采购费用单
**关键管控**：到货天数 · 成本核算(移动加权平均) · 账期 · 预付款 · 费用分摊

### 4.2 销售与应收域

```
客户 → 销售开单(价匹配+信控+库存检) → 审核 → WMS波次 → 拣货出库 → 配送签收 → 应收 → 收款核销
                                              │
                    促销匹配 ← 促销活动        │
                    客户价格 ← 客户价格设置     │
                    退货回收 ← 司机APP         │
```

**核心数据对象**：销售订单 · 销售收货单 · 销售退货单 · 客户应收 · 促销活动 · 客户价格
**关键管控**：价格匹配(3级) · 信用额度 · 最低售价 · 账期 · 促销 · 库存锁定

### 4.3 WMS仓库域

```
┌──────────────────────────────────────────────────┐
│ 入库流程：收货 → 质检 → 上架(策略推荐库位)         │
│ 出库流程：波次下放 → 拣货(路径优化) → 复核 → 装车  │
│ 库内流程：盘点 · 移库 · 补货 · 组合拆分 · 报损     │
│ 策略引擎：上架策略/拣货策略/波次策略/补货策略       │
└──────────────────────────────────────────────────┘
```

**核心数据对象**：库位 · 入库指令 · 出库指令 · 波次 · 盘点单 · 补货任务
**关键管控**：批次追溯 · FIFO/FEFO · 库位推荐 · 路径优化 · 补货触发

### 4.4 TMS配送域

```
装车确认(PDA) → 司机APP接单 → 导航 → 到达 → 签收(签名+拍照)
                                    │
                              ┌─────┼─────┐
                             收款  退货  拒收
```

**核心数据对象**：配送单 · GPS轨迹 · 签收记录 · 电子回单
**关键管控**：GPS实时上报 · 电子围栏 · 超时预警 · 运费结算

### 4.5 财务域

```
┌──────────────────────────────────────────────────────┐
│ 应收应付：销售生成应收 · 采购生成应付                   │
│ 收付款：收款单/付款单/费用单                           │
│ 核销：收款单×应收 · 付款单×应付                        │
│ 账期：五种账期方式 · 预计结款日 · 逾期判断              │
│ 凭证：凭证模板 · 自动生成 · 审核过账                   │
│ 资产：固定资产 · 折旧 · 清理                          │
└──────────────────────────────────────────────────────┘
```
