## 三、收款结算链路（详细）

```
时间线 ──────────────────────────────────────────────────────────────→

D0: 销售开单
  ├─ 结算方式判断：
  │   ├─ 现结 → 收款完成 → 销售单审核
  │   └─ 赊账/月结 → 进入账期计算
  │
  ├─ 销售订单.最近结款日 = NULL（欠款订单）
  └─ 销售订单.结算方式 = 赊账/月结

D1: WMS 出库审核
  ├─ 生成销售出库单
  ├─ 账期计算：
  │   ├─ 门店未设账期 → 预计结款日 = 签收日 + 系统默认账期天数(3天)
  │   ├─ 月结(固定付款日) → 截账日 + N月 + 付款日
  │   ├─ 月结(账期天数) → 截账日 + 天数
  │   ├─ 半月结 → 半月截止日 + 天数
  │   ├─ 周结 → 周六 + 天数
  │   └─ 固定账期天数 → 单据日 + 天数
  └─ 销售出库单.预计结款日 = 计算结果

D2: TMS 配送签收
  ├─ 司机APP签收 → 销售收货单
  ├─ 现结(司机收款) → 销售出库单.最近结款日 = 收款日期
  └─ 赊账 → 最近结款日 保持 NULL

D3: 应收生成
  └─ 生成应收账款记录

Dn: 客户付款
  ├─ 业务员APP收欠款 → 最近结款日 = 提交日期
  ├─ 客户打款到银行 → 出纳录入收款单
  └─ 客户结算 → 收款单生成

Dn+1: 收款核销
  ├─ 收款单 × 应收记录 → 核销
  ├─ 更新 最近结款日 = 核销日期
  └─ 触发凭证生成

逾期判断：
  当前日期 > 预计结款日 AND 最近结款日 IS NULL
  → 逾期天数 = 当前日期 - 预计结款日
  → 应收账龄分析报表更新
```

## 四、仓储作业流程 (WMS)

```
┌──────────────────────────────────────────────────────┐
│                    入库作业                           │
│                                                      │
│  采购订单 ──→ PDA收货 ──→ 质检 ──→ 上架(策略推荐)    │
│                              │                       │
│                      ┌───────┼───────┐              │
│                     合格    让步    不合格            │
│                      │       │        │              │
│                      ▼       ▼        ▼              │
│                    正常   降价接收   退货              │
│                    上架   正常上架   拒收              │
│                                                      │
│  退货入库：司机回收 → PDA扫描 → 退货仓上架             │
│  拒收入库：司机拒收 → PDA扫描 → 原成本冲回            │
│  其他入库：后台手工 → PDA确认 → 成本取当前            │
└──────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────┐
│                    出库作业                           │
│                                                      │
│  波次下放(按线路/片区聚合)                            │
│       │                                              │
│       ▼                                              │
│  PDA领取拣货任务 → 路径排序 → 按序拣货               │
│       │                                              │
│       ├─→ 扫描库位校验 → 扫描商品 → 输入数量          │
│       ├─→ 缺货标记 → 触发补货(被动补货)              │
│       └─→ 拣货完成 → 送至复核区                      │
│                                                      │
│  复核：逐件扫描 → 应发vs实发对比                      │
│       ├─→ 一致：通过 → 打印面单                      │
│       └─→ 差异：少发/多发/错发处理                    │
│                                                      │
│  装车确认：扫描配送单 → 确认装车 → 集货位释放         │
└──────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────┐
│                    补货作业（新增）                    │
│                                                      │
│  触发方式：                                          │
│  ① 主动补货：定时扫描拣货位库存 < 安全库存            │
│     → 自动生成补货任务 → 仓库人员PDA领取              │
│  ② 被动补货：拣货时发现库存不足                      │
│     → 触发即时补货 → 从存储位补到拣货位              │
│                                                      │
│  补货执行(PDA)：                                     │
│  领取补货任务 → 到存储库位取货 → 扫描 →              │
│  搬运到拣货库位 → 上架确认 → 补货完成                │
└──────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────┐
│                    库内作业                           │
│                                                      │
│  盘点：后台计划/PDA发起 → 逐库位扫描 → 差异对比       │
│       → 盘盈入库/盘亏出库 → 库存调整                  │
│                                                      │
│  移库：PDA扫描源库位 → 商品 → 目标库位 → 确认         │
│                                                      │
│  组合：后台申请 → 审核 → PDA出库(散件) → PDA入库(组合)│
│  拆分：后台申请 → 审核 → PDA出库(原品) → PDA入库(新)  │
│                                                      │
│  报损：后台申请 → PDA确认 → 成本=当前成本价           │
│                                                      │
│  生产日期修改：PDA扫描库位+商品 → 选择新日期 → 确认   │
└──────────────────────────────────────────────────────┘
```

## 八、系统状态流转总图

```
采购域状态：
  采购订单: 草稿→待审批→已审批→部分入库→入库完成→已关闭
  采购收货单: (WMS自动生成)→已审核
  采购退货单: (WMS自动生成)→已审核

销售域状态：
  销售订单: 草稿→已审核→已出库→配送中→已签收→已完成/已关闭
  销售收货单: (WMS自动生成)→已生成→已调整
  销售退货单: (WMS自动生成)→已审核

WMS域状态：
  入库指令: 待收货→收货中→已收货→已上架→已审核
  波次: 已生成→已下放→拣货中→拣货完成→复核完成→已发运
  盘点单: 待盘点→盘点中→已提交→已审核
  补货任务: 待补货→补货中→已完成

TMS域状态：
  配送单: 待装车→已装车→配送中→已到达→已签收→已完成

财务域状态：
  收款单/付款单: 草稿→已审核→已核销
  费用单: 草稿→待审批→已审核→已分摊
  凭证: 草稿→已审核→已过账
```
