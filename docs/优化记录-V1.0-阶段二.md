### 3. 价格组多模块管理（PRD v2.0）

**核心业务规则**：

- 价格组不允许新建/删除，系统预置 10 条 `PG01~PG10 配送价1~配送价10`，`is_system=TRUE`
- 编辑只允许改 `price_group_name / sort_order / remark`；启停走独立端点
- 停用时清空所有关联客户的 `price_group_code`
- 关联客户 > 0 时可在列表点击查看门店明细（含 xlsx 导出）
- 商品数从 `base_price_group_item` 聚合真实统计

**数据模型（V4 + V5 迁移）**：

- `base_price_group` +`is_system`
- `base_customer` +`price_group_code`
- `base_price_group_item` — 商品价格（三元组唯一 + `is_active`）
- `base_price_adjust_order` — 调价单头（状态机 DRAFT → PENDING → APPROVED / REJECTED）
- `base_price_adjust_order_item` — 明细（三个单位新价 + old_price 快照）
- `base_price_change_log` — 变价日志（含 order_id / old_price / change_type）

**新增后端**：

- [`BaseMasterController.java`](../backend/src/main/java/com/erp/base/BaseMasterController.java) `/price-group/enable` `/customers`；`priceGroupPage` 单独实现聚合 `customerCount` / `goodsCount`；save 拦截禁止新建 priceGroup + 编辑跳过 rejectIfSystem
- [`PriceGroupExtController.java`](../backend/src/main/java/com/erp/base/PriceGroupExtController.java) — 新 Controller，10 个端点（F2/F3/F4）；`applyOnePrice()` 事务内 upsert 价格 + 写日志（`ADJUST_INIT` / `ADJUST_UPDATE`）；`generateOrderNo()` 生成 `TJ+yyyyMMdd+3位流水`

**新增前端**：

- **路由 & 菜单**：`/price-group-item /price-adjust-order /price-change-log` 三条；`fallback-menus.js` 加 3 项
- **module-config.js**：4 个模块独立配置
- **module-api.js**：3 组端点映射；新增列字段（调价单号/单位级别/变价前后/变动幅度/变更类型 派生列）
- [`PriceAdjustDrawer.vue`](../frontend/src/components/PriceAdjustDrawer.vue) — 调价单专用抽屉：
  - 单据头 + 明细网格 + 商品选择器 + Excel 导入（模板下载）
  - 按 status 自适应按钮组（DRAFT → 保存/提交；PENDING → 审核/驳回；APPROVED/REJECTED → 只读）
- [`GenericBusinessList.vue`](../frontend/src/views/GenericBusinessList.vue)：
  - 3 个模块的派生列（loadRows 里做 unitLevelText / oldPriceText / changeRateText / changeTypeText / statusText）
  - `buildPriceGroupTree()` — 价格组商品查询左树
  - 操作列分支：priceGroupItem 启停单条；priceAdjustOrder 按 status 展示 查看/提交/删除/审核通过/驳回
  - `exportCurrentModuleXlsx()` — 前端 xlsx 直接导出（拉全量 10000 + 应用派生列 + XLSX.writeFile）
- 关联门店弹窗导出从 CSV 改为 xlsx
