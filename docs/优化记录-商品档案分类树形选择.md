# 优化记录：商品档案「商品分类」改为末级树形选择

- 日期：2026-09-13
- 分支：feat/base-goods-category-tree-select
- 模块：base（商品档案）
- 涉及文件：
  - `frontend/src/views/goods/components/CategoryTreeSelect.vue`（新增）
  - `frontend/src/views/goods/components/BaseInfoForm.vue`（接入树选择器、全量拉分类）
  - `frontend/src/views/goods/components/BatchEditDrawer.vue`（全量拉分类 + 状态过滤）

## 一、需求

商品档案新增/编辑抽屉中「商品分类」字段：

1. 下拉以**树状结构**展示**正常状态**的商品分类；
2. **只有末级分类可点选**回填商品分类字段，点非末级只展开/收起；
3. 支持输入关键字对**末级分类名称**模糊查询，平铺返回命中项。

## 二、原实现问题

- 分类是一个普通 `<select>` 平铺 480 个分类名，无层级、中间层也能被选中保存；
- 选项只取 `/base/category/page` 第一页。后端单页硬上限 200（`PageRequest.safePageSize`），
  480 个分类只能拿到前 200，末级集合缺数据，中间层可能因「看不到子级」被误判为末级；
- 不区分分类状态，停用分类照样可选。

## 三、实现方案

### 1. 新增 CategoryTreeSelect.vue（手写组件，项目无 Element Plus）

- 输入为全量**扁平**节点 `{ categoryCode, categoryName, parentCode, defaultTaxRate }`，
  组件内部用 Map 建树；`parentCode` 指向不存在父级的节点按根节点处理（容错脏数据）。
- 同级按 categoryCode 中文数字序（`localeCompare('zh', { numeric: true })`）排序。
- **树态**：一级默认全部收起；点非末级行只切换展开，点末级行才
  `emit('update:modelValue')` + `emit('select', { name, taxRate, code })` 并关闭面板；
  已选项再次打开高亮并带 ✓。
- **搜索态**：输入关键字后仅在「无子节点」记录中按名称不区分大小写匹配，
  最多返回 100 条；每条平铺显示「末级名 + 祖先路径」（如 `休闲零食 / 饼干点心`）消歧。
  中间层「饼干点心」即使名称命中也不出现。
- 键盘：↑↓ 移动、Enter 选中、Esc 关闭；点组件外部关闭；× 清除。
- 历史值对应分类已被停用/删除时，控件保留原值但显示橙色边框警示（不丢数据、不阻止保存）。

### 2. 面板定位：Teleport + fixed（关键坑）

抽屉 `.drawer-body { overflow-y: auto }`，面板若用 absolute 定位在控件下方，
会被滚动容器裁剪（小视口/滚动后必然出现）。最终方案：

- 面板 `<Teleport to="body">`，`position: fixed`，z-index 1200（高于抽屉遮罩 500）；
- 打开时按控件 `getBoundingClientRect()` 实时计算坐标与可用高度：
  下方空间 ≥200px 向下展开，否则向上展开；面板最大高 340px、极限小屏保底 160px，树体内部滚动；
- 捕获阶段监听 `scroll`（含抽屉内部滚动）与 `resize`，rAF 节流重算，面板始终贴住控件；
- 面板根节点 `@mousedown.stop`，配合 document 外部点击关闭逻辑。

### 3. BaseInfoForm.vue

- 新增 `fetchAllCategories()`：pageSize=200 **循环翻页**拉全量分类（按 total 结束、50 页安全阀）；
- 仅保留 `status` 为空/`NORMAL`/`正常` 的分类，映射为树组件节点；
- 抽屉每次打开（reloadTrigger）重新拉取，新维护的分类立即可见；
- 选中末级后保留原有「分类 → 税率」联动（税率值如 `9%` 原样回填，数字补 `%`）；
  清空分类时不清税率（可能是手工设置）。

### 4. BatchEditDrawer.vue

批量编辑弹窗的分类下拉同步改为**循环翻页全量 + 末级判定 + NORMAL 过滤**
（原本同样只取第一页且含中间层、停用项）。交互保持原生单选，不扩大改造范围。

## 四、真实浏览器验收（Edge headless + CDP，admin 登录）

26 项断言全部通过，覆盖：

- 新增抽屉打开后默认只显示 12 个一级分类，下级全部收起；
- 点非末级仅展开（行数 12→20），分类字段不回填；
- 沿树展开点末级「粗粮饼干」→ 字段回填、面板自动关闭、税率联动为 9%；
- 重开面板已选末级高亮；× 可清除；
- 搜「饼干」命中 10 条末级（与后端叶子集合逐一比对一致），中间层「饼干点心」不出现，
  每条带「休闲零食 / 饼干点心」祖先路径，点击回填并关面板；
- 无关键字结果显示「未找到」空态；Esc 关闭；
- 面板 fixed/视口内无裁剪/elementFromPoint 可交互；抽屉滚动时面板跟随（偏差 0px）；
- 完整新建商品（7 个必填项齐全）只调用 `/base/goods/create`、code=0、落库分类正确，
  再以编辑模式打开回显正确、无停用橙框；
- 验收临时商品 TESTCTS* 已软删并经 H2 Shell 物理清理，环境还原。

## 五、备注

- `/base/goods/page` 当前**不过滤** DELETED 状态（软删商品仍出现在列表），是既有行为，未在本次改动；
- 分类最大层级 3 级；480 个分类全部 NORMAL、叶子无重名（2026-09-13 实测）。
