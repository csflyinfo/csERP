## 一、前端实现目标

V1.0前端实现应优先满足：

```text
稳定
高效
可维护
字段可配置
表格性能好
单据录入快
权限控制清晰
可持续扩展到WMS/TMS/B2B
```

前端不是简单还原视觉图，需要把ERP高频操作能力、网格配置能力、权限能力和状态反馈做成基础能力。

## 二、推荐技术栈

### 2.1 Web后台

建议：

```text
Vue 3 + TypeScript + Vite + Pinia + Vue Router
```

UI组件库可选：

```text
Element Plus / Ant Design Vue / 自研业务组件层
```

建议做法：

- 基础组件可基于成熟UI库。
- 业务组件必须自研封装。
- 表格组件必须增强，不直接裸用普通表格。

│  ├─ dashboard/

│  ├─ finance/

## 三、布局实现规范

### 3.1 AppShell

系统壳组件：

```text
AppShell
├─ TopBar
├─ SideMenu
└─ MainContent
```

### 3.2 顶部栏 TopBar

功能：

- 系统名称。
- 模块快捷搜索。
- 导出中心。
- 消息中心。
- 用户信息。

实现要求：

- 顶部高度固定56px。
- 模块搜索支持键盘回车跳转。
- 用户信息点击弹出用户详情。
- 导出中心跳转/打开导出任务面板。

### 3.3 左侧菜单 SideMenu

实现要求：

- 一级菜单默认展示。
- 当前一级菜单展开其二级菜单。
- 切换一级菜单时，自动收起原二级。
- 当前二级菜单高亮。
- 菜单权限由后端返回或前端路由元数据控制。

菜单数据结构建议：

```ts
interface MenuItem {
  code: string
  name: string
  icon?: string
  path?: string
  children?: MenuItem[]
  permissionCode?: string
}
```

## 四、路由规范

### 4.1 路由命名

建议：

```text
/base/goods
/base/customer
/base/supplier
/purchase/order
/purchase/inbound
/sales/order
/inventory/balance
/finance/receivable
/system/user
```

### 4.2 页面类型路由

列表页：

```text
/purchase/order
```

新增页：

```text
/purchase/order/create
```

编辑页：

```text
/purchase/order/edit/:id
```

详情页：

```text
/purchase/order/detail/:id
```

### 4.3 路由状态保持

从列表进入编辑，再返回列表时必须恢复：

- 查询条件。
- 分页页码。
- 排序状态。
- 表格列配置。
- 滚动位置。

## 五、通用数据网格实现规范

### 5.1 DataGrid组件能力

必须支持：

```text
字段显示/隐藏
字段拖拽排序
字段宽度调整
表头排序
固定列
分页
当前页合计
查询总合计
导出主单
导出明细
空态
加载态
错误态
```

### 5.2 字段配置模型

```ts
interface GridColumnConfig {
  field: string
  title: string
  visible: boolean
  width?: number
  fixed?: 'left' | 'right'
  sortable?: boolean
  align?: 'left' | 'center' | 'right'
  permissionCode?: string
  summaryType?: 'sum' | 'count' | 'avg' | 'none'
  order: number
}
```

### 5.3 用户字段配置保存

接口建议：

```text
GET  /api/system/grid-config/get
POST /api/system/grid-config/save
POST /api/system/grid-config/reset
```

保存维度：

```text
userId + pageCode + gridCode
```

### 5.4 表格性能

- 超过100行建议虚拟滚动。
- 横向列多时必须固定操作列。
- 不在单元格中渲染过多复杂组件。
- 金额/数量字段使用等宽数字。
- 汇总计算优先后端返回，前端只做当前页汇总。

## 六、查询表单实现规范

### 6.1 查询区组件

建议组件：

```text
SearchPanel
```

能力：

- 默认展示一行高频查询条件。
- 展开更多展示低频条件。
- 支持重置。
- 支持保存常用查询方案。
- 支持Enter触发查询。

### 6.2 查询项类型

| 类型 | 组件 |
|---|---|
| 客户 | CustomerSelect |
| 供应商 | SupplierSelect |
| 商品 | GoodsSelect |
| 仓库 | WarehouseSelect |
| 人员 | EmployeeSelect |
| 状态 | EnumSelect |
| 日期 | DateRangePicker |
| 金额 | AmountRangeInput |
| 数量 | QuantityRangeInput |
| 综合搜索 | SearchTypeInput |

### 6.3 查询状态保持

- 查询条件存入页面store。
- 返回列表时恢复。
- 重置时清空除默认日期外的条件。

## 七、单据编辑实现规范

### 7.1 BillEditor组件

```text
BillEditor
├─ BillHeader
├─ BillDetailGrid
└─ BillSummaryBar
```

### 7.2 单据头 BillHeader

要求：

- 4列或6列紧凑布局。
- 高频字段直接展示。
- 低频字段放入更多信息。
- 必填字段标红星。
- 审核后字段只读。

### 7.3 单据明细 BillDetailGrid

要求：

- 占据编辑页主要区域。
- 默认展示多行空白行。
- 支持键盘录入。
- 支持扫码录入。
- 支持复制行、删除行、插入行。
- 支持导入明细。
- 支持选择商品/来源单据。

### 7.4 底部汇总 BillSummaryBar

固定在编辑页底部。

常见字段：

```text
数量
商品金额
税额
费用金额
成本金额
毛利
应收金额
应付金额
已收/已付
未收/未付
```

### 7.5 单据状态控制

| 状态 | 页面行为 |
|---|---|
| 草稿 | 可编辑、可删除 |
| 待审核 | 可编辑，按权限控制 |
| 已审核 | 只读，可反审核 |
| 已完成 | 只读 |
| 已关闭 | 只读 |
| 已作废 | 只读 |

## 八、快捷键实现规范

### 8.1 快捷键注册

建议使用统一Hook：

```ts
useShortcut(keys, handler, options)
```

### 8.2 快捷键作用域

- 当前激活页面生效。
- 弹窗打开时弹窗优先生效。
- 输入框中避免拦截普通文字输入。

### 8.3 必须支持

```text
F2 主对象
F3 商品
F4 常用/历史
F5 保存草稿
F6 提交/审核
F7 新增明细行
F8 删除明细行
F9 重算金额
Ctrl+S 保存
Ctrl+Enter 提交/审核
```

## 九、权限实现规范

### 9.1 权限类型

```text
菜单权限
按钮权限
数据权限
字段权限
操作权限
```

### 9.2 字段权限

敏感字段：

```text
采购价
成本单价
成本金额
毛利
毛利率
客户欠款
供应商余额
资金余额
```

无权限时：

- 列表隐藏字段。
- 表单隐藏字段或显示为 `***`。
- 导出时不导出。
- 汇总中不显示。

### 9.3 按钮权限

无权限时：

- 高风险操作按钮不显示。
- 或置灰并显示无权限原因。

## 十、导入导出实现规范

### 10.1 导入

导入流程：

```text
下载模板
上传文件
预校验
显示校验结果
确认导入
失败原因下载
```

### 10.2 导出

支持：

```text
导出主单
导出明细
导出当前页
导出查询结果
```

大数据导出进入导出中心。

导出需遵循字段权限和当前字段设置。

## 十一、状态与反馈实现规范

### 11.1 Toast

成功：2秒自动关闭。  
失败：3-5秒，可手动关闭。  
不遮挡主操作区域。

### 11.2 错误提示

表单错误：

- 字段红框。
- 字段下方错误文案。
- 顶部错误摘要。
- 自动滚动到第一个错误字段。

### 11.3 二次确认

以下操作必须确认：

```text
删除
作废
反审核
付款审核
报损审核
成本调整审核
采购费用审核
初始化启用
```

---

## 十二、页面性能规范

- 路由级代码分割。
- 大表格虚拟滚动。
- 表格查询防抖。
- 导出异步化。
- 图片附件懒加载。
- 避免在表格单元格中创建大量复杂组件。
- 页面切换保留状态，避免重复请求。

---

## 十三、前端验收要点

开发完成后必须确认：

```text
菜单权限正确
路由跳转正确
列表查询条件可用
字段设置可保存
表格排序可用
导出主单/明细可用
单据新建/编辑/审核可用
明细行键盘录入可用
金额/数量计算正确
权限字段隐藏正确
返回列表保留查询状态
```
