## 一、验收原则

V1.0 UI验收不只检查“页面是否好看”，还必须检查：

```text
页面结构是否符合业务流程
字段是否符合PRD
查询是否可用
列表是否可配置
单据是否先列表后编辑
明细录入是否高效
状态是否清晰
权限是否生效
异常是否有提示
导入导出是否可追溯
```

验收优先级：

| 优先级 | 说明 |
|---|---|
| P0 | 上线必须满足，不满足不可上线 |
| P1 | 首版应满足，可短期补齐 |
| P2 | 体验增强，后续迭代 |

## 十二、最终上线前UI验收结论

上线前必须满足：

```text
P0 项全部通过
P1 项无严重阻塞
业务主流程页面可完整操作
高风险操作有提示
字段权限可控制
表格交互可用
财务闭环可演示
库存追溯可演示
```

如 P0 未通过，不建议进入开发验收或上线评审。
