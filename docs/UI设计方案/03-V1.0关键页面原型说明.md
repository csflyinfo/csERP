## 二、销售快速开单原型

### 2.1 页面结构

```text
┌────────────────────────────────────────────────────────────────────┐
│ 销售快速开单                                      快捷键帮助 [?]     │
├────────────────────────────────────────────────────────────────────┤
│ 客户[F2] [________________]  仓库[总仓▼]  业务员[张三▼]  结算[月结] │
│ 欠款：12,000  逾期：2,000  信用额度：50,000  可用额度：38,000       │
├────────────────────────────────────────────────────────────────────┤
│ 商品[F3] [扫码/编码/名称/简拼________________] [常购F4] [赠品F7]    │
├────────────────────────────────────────────────────────────────────┤
│ 商品明细                                                            │
│ 商品编码│商品名称│单位│数量│可用库存│单价│折扣│金额│成本│毛利│操作   │
│ SP001  │农夫山泉│箱 │10 │120     │35 │0  │350 │***│***│删除   │
├────────────────────────────────────────────────────────────────────┤
│ 收款方式：现金[ ] 微信[ ] 支付宝[ ] 银行[ ] 预收[ ] 赊账[√]          │
├────────────────────────────────────────────────────────────────────┤
│ 商品金额：350.00  优惠：0.00  应收：350.00  已收：0.00  未收：350.00 │
│ [挂单] [保存草稿F5] [审核F6] [审核并打印 Ctrl+Enter]                 │
└────────────────────────────────────────────────────────────────────┘
```

### 2.2 关键交互

- F2 聚焦客户搜索。
- F3 聚焦商品搜索。
- 扫码后自动带出商品并跳到数量。
- 回车在明细单元格间流转。
- 库存不足行内标红。
- 低于最低售价显示“低价”标签。
- 超信用额度顶部显示红色风险条。

### 2.3 视觉重点

- 客户风险信息紧贴客户选择区域。
- 商品搜索框占据一整行，方便扫码录入。
- 金额汇总固定底部，避免长明细时看不到合计。
- 主按钮“审核并打印”靠右，蓝色主按钮。

## 三、采购订单原型

### 3.1 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 采购订单 PO202606130001                         状态：草稿     │
├──────────────────────────────────────────────────────────────┤
│ 供应商[F2] [供应商搜索]  采购员[李四]  仓库[总仓]  日期[今天]   │
│ 预计到货[2026-06-18]  结算方式[月结30天]                       │
├──────────────────────────────────────────────────────────────┤
│ 商品[F3] [商品搜索/扫码] [历史采购F4] [添加赠品F7]               │
├──────────────────────────────────────────────────────────────┤
│ 商品明细                                                        │
│ 商品│单位│数量│单价│税率│金额│成本单价│成本金额│已入库│备注      │
├──────────────────────────────────────────────────────────────┤
│ 商品金额：10,000  税额：1,300  费用分摊：0  应付预估：11,300     │

└──────────────────────────────────────────────────────────────┘
```

### 3.2 设计重点

- 供应商选择后自动带出到货天数和结算方式。
- 商品行显示最近采购价和当前库存，可在商品选择弹窗中展示。
- 成本字段默认受权限控制。
- 已审核后明细不可编辑。

## 六、应收结算原型

### 6.1 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 应收结算                                                       │
│ 对象类型[客户▼] 对象[客户搜索] 结算日期[今天]                  │
├──────────────────────────────────────────────────────────────┤
│ 待结算应收                                                     │
│ ☑ 应收单号│来源单据│日期│应收│已收│未收│本次结算│折让│逾期天数 │
│ ☑ AR001  │SR001  │6-1│1000│200 │800 │800    │0  │5       │
├──────────────────────────────────────────────────────────────┤
│ 收款信息                                                       │
│ 收款方式[银行▼] 资金账户[工行▼] 收款金额[800] 折让[0]          │
├──────────────────────────────────────────────────────────────┤
│ 已选应收：800  本次收款：800  折让：0  结算后余额：0            │
│ [生成收款单并核销] [仅生成收款单] [打印结算单]                 │
└──────────────────────────────────────────────────────────────┘
```

### 6.2 设计重点

- 本次结算金额默认等于未收金额。
- 折让金额需要权限，默认弱化。
- 主按钮为“生成收款单并核销”。
- 结算后余额必须实时计算。

## 七、应付结算原型

布局与应收结算一致，差异：

```text
对象类型：供应商/往来单位
待结算应付列表
付款方式、付款资金账户、付款金额
生成付款单并核销
```

付款时需展示资金账户余额：

```text
当前账户余额：¥50,000.00
本次付款：¥12,000.00
付款后余额：¥38,000.00
```
