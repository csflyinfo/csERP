### 2.7 单位设置区

采用矩阵表格：

| 项目 | 基本单位 | 大单位 | 中单位 |
|---|---|---|---|
| 是否启用 | 勾选 | 勾选 | 勾选 |
| 单位 | 下拉 | 下拉 | 下拉 |
| 条码 | 输入 | 输入 | 输入 |
| 换算率 | 1 | 输入 | 输入 |
| 重量 | 输入 | 自动/输入 | 自动/输入 |
| 体积 | 输入 | 自动/输入 | 自动/输入 |

规则：

- 基本单位必填。
- 大单位、中单位可选。
- 换算率必须大于0。
- 条码不可重复。
- 多单位换算用于采购、销售、库存显示，但底层库存按基本单位计算。

### 2.8 价格设置区

采用矩阵表格：

| 价格项 | 基本单位 | 大单位 | 中单位 |
|---|---|---|---|
| 标准售价 | 输入 | 自动/输入 | 自动/输入 |
| 最低售价 | 输入 | 自动/输入 | 自动/输入 |
| 参考进价 | 输入 | 自动/输入 | 自动/输入 |
| 建议零售价 | 输入 | 自动/输入 | 自动/输入 |
| 价格组1 | 输入 | 自动/输入 | 自动/输入 |
| 价格组2 | 输入 | 自动/输入 | 自动/输入 |

规则：

- 价格联动开启时，修改任意单位价格，其他单位按换算率自动联动。
- 关闭价格联动时，各单位价格独立维护。
- 最低售价用于销售低价校验。

### 2.9 操作按钮

底部固定操作：

```text

取消
```

### 6.1 单位管理

列表列（共 6 列，无「类型/分组」和「备注」）：

```text
单位编码
单位名称
是否中单位（是/否）
是否大单位（是/否）
状态
操作（编辑/删除）
```

新建/编辑弹窗（480×动态高度）：

|字段|控件|说明|
|---|---|---|
|单位编码|输入框|唯一，编辑时不可修改|
|单位名称|输入框（必填）|例如「瓶」「箱」「提」|
|是否中单位|复选框|勾选后该单位可被商品档案的「中单位」下拉引用|
|是否大单位|复选框|勾选后该单位可被商品档案的「大单位」下拉引用|
|状态|下拉（仅编辑显示）|正常 / 停用|

规则：

- 表单不再出现「可作为基本单位」字段；后台保存时 `canBaseUnit` 恒为 true（兼容老数据）。
- 中/大两个开关允许同时勾选（一个单位可以同时充当中单位和大单位）。
- 停用（`STOPPED`）的单位在商品档案所有单位下拉里都不再出现。

商品档案联动规则：

|商品单位列|下拉数据来源|
|---|---|
|小单位（基本单位）|所有 `status=NORMAL` 的单位（不受两个开关限制）|
|中单位|满足 `status=NORMAL AND canMiddleUnit=true`|
|大单位|满足 `status=NORMAL AND canLargeUnit=true`|
