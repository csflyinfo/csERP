### 2.7 单位设置区

采用矩阵表格：

| 项目 | 基本单位 | 大单位 | 中单位 |
|---|---|---|---|
| 是否启用 | 勾选 | 勾选 | 勾选 |
| 单位 | 下拉 | 下拉 | 下拉 |
| 条码 | 输入 | 输入 | 输入 |
| 换算率 | 1 | 输入 | 输入 |
| 重量 | 输入 | 自动/输入 | 自动/输入 |
| 体积 | 输入 | 自动/输入 | 自动/输入 |

规则：

- 基本单位必填。
- 大单位、中单位可选。
- 换算率必须大于0。
- 条码不可重复。
- 多单位换算用于采购、销售、库存显示，但底层库存按基本单位计算。

### 2.8 价格设置区

采用矩阵表格：

| 价格项 | 基本单位 | 大单位 | 中单位 |
|---|---|---|---|
| 标准售价 | 输入 | 自动/输入 | 自动/输入 |
| 最低售价 | 输入 | 自动/输入 | 自动/输入 |
| 参考进价 | 输入 | 自动/输入 | 自动/输入 |
| 建议零售价 | 输入 | 自动/输入 | 自动/输入 |
| 价格组1 | 输入 | 自动/输入 | 自动/输入 |
| 价格组2 | 输入 | 自动/输入 | 自动/输入 |

规则：

- 价格联动开启时，修改任意单位价格，其他单位按换算率自动联动。
- 关闭价格联动时，各单位价格独立维护。
- 最低售价用于销售低价校验。

### 2.9 操作按钮

底部固定操作：

```text

取消
```
