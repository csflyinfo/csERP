# V1.0 ERP核心经营版 — ERP后台UI设计方案

> 文档版本：v1.0  
> 编写日期：2026-06-13  
> 适用范围：V1.0 ERP后台PC Web  
> 设计重点：高密度数据、快速录入、强状态识别、字段可配置、财务库存准确表达

---

## 一、ERP后台整体布局

### 1.1 页面框架

建议采用经典企业后台布局：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部栏：Logo / 面包屑 / 全局搜索 / 消息 / 用户 / 设置           │
├──────────────┬───────────────────────────────────────────────┤
│ 左侧菜单      │ 内容区                                         │
│ 工作台        │ 页面标题                                       │
│ 基础资料      │ 查询区                                         │
│ 采购管理      │ 操作区                                         │
│ 销售管理      │ 数据表格/表单                                  │
│ 库存管理      │ 分页/汇总                                      │
│ 财务管理      │                                               │
│ 报表中心      │                                               │
│ 系统管理      │                                               │
└──────────────┴───────────────────────────────────────────────┘
```

### 1.2 左侧菜单

- 一级菜单常驻左侧。
- 当前菜单高亮使用主蓝色。
- 支持菜单折叠。
- 菜单项使用统一线性SVG图标。
- 不使用emoji图标。

### 1.3 顶部栏

顶部栏包含：

| 元素 | 说明 |
|---|---|
| 系统名称 | B2B-ERP-WMS-TMS 或企业简称 |
| 面包屑 | 当前页面路径 |
| 全局搜索 | 搜索客户、商品、单据号 |
| 消息通知 | 审批、预警、导出完成 |
| 快捷入口 | 快速开单、库存查询、收款 |
| 用户菜单 | 个人信息、退出、主题/密度设置 |

## 二、工作台UI设计

### 2.1 页面目标

工作台用于老板、管理层、内勤快速查看经营状态和待处理事项。

### 2.2 页面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 今日销售额 | 今日订单数 | 今日收款 | 应收余额 | 应付余额 | 库存金额 │
├──────────────────────────────────────────────────────────────┤
│ 待办事项                     │ 风险预警                         │
│ 待审核销售订单 12             │ 逾期应收 35                      │
│ 待审核采购订单 8              │ 低库存商品 48                    │
│ 待确认销售收货 16             │ 临期商品 21                      │
├───────────────────────────────┼────────────────────────────────┤
│ 销售趋势折线图                │ 应收账龄分布                     │
├───────────────────────────────┼────────────────────────────────┤
│ 商品销售排行                  │ 客户销售排行                     │
└──────────────────────────────────────────────────────────────┘
```

### 2.3 指标卡片

卡片内容：

- 指标名称
- 指标值
- 同比/环比
- 趋势箭头
- 点击跳转明细

视觉：

- 关键数字使用 24-32px。
- 金额使用千分位。
- 逾期、风险类指标用红色提示。

## 三、高级数据网格UI规范

### 3.1 工具栏

所有列表页右上角统一提供：

```text
[刷新] [密度] [字段设置] [导出] [更多]
```

### 3.2 字段设置

字段设置弹窗：

```text
┌──────────────────────────────┐
│ 字段设置                      │
├──────────────────────────────┤
│ 搜索字段 [________]           │
│                              │
│ ☑ 单据号      ⋮⋮             │
│ ☑ 客户        ⋮⋮             │
│ ☑ 金额        ⋮⋮             │
│ ☐ 备注        ⋮⋮             │
│                              │
│ [恢复默认] [取消] [保存]       │
└──────────────────────────────┘
```

### 3.3 表格底部汇总

表格底部固定显示：

```text
当前页合计：数量 120 | 金额 35,000.00 | 成本金额 28,000.00
查询总合计：数量 2,300 | 金额 690,000.00 | 成本金额 510,000.00
```

无权限字段不显示合计。

### 3.4 表格密度切换

密度按钮可选：

```text
紧凑 / 默认 / 宽松
```

## 四、销售快速开单UI设计

### 4.1 设计目标

销售快速开单是全系统最高频页面，要求：

```text
少鼠标
少跳转
少弹窗
强校验
强快捷键
快速录入
```

### 4.2 页面布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ 销售快速开单                                                        │
│ 客户[F2] [搜索客户/扫码]  仓库[总仓]  业务员[张三]  结算[月结30天]    │
│ 欠款：¥12,000  逾期：¥2,000  信用额度：¥50,000  可用：¥38,000        │
├────────────────────────────────────────────────────────────────────┤
│ 商品[F3] [扫码/编码/名称/简拼] [常购F4] [历史订单] [赠品F7]           │
├────────────────────────────────────────────────────────────────────┤
│ 商品明细                                                            │
│ 商品 | 单位 | 数量 | 可用库存 | 单价 | 折扣 | 金额 | 成本 | 毛利 | 操作 │
│ 农夫山泉 | 箱 | 10 | 120 | 35.00 | 0 | 350.00 | *** | *** | 删除 │
├────────────────────────────────────────────────────────────────────┤
│ 收款：现金[ ] 微信[ ] 支付宝[ ] 银行[ ] 预收款[ ] 赊账[√]            │
├────────────────────────────────────────────────────────────────────┤
│ 商品金额：350.00  优惠：0.00  应收：350.00  已收：0.00  未收：350.00 │
│ [挂单] [保存草稿F5] [审核F6] [审核并打印 Ctrl+Enter]                 │
└────────────────────────────────────────────────────────────────────┘
```

### 4.3 客户信息风险条

客户选择后显示风险条：

| 状态 | 展示 |
|---|---|
| 正常 | 灰底/蓝色信息 |
| 有逾期 | 橙色提醒 |
| 超信用 | 红色提醒 |
| 冻结客户 | 红色阻断 |

示例：

```text
⚠ 客户存在逾期应收 ¥2,000，已逾期 18 天
```

### 4.4 商品明细行内校验

| 场景 | UI反馈 |
|---|---|
| 库存不足 | 可用库存红色，行背景浅红 |
| 低于最低售价 | 单价红色，显示“低价”标签 |
| 超信用 | 顶部风险条红色，审核按钮需授权 |
| 赠品 | 行标签“赠品”，金额为0 |

### 4.5 快捷键提示

右上角显示：

```text
快捷键帮助 [?]
```

点击后展示当前页面快捷键。

## 五、采购订单UI设计

### 5.1 页面布局

```text
采购订单
├─ 供应商信息区
│  供应商、采购员、收货仓库、预计到货日、结算方式
├─ 商品明细区
│  商品、单位、数量、单价、税率、金额、成本单价、成本金额
├─ 费用/发票提示区
│  采购费用状态、发票状态、应付状态
├─ 金额汇总区
│  商品金额、税额、费用分摊、最终应付预估
└─ 操作区
```

### 5.2 设计重点

- 供应商选择后带出到货天数、结算方式、默认采购员。
- 商品选择时显示最近采购价、参考进价、当前库存、采购在途。
- 采购订单明细显示成本单价/成本金额，按权限控制。
- 已入库数量和未入库数量要在明细行展示。

## 六、采购费用单UI设计

### 6.1 页面布局

```text
采购费用单
├─ 费用基本信息
│  费用类型、收款对象、费用金额、税额、分摊方式
├─ 费用明细
│  项目、数量、单价、金额、税额
├─ 分摊对象
│  选择采购入库单
├─ 分摊预览
│  入库单、分摊比例、分摊金额、分摊后成本
└─ 审核提示
```

### 6.2 分摊预览重点

分摊预览表必须清楚展示：

```text
费用金额：1,000.00
已分摊：1,000.00
未分摊：0.00
```

表格列：

```text
入库单号 | 入库金额 | 分摊基数 | 分摊比例 | 分摊金额 | 分摊后成本金额 | 分摊后成本单价
```

### 6.3 审核风险提示

审核按钮附近显示：

```text
审核后将重算采购入库成本，可能影响后续出库成本和毛利，请确认分摊结果。
```

## 八、应收结算UI设计

### 8.1 页面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 对象类型：客户/往来单位   对象搜索   结算日期                  │
├──────────────────────────────────────────────────────────────┤
│ 待结算应收列表                                                │
│ 勾选 | 应收单号 | 来源单据 | 日期 | 应收 | 已收 | 未收 | 本次结算 │
├──────────────────────────────────────────────────────────────┤
│ 本次收款                                                      │
│ 收款方式  资金账户  收款金额  折让金额  折让原因               │
├──────────────────────────────────────────────────────────────┤
│ 已选应收：10,000  本次收款：8,000  折让：200  剩余：1,800       │
│ [生成收款单并核销] [仅生成收款单] [打印结算单]                 │
└──────────────────────────────────────────────────────────────┘
```

### 8.2 UX重点

- 主按钮为“生成收款单并核销”。
- 折让金额使用警示样式，必须填写原因。
- 只能选择同一对象的应收单。
- 勾选后自动汇总。

## 九、应付结算UI设计

应付结算与应收结算保持一致，只是方向为付款。

关键差异：

- 对象为供应商/往来单位。
- 资金账户为出账账户。
- 需校验资金账户余额。
- 主按钮为“生成付款单并核销”。

## 十一、报损单UI设计

### 11.1 风险提示

报损单顶部显示：

```text
报损会直接减少库存并形成公司损失，请确认商品、批次和数量。
```

### 11.2 明细重点

报损明细必须突出：

- 到期日期
- 当前可用库存
- 报损数量
- 成本单价
- 成本金额
- 报损原因
- 附件照片

### 11.3 高风险报损

金额超过阈值时：

- 审核按钮显示“需审批”。
- 成本金额红色强调。
- 必须上传附件或填写原因。

---

## 十二、成本调整单UI设计

### 12.1 页面重点

成本调整单不改变数量，只改变成本。

因此页面要突出：

```text
当前库存数量不变
调整前成本单价
调整后成本单价
调整差异金额
```

### 12.2 对比展示

建议明细表使用前后对比列：

```text
商品 | 当前库存 | 调整前成本 | 调整后成本 | 调整前金额 | 调整后金额 | 差异金额
```

---

## 十三、导出与快捷键

所有ERP后台页面遵循：

- 列表支持导出主单、导出明细。
- 明细导出一行商品/费用一行。
- 当前网格字段顺序影响默认导出顺序。
- 单据录入支持快捷键。
- 表格字段可拖拽、隐藏、排序、汇总。

详见：`17-V1.0-通用网格与单据交互规范.md`
