## 一、组件库设计目标

V1.0组件库服务于商贸ERP高频业务场景，优先保证：

```text
高密度展示
快速录入
状态清晰
权限可控
字段可配置
导出可追溯
长时间使用不疲劳
```

组件库不追求花哨视觉，必须优先满足业务效率和一致性。

## 三、布局组件

## 3.1 AppShell 系统外壳

### 结构

```text
AppShell
├─ TopBar
├─ Sidebar
│  ├─ 一级菜单
│  └─ 当前一级下二级菜单
└─ ContentArea
   ├─ ModuleHeader
   └─ PageContent
```

### 设计要求

- 顶部高度：56px。
- 左侧菜单宽度：216px。
- 内容区背景：浅科技蓝。
- 内容区内页面组件必须有统一内边距：14px或16px。
- 不允许页面自己覆盖系统级布局。

---

## 3.2 TopBar 顶部导航

### 内容

```text
系统名称
模块快捷搜索框
导出中心
消息
用户信息
```

### 交互

| 操作 | 行为 |
|---|---|
| 输入模块名并回车 | 跳转到对应模块 |
| 点击导出中心 | 打开导出任务列表 |
| 点击消息 | 打开待办/预警消息 |
| 点击用户信息 | 弹出用户详情 |

### 用户详情弹层字段

```text
姓名
账号
角色
数据范围
退出登录
```

---

## 3.3 Sidebar 菜单

### 规则

- 默认只展示一级菜单。
- 点击一级菜单后，该一级菜单下方展开二级菜单。
- 切换一级菜单时，原二级菜单收起。
- 当前一级菜单高亮为蓝色渐变。
- 当前二级菜单为白底蓝边。

### 菜单项高度

| 类型 | 高度 |
|---|---:|
| 一级菜单 | 38px |
| 二级菜单 | 32px |

## 五、表单组件

## 5.1 Input 输入框

### 状态

| 状态 | 视觉 |
|---|---|
| 默认 | 白底、浅蓝灰边框 |
| 聚焦 | 蓝色边框、浅蓝外发光 |
| 禁用 | 浅灰底、灰字 |
| 错误 | 红色边框、错误提示 |
| 只读 | 浅底色，可复制，不可编辑 |

## 5.2 Select 选择器

适用于：客户、供应商、仓库、商品、人员、状态、单据类型等。

### 要求

- 支持搜索。
- 支持清空。
- 长文本省略并可悬浮查看。
- 禁用项不可选择。
- 引用基础数据时，展示编码+名称更佳。

示例：

```text
C001 华联超市
G001 农夫山泉杭州经销
W001 总仓
```

## 5.3 DateRangePicker 日期区间

用于单据日期、创建时间、审核时间、收付款日期。

快捷项：

```text
今天
昨天
本周
本月
上月
近7天
近30天
```

## 5.4 AmountInput 金额输入

- 默认右对齐。
- 使用千分位展示。
- 输入时允许小数。
- 不允许非法字符。
- 负数仅红字业务允许。

## 5.5 QuantityInput 数量输入

- 默认右对齐。
- 支持小数位配置。
- 支持起订量/起订倍数校验。
- 出库类数量不可超过可用库存。

## 六、业务组件

## 6.1 BillList 单据列表

### 标准结构

```text
状态Tab
查询条件
操作按钮
单据列表
批量操作栏
分页合计
```

### 操作按钮

```text
新建
导入
导出
打印
批量审核
批量作废
批量删除
```

### 注意

进入具体单据模块后，不展示与当前模块无关的业务类型Tab。

例如进入“销售订单”，不展示：

```text
销售单 / 退货单 / 换货单 / 还货单
```

## 6.2 BillEditor 单据编辑页

### 结构

```text
顶部操作栏
紧凑单据头
明细操作条
明细录入网格
底部汇总栏
```

### 单据头

- 采用4列或6列紧凑布局。
- 只放高频关键字段。
- 低频字段进入更多信息或折叠区。

### 明细网格

- 占据页面主要空间。
- 默认显示多行空白行。
- 不因记录少而收缩。
- 支持键盘录入。

## 6.3 AmountSummaryBar 金额汇总条

位置：单据编辑页底部。

显示：

```text
数量
金额
税额
成本金额
毛利
应收/应付
已收/已付
未收/未付
```

不同单据显示不同字段。

## 八、反馈组件

## 8.1 Toast

- 成功提示：2秒自动消失。
- 失败提示：3-5秒，可手动关闭。
- 不遮挡主要操作区域。

## 8.2 ConfirmDialog

高风险操作必须二次确认。

结构：

```text
标题
风险说明
影响范围
取消
确认
```

## 8.3 EmptyState

空态文案示例：

```text
暂无数据
你可以调整筛选条件，或点击“新建”创建第一条记录。
```

## 8.4 LoadingState

- 列表加载使用骨架屏。
- 按钮提交使用loading状态。
- 避免全屏长时间空白。
