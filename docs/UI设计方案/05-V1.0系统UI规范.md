# V1.0 ERP核心经营版 — 系统UI规范

> 文档版本：v1.0  
> 编写日期：2026-06-13  
> 适用范围：V1.0 ERP核心经营版 Web后台  
> 依据文档：`PRD-版本化产品需求/V1.0-ERP核心经营版/`、`prototype/v1-erp-complete/index.html`  
> 设计目标：企业级、效率优先、数据密度高、状态清晰、交互稳定、长时间使用不疲劳

---

## 一、总体设计定位

### 1.1 产品UI定位

V1.0 ERP核心经营版是面向商贸经销企业的经营管理后台，不是营销型网站，也不是低密度管理看板。UI设计应服务于以下核心目标：

```text
快速录入
快速查询
快速审核
快速核销
快速定位异常
清楚看到库存、应收、应付、资金、成本
```

### 1.2 视觉关键词

```text
科技蓝
企业级SaaS
高密度表格
清晰状态
低装饰
强反馈
强可配置
强权限感
```

### 1.3 竞品参考方向

设计方式参考以下ERP/经营后台的通用习惯：

- 左侧一级/二级菜单结构。
- 顶部系统栏 + 模块搜索 + 用户区。
- 业务模块先列表后编辑。
- 列表上方查询条件，查询条件下方操作按钮，下面数据网格。
- 业务单据编辑页头部紧凑，明细表格占主要空间。
- 财务、库存、单据状态用标签表达。
- 表格支持字段配置、排序、汇总、导出。

| border-light | `#E5EDF7` | 表格线、分割线 |
| text-primary | `#12385F` | 标题、重要文本 |
| text-regular | `#173B5D` | 正文 |
| text-secondary | `#5D7896` | 说明文本 |

### 2.2 状态色

| 状态 | 色值 | 用途 |
|---|---|---|
| success | `#16A34A` | 已完成、已审核、已核销、正常 |
| warning | `#F59E0B` | 待审核、部分完成、即将逾期 |

### 2.3 状态标签规范

| 状态 | 样式 |
|---|---|
| 草稿 | 灰底灰字 |
| 待审核 | 橙底橙字 |

| 已完成 | 绿底绿字 |
| 已关闭 | 灰底深灰字 |

### 4.2 顶部导航栏

顶部高度建议：`56px`。

包含：

| 元素 | 说明 |
|---|---|
| 系统名称 | `商贸云 ERP V1.0` |


## 五、通用数据网格规范

### 5.1 列表页结构

业务列表页统一结构：

```text
模块标题区
状态Tab
查询条件区
操作按钮区
数据网格
底部批量操作/合计/分页
```

### 5.2 查询条件区

查询条件默认显示一行，支持展开更多。

```text
第一行：高频条件
展开更多：低频条件
```

控件类型：

| 字段类型 | 控件 |
|---|---|
| 客户 | 客户选择下拉/弹窗 |
| 供应商 | 供应商选择下拉/弹窗 |
| 商品 | 商品选择下拉/弹窗 |
| 仓库 | 仓库下拉 |
| 人员 | 人员下拉 |
| 状态 | 枚举下拉 |
| 日期 | 日期区间 |
| 金额 | 金额区间 |
| 单据号 | 输入框 |
| 综合搜索 | 下拉 + 输入框 |

### 5.3 操作按钮区

操作按钮在查询条件下方，数据网格上方。

常用按钮：

```text
新建
导入
导出
打印
批量审核
批量作废
批量删除
字段设置
```

主按钮使用蓝色，危险操作使用红色或二次确认。

### 5.4 数据网格能力

所有数据网格必须支持：

- 字段显示/隐藏。
- 字段拖拽排序。
- 字段宽度调整。
- 表头点击排序。
- 左固定列：选择框、单据号/编码。
- 右固定列：操作。
- 当前页合计。
- 查询总合计。
- 分页。
- 导出主单。
- 导出明细。

### 5.5 网格密度

ERP默认采用紧凑密度：

| 密度 | 行高 |
|---|---:|
| 紧凑 | 32px |
| 默认 | 38px |
| 宽松 | 44px |

V1.0 默认建议 `34px - 38px`。

## 六、业务单据列表规范

### 6.1 业务单据列表结构

以销售订单为例：

```text
销售订单
├─ 状态Tab：全部 / 待审核 / 已审核
├─ 查询条件：单据日期、单据编号、客户、仓库、业务员、状态等
├─ 操作按钮：新建、导入、导出、打印
├─ 数据网格
└─ 底部：已选、批量操作、当前页合计、查询总合计、分页
```

### 6.2 不展示无关业务标签

进入单一模块后，不再展示类似：

```text
销售单 / 退货单 / 换货单 / 还货单
采购订单 / 采购入库 / 采购收货 / 采购费用
```

这些不属于该单据模块自身的标签，不能放在业务单据列表顶部。

### 6.3 单据编辑页结构

```text
顶部操作栏
紧凑单据头
明细操作条
明细录入网格
底部汇总栏
```

### 6.4 单据头紧凑布局

单据头使用 6 列或 4 列紧凑布局。

原则：

- 单据头不应占据过多垂直空间。
- 高频字段优先展示。
- 低频字段进入更多信息或折叠区。
- 明细区域应占主要空间。

### 6.5 明细网格

明细网格要求：

- 占满编辑页剩余高度。
- 默认展示多行空白行。
- 不因只有一条记录而收缩。
- 支持行内编辑。
- 支持新增行、删除行、导入明细、选择商品/来源单据。

## 十、表单交互规范

### 10.1 必填校验

- 必填字段 label 加红色 `*`。
- 保存时校验必填字段。
- 错误字段红框。
- 顶部显示错误摘要。
- 自动定位第一个错误字段。

### 10.2 数量金额校验

- 数量不能小于0，红字业务除外。
- 单价不能小于0。
- 金额自动计算。
- 成本不能为负。
- 库存出库数量不能超过可用库存。

### 10.3 高风险确认

以下操作必须二次确认：

```text
审核报损单
审核成本调整单
反审核
作废
删除
付款审核
采购费用审核重算成本
```

## 十二、响应式与性能建议

V1.0 Web后台以桌面优先，建议适配：

```text
1366px
1440px
1600px
1920px
```

低于 1280px 时：

- 左侧菜单可折叠。
- 表格横向滚动。
- 操作按钮折叠进更多菜单。

性能要求：

- 大表格使用虚拟滚动。
- 导出走导出中心异步任务。
- 查询条件变更不自动请求，点击查询后请求。
- 表格列宽、排序、显示隐藏按用户保存。

---

## 十三、可访问性规范

- 文本对比度不低于 4.5:1。
- 所有按钮必须有可见文字或 aria-label。
- 键盘 Tab 顺序符合视觉顺序。
- 焦点状态必须清晰。
- 错误提示不只依赖颜色。
- 状态标签必须有文字。
