# V1.0 ERP核心经营版 — 业务单据模块高保真细化

> 文档版本：v1.0  
> 编写日期：2026-06-13  
> 适用范围：销售、采购、库存类业务单据页面  
> 设计目标：将V1.0业务单据细化到可交付高保真设计和前端实现的页面结构、字段、交互、状态和风险提示。

---

## 一、业务单据通用设计原则

### 1.1 通用流程

所有业务单据遵循：

```text
列表页 → 新建/编辑页 → 保存/提交/审核 → 返回列表
```

禁止进入模块后直接展示编辑页。

### 1.2 列表页结构

```text
模块标题
状态Tab
查询条件区
操作按钮区
数据网格
底部批量操作/分页/合计
```

### 1.3 编辑页结构

```text
顶部操作条
紧凑单据头
明细操作条
明细录入网格
底部汇总栏
```

### 1.4 明细仓库与单位换算规则

所有库存影响类单据明细增加“仓库”列，并支持业务单位开单、基本单位换算。

规则：

```text
默认按单据头仓库带入明细仓库
选择商品后优先带出商品默认仓库
是否允许一单多仓由系统参数控制
库存、成本、流水计算均以明细仓库为准
用户可按箱、件、包、瓶等业务单位开单
库存、成本、批次、流水统一按基本单位数量计算
```

明细网格必须展示：

```text
商品
仓库
业务单位
开单数量
换算率
基本单位
基本单位数量
单价
金额
成本单价
成本金额
批次
```

调拨单除外：

```text
调拨单头部维护调出仓库、调入仓库；明细不单独编辑仓库，但需记录业务单位、开单数量、换算率、基本单位数量。
```

### 2.5 关键交互

- 选择客户后带出地址、业务员、账期、信用额度、应收余额、逾期金额。
- 选择商品后带出单位、价格、可用库存、默认仓库、成本。
- 修改明细仓库后刷新可用库存、批次、成本单价。
- 库存不足行内红色提示，审核阻断。
- 超信用按系统参数提醒、阻断或审批。
- 低于最低售价显示低价标签并触发授权。
