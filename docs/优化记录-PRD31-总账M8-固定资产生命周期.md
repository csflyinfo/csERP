## 业务规则（落地口径）

1. **变更（BG 留痕）**：仅允许改部门、折旧费用科目、折旧方法及年限/工作量参数；**原值、残值、残值率一律禁改**（金额差错引导走拆分/合并/清理）。变更前后快照 JSON 入 fin_asset_change（change_type=变更，BG 流水号），无凭证。费用科目仍校验末级+借方；年限仍要求整年 ≥12 月。
2. **清理（QL 凭证 + 1606 过渡）**：
   - 转入：借 1602 累计折旧[部门]（有累计才出）/ 借 1606 固定资产清理（净值）/ 贷 1601 固定资产[部门]（原值）；
   - 收入：借 现金类科目（**带现金流量项目 CF10 处置固定资产收现**）/ 贷 1606；费用：借 1606 / 贷 现金类科目；有收入或费用时现金对方科目必填且必须是末级 `is_cash` 科目；
   - 损益结转：收益 借 1606 / 贷 5301 营业外收入；损失 借 5711 营业外支出 / 贷 1606；1606 借贷双向结平；损益额 = 收入 − 费用 − 净值，结果类型 收益/损失/持平；
   - 卡片置「已清理」并写 fin_asset_disposal，**重复清理拒绝**；清理前若当期未计提折旧给出 depWarn（当月减少当月照提的口径提示，不阻断）；凭证为 `转` 字草稿（source_bill_type=QL、source_bill_no=QL 流水号，幂等）。
3. **拆分（不生凭证）**：≥2 部分，每部分资产名必填、比例 >0，比例和与 1 的偏差 ≤0.0001；原值/累计折旧/残值/总工作量/已用工作量按比例 HALF_UP 分摊，**最后一张吃尾差**（总额减已分额，保证分文不差）；后继卡继承类别/方法/年限/购入日期/费用科目/最后折旧期（次月起提与补提口径连续）；原卡置「已拆分」，fin_asset_change 留痕 change_type=拆分。
4. **合并（不生凭证）**：≥2 张使用中卡片，且**类别、折旧方法、费用科目、使用部门四项全一致**（任一不符逐条中文拒绝）；原值/累计/残值/工作量相加，年限取最大、购入日期取最早（残值率按 残值/原值 重算 4 位）；新卡「使用中」，原卡置「已合并」，逐卡留痕 change_type=合并。
5. **盘点（只留痕）**：按期间对使用中+已停用卡片逐张登记 相符/盘亏/盘盈 + 备注，单号 PD{期间}-{三位序号}，明细 JSON 存档；**不改卡片状态、不生凭证**——盘亏确认损失后由会计在资产卡片页另行发起清理（走 1606/5711）。
6. **台账滚动表**：固定资产原值 期末 = 期初 + 本期新增（购入月=本期）− 本期减少（本期清理单原值）；累计折旧 期末 = 期初 + 本期计提（fin_asset_depreciation）− 清理转出累计；恒等偏差 <0.005 即 balanced。并列 GL 对照列（1601/1602 的 QC/本期借/本期贷/QM、折旧费用 560103+560202 本期借方发生）；账外卡片（未生成入账凭证）造成的台账 vs GL 差异属预期，页面口径已注明。
