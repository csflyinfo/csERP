# 总账模块 系统说明与操作手册

> 适用版本：总账 M1~M9 全量交付（2026-09）。本手册面向使用本系统的财务/会计人员与系统管理员。
> 验收环境地址：`http://localhost:5173`，账号 `admin` / 密码 `admin123`。总账功能全部在左侧菜单 **「总账管理」** 组下。
> 总账已随主干上线并并入日常验证环境（2026-09 起，迁移至 V101），直接用平时的 `http://localhost:5173` 即可，无需再开 5174。若菜单里看不到「总账管理」，按 Ctrl+F5 强制刷新清缓存。

---

## 第一部分　系统说明

### 1. 总账模块能做什么

总账是 ERP 的财务核算中枢：业务单据（采购、销售、库存、费用、固定资产）经审核后自动生成记账凭证，会计也可以手工填制凭证；凭证经审核、过账后形成各类账簿与会计报表，月末通过结账向导完成折旧计提、自动转账、损益结转和期末结账。

功能一览（菜单顺序即业务流程顺序）：

| # | 菜单 | 功能 |
|---|---|---|
| 1 | 会计科目 | 会计科目体系的新增、修改、停用；预置企业会计制度标准科目 |
| 2 | 总账初始化 | 启用总账、录入期初余额（含辅助核算期初）、试算平衡 |
| 3 | 核算项目 | 项目类辅助核算档案（其他辅助核算：客户/供应商/部门/员工/商品/片区复用基础档案） |
| 4 | 凭证管理 | 手工填制凭证、审核、反审核、过账、反过账、作废、红字冲销、打印、导出 |
| 5 | 待生成凭证 | 业务单据产生的凭证事件池：生成凭证、失败重生成、忽略 |
| 6 | 凭证模板 | 业务事件 → 凭证分录模板（借贷科目、金额取数表达式、辅助核算） |
| 7 | 转账模板 | 月末自动转账模板（如结转增值税、计提附加税费）的维护与启停 |
| 8 | 业务类型映射 | 其他出/入库类型 → 对方科目的对照配置（可导出 CSV） |
| 9 | 档案科目映射 | 资金账户/费用类型/商品分类 → 总账科目的对照配置（可导出 CSV） |
| 10 | 账簿查询 | 总账、明细账、序时账、科目余额表、多栏账、辅助核算余额表/明细表 |
| 11 | 资产卡片 | 固定资产卡片全生命周期：建卡、变更、清理、拆分、合并、台账 |
| 12 | 折旧计提 | 月度折旧向导：预览 → 执行，自动生成折旧凭证 |
| 13 | 资产盘点 | 固定资产定期盘点（盘亏/盘盈只留痕，不自动调账） |
| 14 | 期末处理 | 月末结账向导：8 步指引 + 自动转账/损益结转/结账/反结账 |
| 15 | 总账报表 | 资产负债表、利润表、现金流量表（公式可查看/编辑） |
| 16 | 业财对账 | 业务模块数据与总账发生额的三线核对 |

### 2. 核心业务流程

```
        ┌───────────── 一次性初始化 ─────────────┐
        │ 会计科目 → 期初余额 → 试算平衡 → 启用总账 │
        └──────────────────┬───────────────────┘
                           ▼
   日常：业务单据审核 ──事件池──▶ 自动生成凭证草稿
         会计手工填制凭证 ──────▶ 凭证草稿
                           ▼
              凭证审核 ──▶ 凭证过账（账簿/报表实时反映）
                           ▼
   月末：期末处理向导
     ① 事件检查 ② 单据检查 ③ 折旧计提 ④ 自动转账
     ⑤ 结转损益 ⑥ 结账检查（四项硬检查）⑦ 期末结账 ⑧ 业财对账
                           ▼
              账簿查询 / 三大报表 / 业财对账（随时可查）
```

### 3. 关键规则（系统自动控制，务必了解）

1. **凭证状态机**：草稿 → 已审核 → 已过账；作废、已冲销为终态。
   - 只有**草稿**能修改/删除/审核；已审核可反审核回草稿；过账后不能直接改，要改先**反过账→反审核**（或由会计做**红字冲销**）。
   - 凭证号在**审核时**生成，规则「字-年月-4 位流水」（如 记-202609-0001）；反审核、作废、红冲都**占号不补号**。
   - 借贷不平不能审核；已结账期间、未开账期间不能录入凭证。
2. **红字冲销**：对已过账凭证生成一张金额为负的红字凭证并直接过账，原凭证留痕，用于隔月更正。
3. **辅助核算 7 个维度**：客户、供应商、部门、员工、商品、项目、片区。科目是否挂辅助核算在会计科目上设置；挂了辅助核算的分录**必须填写**对应对象（片区为自由文本，其余从档案选择）。
4. **业务凭证自动生成**：采购/销售/库存/费用/固资等单据审核后，系统按「凭证模板 + 科目映射」自动生成凭证草稿，会计在**待生成凭证**或**凭证管理**里审核过账即可；生成失败会带中文原因（通常是科目映射缺失），补配后点重生成。
5. **固定资产**：当月增加次月计提、当月减少当月照提；折旧方法支持直线法、双倍余额递减法（末两年改直线）、年数总和法、工作量法；清理通过「固定资产清理」科目过渡，损益计入营业外收入/支出，处置收现自动计入现金流量表。
6. **期末结账四项硬检查**（任一不过不能结账）：① 本期凭证全部过账；② 借贷平衡（本期发生 + 期初试算）；③ 损益已结转（或无损益发生）；④ 上期已结账。
7. **反结账**：只允许反结**最后一个**已结账期间，且必须填写原因；12 月年结后期间冻结，需反年结请联系系统管理员。
8. **金额口径**：所有金额保留 2 位小数，系统内部按 BigDecimal 精确计算；账簿报表只统计**已过账**凭证（已冲销的红字凭证留账轧差）。
9. **操作留痕**：凭证的保存/审核/过账/红冲、期末转账/结账、模板与公式维护等动作全部写入操作日志（系统管理 → 操作日志可查）。

## 第二部分　操作说明（按流程）

### 步骤 0：登录与入口

浏览器打开 `http://localhost:5173`，输入账号密码登录。左侧菜单找到 **「总账管理」** 组（在「财务管理」与「报表中心」之间）。

### 步骤 1：设置会计科目（管理员/会计主管）

路径：**总账管理 → 会计科目**

- 系统已预置标准会计科目（资产/负债/权益/成本/损益），一般可直接使用。
- 需要下级明细时：选中上级科目 → 新增下级，科目编码按层级 4-2-2-2 规则（如 5602 管理费用 → 560202 折旧费）。
- 科目需设置：余额方向（借/贷）、是否末级（**只有末级科目能在凭证中使用**）、辅助核算（勾选该科目要按哪些维度核算，如部门、客户）、是否现金类科目（现金流量表取数用）、数量核算。
- 已使用的科目不能删除，只能停用。
- 2221 应交税费下的明细科目方向统一为贷方（系统保存时校验）。

### 步骤 2：总账初始化（启用前一次性完成）

路径：**总账管理 → 总账初始化**

1. 检查启用期间（默认为当前月，如 202609）。
2. 录入科目期初余额：
   - 普通科目直接录「期初借方/期初贷方」；
   - **挂辅助核算的科目**（如 1602 累计折旧按部门核算）：点该科目的辅助核算明细，逐对象录入（如 部门 D001 贷 500.00），各对象合计自动汇总到科目；
   - 启用期初借贷必须相等。
3. 点 **试算平衡**：显示「资产=负债+权益」合计，平衡后点 **启用总账**。
   - ⚠️ 启用后期初余额**锁死不可修改**（保证账实连续），务必核对无误再启用。
4. 启用时系统自动生成全年会计期间，并把启用期之前的期间批量结账。

> 提示：初始化完成后，工作台/初始化页会提示「未映射 GL 科目的资金账户/费用类型/商品分类清单」，先去步骤 4 把对照配齐，业务凭证才能顺利生成。

### 步骤 3：配置科目对照（业务凭证能自动生成的前提）

**(1) 档案科目映射** —— 总账管理 → 档案科目映射

| 对照 | 用途 |
|---|---|
| 资金账户 → 资金科目 | 收付款、费用出账户时贷记的科目（如现金账户→1001 库存现金） |
| 费用类型 → 费用科目 | 费用单借记的费用科目（未配置时系统兜底 560299 并告警） |
| 商品分类 → 收入/成本科目 | 销售签收贷记收入、结转成本借记成本（未配置兜底 500101/5401） |

每行选择科目后点「保存」。科目必须是**末级且启用**；资金账户只能选现金类科目。

**(2) 业务类型映射** —— 总账管理 → 业务类型映射

- 其他出/入库类型（如内部领用、赠品入库、期初库存）在系统管理 → 数据字典维护；本页为每个类型配置生成凭证时的**对方科目**。
- 对方科目留空 = 该类型**不生成凭证**（如期初库存）。
- 红字「未配置」表示字典里有该类型但还没配科目——业务单据审核后凭证会生成失败，补配后重生成即可。

两个页面右上角都有 **「导出对照配置（CSV）」** 按钮，导出当前全部对照（含配置状态），可用 Excel 直接打开核对/存档。

### 步骤 4：日常制单与过账

**(1) 手工凭证** —— 总账管理 → 凭证管理 → 新增

- 选择凭证字（记/收/付/转）、日期，逐行录入摘要、科目（末级）、借方/贷方金额；挂辅助核算的科目会弹出辅助对象选择（片区直接输入文字）；现金类科目可指定现金流量项目。
- 可保存为草稿随时修改；**审核**时系统校验借贷平衡、科目合法、辅助核算完整，通过后生成凭证号。
- 审核无误后点 **过账**——过账后账簿、报表立即包含该凭证。
- 操作列：查看、打印、审核/反审核、过账/反过账、作废、红冲。

**(2) 业务凭证自动生成** —— 总账管理 → 待生成凭证

- 采购入库/销售签收/收付款/费用单/固资业务等单据在原模块**审核**后，自动进入事件池（单据反审核会自动冲回）。
- 列表显示：来源单据、业务类型、状态（待生成/已生成/生成失败/已忽略/已冲回）、失败原因。
- 处理方式：选择事件点 **生成凭证**（生成草稿，再去凭证管理审核过账）；生成失败的按中文原因处理（多为映射缺失）后**重生成**；不需要生单的事件可置「已忽略」。

**(3) 凭证打印** —— 凭证管理列表 → 操作列「打印」

- 新窗口打开打印页：单位名称、凭证号、日期、附件张数、分录（摘要/科目/辅助核算/借贷金额）、合计大写金额、制单/审核/记账签章栏。
- 页面打开后自动调起浏览器打印，直接选打印机或另存 PDF；未过账凭证底部有红色提示。

**(4) 凭证导出** —— 凭证管理 → 导出（CSV）

- 按日期范围导出凭证明细（金蝶兼容列序），用于外部查账或归档。

### 步骤 5：账簿查询（随时可查，数据随过账实时更新）

路径：**总账管理 → 账簿查询**，顶部切换账种页签：

| 账种 | 看什么 | 操作要点 |
|---|---|---|
| 总账 | 每个一级科目的期初、本期借贷发生、期末 | 选期间范围 |
| 明细账 | 某科目逐笔凭证发生 + 逐笔余额 | 选末级科目 + 日期范围 |
| 序时账 | 所有凭证按时间流水列示 | 选日期范围 |
| 科目余额表 | 全部科目的期初/本期/期末借贷余额 | 选期间范围 |
| **多栏账** | 上级科目的明细子科目摊成多栏（如管理费用各明细各占一栏） | 选**非末级**科目（末级科目请查明细账）+ 月份范围；分析侧自动按科目方向（费用分析借方、收入分析贷方） |
| **辅助核算余额表** | 按客户/供应商/部门/员工/商品/项目/片区汇总期初、本期借贷、期末 | 选维度 + 期间范围，可选科目过滤；对象名称自动取档案（片区显示原文） |
| **辅助核算明细账** | 某个辅助对象的逐笔明细 + 滚动余额 | 选维度 + 对象（片区直接输文字）+ 日期范围，可跨科目或按科目过滤 |

### 步骤 6：固定资产

**(1) 建卡** —— 资产卡片 → 新增：录入资产名称、类别、原值、残值率、折旧方法、使用年限/工作量、购入日期、使用部门、折旧费用科目。入账凭证自动生成草稿。

**(2) 月度折旧** —— 折旧计提（或从期末处理向导第③步入）：
- 选期间 → **预览**（逐卡月折旧额、合计）→ **执行**：生成「转」字折旧凭证（按费用科目+部门分组汇总），同一期间重复执行幂等不重复计提。
- 当月新增的卡片次月起提；已清理卡片不再计提。

**(3) 卡片变动**：
- **变更**：可改部门、费用科目、折旧方法/年限（原值、残值禁改——金额差错请走拆分/合并/清理）；
- **清理**：录入处置收入/费用、现金科目 → 预览净值与损益（收益/损失）→ 执行，自动生成清理凭证（1606 过渡、损益入 5301/5711、收现带现金流量项目 CF10）；重复清理自动拦截；
- **拆分**：一张卡按比例拆成多张（比例和必须=1，末张吃尾差），原卡置已拆分，不生成凭证；
- **合并**：同类、同部门、同方法、同费用科目的多张卡合成一张，原卡置已合并，不生成凭证；
- **盘点**：资产盘点页逐卡登记相符/盘亏/盘盈，**只留痕不调账**；盘亏需报损的由会计在卡片上发起清理。
- 资产卡片页顶部为**资产台账滚动表**（台账期初/增/减/期末 与 总账 1601/1602 发生额对照）。

### 步骤 7：月末处理（核心，按向导走）

路径：**总账管理 → 期末处理**，向导显示 8 步状态，按顺序处理：

1. **事件检查**：有待生成/失败事件时去待生成凭证处理完；
2. **单据检查**：提示项——确认本期采购/销售/库存/费用单据都已审核（不阻断）；
3. **折旧计提**：预览并执行本月折旧（见步骤 6）；
4. **自动转账**：
   - 系统预置模板：ZZ01 结转未交增值税（仅一般纳税人执行）、ZZ02 计提附加税费；模板在 **转账模板** 菜单维护（可增、改、停用；预置模板不可删除）。
   - **预览**查看每张模板将生成的分录金额 → **执行**（可只选部分模板）：生成「转」字凭证草稿；零金额/借贷不平/条件不满足自动跳过；同一模板同期间重复执行幂等。
   - 生成的转账凭证记得去**凭证管理审核过账**。
5. **结转损益**：预览收入合计、成本费用合计、净利润 → 执行生成 JZ 结转凭证（草稿）→ 审核过账；
6. **结账检查**：四项硬检查（全部过账 / 借贷平衡 / 损益结转 / 上期已结），全部 ✓ 才能继续；
7. **期末结账**：点结账，本期置「已结账」、下期自动转为「进行中」（年末 12 期结账后年度冻结）。结账后本期不能再录凭证；如发现遗漏，可用 **反结账**（仅最后一个已结账期间，必填原因）后补凭证再重新结账；
8. **业财对账**：结账后随时可查，核对业务模块与总账发生额是否一致。

> 转账模板维护（总账管理 → 转账模板）：编号留空自动生成（ZZ03、ZZ04…）；金额公式支持取数函数 QM（期末余额）、QC（期初）、FSD/FSC（本期借/贷发生）、LJFS/LJFSC（本年累计）、CF（现金流量项目），支持 + - * / 与括号；执行条件支持变量 taxpayer（纳税人类型）、surtax_rate（附加税率）。**保存时系统会立即试算公式**，写错会直接拒绝，避免月末才发现。

### 步骤 8：报表与对账

**(1) 总账报表** —— 总账管理 → 总账报表：

- **资产负债表**：期末数 + 年初数两列，页头自动做平衡校验（资产总计 = 负债和所有者权益总计，差额显示）；
- **利润表**：本月数 + 本年累计；
- **现金流量表**：本月金额 + 本年累计；已过账凭证中现金类分录未指定流量项目的，可在页内「现金流量项目补录」批量补录（只影响报表列报，不影响余额）。
- **公式编辑**（会计主管用）：右上角按钮打开公式抽屉，可修改各报表项目的名称与取数公式（保存即试算，写错拒绝）；一般业务不需要改。

**(2) 业财对账** —— 总账管理 → 业财对账：业务发生额（应收/应付/库存/资金等口径）与总账科目发生额三线并列，差异行自动定位，帮助排查「单据已做但凭证未过账」等问题。

## 第三部分　常见问题（FAQ）

| 现象 | 原因与处理 |
|---|---|
| 菜单里看不到「总账管理」 | 总账已并入日常验证环境（2026-09 起），地址就是 `http://localhost:5173`（账号 admin/admin123），不再有单独的 5174。看不到菜单时：① 确认打开的是 `http://localhost:5173`；② 按 Ctrl+F5 强制刷新清缓存；③ 菜单组「总账管理」在左侧栏「财务管理」与「报表中心」之间。仍没有则多是后端（8080）未启动或未连数据库，联系管理员确认后端已起 |
| 业务单据审核后凭证没出现 | 去「待生成凭证」看状态：生成失败会带中文原因，多为科目映射缺失——到档案科目映射/业务类型映射补配后重生成 |
| 凭证不能审核 | 检查：借贷是否平衡、科目是否末级启用、挂辅助核算的分录是否填了对象、期间是否已结账/未开账 |
| 凭证过账后发现错了 | 当月：反过账 → 反审核 → 修改；已隔月：做红字冲销后重新制单 |
| 多栏账查不出/提示选非末级 | 多栏账只对**上级科目**使用（如 5602 管理费用）；末级科目请查「明细账」 |
| 辅助账里对象显示编码不显示名称 | 该对象不在基础档案中（片区为自由文本属正常）；其余维度请先在基础资料建档并使用编码制单 |
| 月末结不了账 | 看第⑥步结账检查哪项未过：有草稿/已审核凭证 → 审核过账或作废；损益未结转 → 先做第⑤步并把 JZ 凭证过账；上期未结 → 先结上期 |
| 折旧金额与预期不符 | 当月增加次月才提；清理/拆分/合并后的卡片按新原值与剩余年限计提；可在折旧预览里逐卡核对 |
| 资产负债表不平 | 先确认本期已结账且损益已结转；再有差异看业财对账定位未过账凭证；报表公式被人为改过可联系管理员核对 |
| 想修改已结账月份的凭证 | 期末处理 → 反结账（仅限最后一个已结账期间，必填原因）→ 反过账/反审核修改 → 重新结账 |

## 第四部分　管理员备注

- 总账启用后期初锁死；科目/模板/公式等基础配置建议由会计主管统一维护，所有写操作均有操作日志（系统管理 → 操作日志，模块码 finance.gl.*）。
- 自动转账模板、报表公式的取数函数体系：QM/QC（期末/期初余额）、FSD/FSC（本期借/贷发生）、LJFS/LJFSC（本年累计借/贷发生）、CF/CFY（现金流量项目），支持四则运算与括号；条件变量：taxpayer（GENERAL/SMALL）、surtax_rate。
- 数据与备份：系统使用 H2 文件库（后端 backend/data 目录），月结/年结前建议备份数据库文件。
