# ERP + WMS + TMS 商贸经销商管理系统

## 📋 项目概述

面向商贸经销商行业，提供一套完整的 **进销存 + 仓储作业 + 配送运输** 的数字化管理系统。

> **参照文档**：ERP系统提纲 | 编制：2026-06-10

## 🏗️ 系统架构

```
┌──────────────────────────────────────────────────┐
│            ERP 后台管理系统 (PC Web)               │
│  采购·销售·库存·财务·报表·基础数据·系统管理         │
│  22个微服务 | Vue3+Element Plus+Vite             │
├──────────────────────────────────────────────────┤
│            WMS 仓库作业系统 (PDA APP)              │
│  收货·上架·拣货·复核·盘点·移库·组合拆分·装车·拒收  │
│  适配斑马/霍尼韦尔/东集PDA | Flutter/uni-app      │
├──────────────────────────────────────────────────┤
│            TMS 司机配送系统 (Driver APP)           │
│  派单·导航·签收·拍照·回款·退货回收·拒收·轨迹       │
│  Android+iOS | Flutter/uni-app                   │
└──────────────────────────────────────────────────┘

成本算法：移动加权平均法（按仓库成本分组独立核算）
日结数据：每日定时生成客户/供应商/往来单位/商品日结
```

## 🛠️ 技术选型

| 层级 | 技术栈 |
|------|--------|
| **后端框架** | Spring Cloud Alibaba 2023.x 微服务 |
| **注册/配置** | Nacos 2.3 Cluster |
| **API网关** | Spring Cloud Gateway |
| **RPC** | Dubbo 3.3 (核心链路) + OpenFeign |
| **限流熔断** | Sentinel |
| **分布式事务** | Seata (AT/TCC) |
| **消息** | RocketMQ 5.x |
| **定时任务** | XXL-JOB |
| **数据库** | PostgreSQL 16 (主) + MySQL 8.0 (辅) + Redis 7.x + Elasticsearch 8.x + TDengine |
| **对象存储** | MinIO |
| **ERP前端** | Vue 3 + TypeScript + Element Plus + Vite |
| **WMS PDA** | Flutter/uni-app (Android 8.0+ PDA) |
| **TMS APP** | Flutter/uni-app (Android/iOS) |
| **容器编排** | Kubernetes (K8s) |
| **监控** | Prometheus + Grafana + SkyWalking + ELK |

## 🔑 核心功能模块（根据系统提纲）

### 一、系统管理 (10项)
权限组管理 · 用户管理（数据范围权限） · 系统参数 · 操作日志 · 导出中心 · 导入列表 · 打印模版字段查询 · 打印模版设置 · 系统默认字典 · 用户数据字典

### 二、基础管理 (21项)
部门管理 · 货主信息 · 人员信息 · 单位信息 · 品牌管理 · 商品分类(三级) · 供应商信息 · 价格组设置 · **商品信息(多单位/价格组)** · 片区管理(多级树) · 线路管理 · 客户信息(门店) · 仓库管理(成本分组) · 商品调价单 · 商品调价查询 · 客户价格设置 · 资金账户 · 费用类型 · 收入类型 · 付款类型 · 往来单位管理

### 三、采购管理 (9项)
采购订单 · 采购退货申请 · 采购收货单(成本核算) · 采购退货单 · **AI采购预测**(日均销量/库存上下限) · 采购改价单 · 采购费用单(分摊) · 缺货分析 · 商品周转率分析

### 四、销售管理 (5项)
销售订单 · **销售收货单**(可改签收单价/日期) · 销售退货申请 · 销售退货单(司机回收/仓库入库双模式) · 销售看板

### 五、WMS仓库管理 (27项)

### 六、财务管理 (18项)
收款单 · 付款单 · 费用单 · 应付结算 · 应收结算 · 往来单位结算 · 客户应收应付 · 供应商应收应付 · 往来单位应收应付 · 凭证模板 · 凭证管理 · 科目管理 · 核算项目管理 · 凭证查询 · 固定资产管理 · 固定资产折旧 · 固定资产清理 · 成本调整单

### 七、报表中心
